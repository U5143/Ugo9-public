# 目と口の開け閉じ・揺れ物の候補・待機のアニメの下書き

エディタのボタンから使う下書き。パーツと骨の名前（PSD のレイヤー名。日本語・英語）から探す。作り手が直すための初期案で、顔の向きの下書き（`docs/顔の向きの自動生成.md`）と同じく、エディタが今のキーに合わせて書き込む形で返す。

## 目の開け閉じ（`tools/eye_mouth.mjs` の `makeEyeBlink`）

```js
import { makeEyeBlink } from '../tools/eye_mouth.mjs';
const { motions, warnings } = makeEyeBlink(model);   // 両目を名前から
// motions: [{ at: { EyeOpenL: 0 }, morphs: { 'まつ毛 左': { dense: [dx0, dy0, ...] }, ... } }, { at: { EyeOpenR: 0 }, ... }]
makeEyeBlink(model, { parts: ['eyeUpperL', 'eyeWhiteL', 'irisL'], param: 'EyeOpenL' });  // 1 つの目を指定して
```

- 目のパーツ：名前に eye・目・瞳・まぶた・まつ毛・白目・lash・iris など（眉・brow は除く）
- 左右：名前の 左・右・left・right、または最後の `L`・`R`（`eyeUpperL`・`eye_L`）。名前に無ければ、PSD を開いた時のフォルダの名前（`opts.layers`、省けば `model.source.psd.layers` の `path`。`左目` フォルダなど）。それでも左右の無いパーツしか無ければ、画面の左の目を L、右の目を R として警告。左右の決め方は `sideOfPart(model, opts)` で、`makeStarterRig` も同じ物を使う
- 役目：下まぶた（lower・下まぶた）は上へ、上まぶた（upper・上まぶた・まつ毛・lash・lid）は下へ、白目・瞳・その他の目のパーツは 1 本の線に潰す。上と下が会う線は白目の上から `closeAt`（既定 0.6）の高さ
- パラメータ：`EyeOpenL`・`EyeLOpen`・`ParamEyeLOpen`・`EyeOpen` の順に探す（R も同じ）。motion は閉じた側の値（既定値でない方の端、ふつう 0）。無い時は `EyeOpenL`（min 0・default 1・max 1）の 0 で作って警告し、作るべきパラメータを戻り値の `params`（`[['EyeOpenL', 0, 1, 1]]`）でも返す（エディタはそれを作ってから呼び直す）

## 口の開け閉じ（`makeMouthOpen`）

```js
const { motions, warnings } = makeMouthOpen(model);  // [{ at: { MouthOpen: 1 }, morphs }]
```

- 口のパーツ：名前に mouth・口・唇・lip・歯・舌・あご など。下唇・あご（lower・下）は `open` px 下へ（既定は口の幅の 0.3 倍）、上唇（upper・上）はその 0.15 倍上へ、口の中（inside・口の中・歯・舌）はその間に伸ばす
- 口が 1 枚の絵なら上下に伸ばすだけ（警告：唇と口の中を分けると良い）
- パラメータ：`MouthOpen`・`MouthOpenY`・`ParamMouthOpenY` の順。motion は開いた側の端。無い時は `params` に `['MouthOpen', 0, 0, 1]`

## 揺れ物の候補（`tools/suggest_chains.mjs` の `suggestChains`）

```js
import { suggestChains } from '../tools/suggest_chains.mjs';
suggestChains(model);  // [{ root: 'hairL', bones: ['hairL', 'hairL2', 'hairL3'], reason: 'name: hair' }, ...]
```

- 骨の名前、またはその骨に付いたパーツ全部の名前が、髪・リボン・スカート・しっぽ・耳・布（マント・袖・フリル）・飾り（イヤリングなど）の物（頭の骨に前髪のパーツが付いていても、顔のパーツも付いていれば候補にしない）
- 子に揺れない骨がある骨は入れない（頭の骨に目や首の骨が付いている時など）
- 候補はそういう骨から始まり、子が 1 本の間だけ先へ続く（鎖は 1 本の線）。枝分かれの先の揺れる骨は、それぞれ別の候補
- 一番上の骨（親の無い骨）、もう鎖に入っている骨、格子の中の骨、制約で使う骨は入れない
- 骨が上を向いている時は `warning` を付ける。鎖は根元で吊るされて垂れるので、固定する所から下へ向けた骨にする（PSD の `groupBones` の骨は上を向いている）

## 待機のアニメ（`tools/idle.mjs` の `makeIdle`）

```js
import { makeIdle } from '../tools/idle.mjs';
const { animation, params, notes, warnings } = makeIdle(model, { duration: 4, blinks: 2, amount: 1, seed: 1 });
// animation: { id: 'idle', duration: 4, loop: true, tracks: { Breath: [[0, 0, 'smooth'], [2, 1, 'smooth'], [4, 0, 'smooth']], ... }, bones?: {...} }
```

- モデルにある物だけを動かす。キーは全部 `smooth`。どのトラックも始めと終わりが同じ値で、ループの継ぎ目で跳ばない
- 呼吸：`Breath`（`ParamBreath`）を既定値から最大へ上げて戻す（3.5 秒に 1 回くらい）。無ければ体の骨（body・chest・体・胸）の `scaleY` を 1.2% 動かす（お知らせ `idleBreathBone`）
- まばたき：`EyeOpenL`・`EyeOpenR`（無ければ `EyeOpen`）を、左右同時に `blinks` 回、0.06 秒で閉じ・0.02 秒閉じたまま・0.08 秒で開く。場所は `seed` の乱数で決める（同じ seed なら同じアニメ）
- ゆらぎ：`AngleX`（幅の 1 割、1 往復）・`AngleY`（6%、2 往復）・`AngleZ`（8%、X と逆向きに 1 往復）。キーは折り返しの所だけに置くので、`smooth`（キーの間の smoothstep）で余弦のような波になり、継ぎ目でも折れない
- 髪：鎖（`chains`）があれば何もしない（物理で揺れる）。無ければ `HairSway` のような名前のパラメータを幅の 3 割で 2 往復
- id は `idle`。もうあれば `idle2`、`idle3`…
- `params` は空。キーフォームの無いパラメータを作っても何も動かないので、足りない物は notes で知らせる（`idleNoBreath`・`idleNoBlink`・`idleNoSway`・`idleNothing`）。目の開け閉じは先に `makeEyeBlink` で作る

## 下書きをまとめて作る（`tools/starter_rig.mjs` の `makeStarterRig`）

PSD を開いた直後のモデルに、顔の格子・顔の向き・目と口の開け閉じ・待機のアニメを 1 度に作る。エディタの「下書きをまとめて作る」ボタンから呼ぶ。モデルは書き換えず、足す物だけを返す。エディタはそれを、格子 → パーツを格子へ → パラメータ → motions → アニメの順に 1 手で書く（取り消し 1 回で戻る）。

```js
import { makeStarterRig } from '../tools/starter_rig.mjs';
const r = makeStarterRig(model);
// r.warps: [{ id: 'face', cols: 6, rows: 6, rect, bone }, { id: 'eyeL', parent: 'face', ... }, ...]
// r.assign: { partId: gridId }（そのパーツの bone・weights は外す）
// r.params: [[id, min, default, max]]、r.motions: [{ at, warps?, morphs? }]、r.animation: 待機のアニメか null
```

- 顔の格子：名前が 顔・輪郭・face のパーツと、目・口・眉・鼻・頬のパーツをまとめた外接矩形を 1 割広げる。骨は顔のパーツの骨。顔・眉・鼻・頬は顔の格子に、目は左右ごとの格子、口は口の格子（どれも顔の格子の中）に入れる。髪と体は骨のまま
- 目の左右：レイヤーの名前、無ければ PSD のフォルダの名前（`opts.layers`、省けば `model.source.psd.layers` の `path`。「左目」フォルダなど）、それも無ければ画面の位置
- 顔の向き・目・口・待機は、それぞれ `makeFaceAngles`（`auto: 'parts'`、中の格子も）・`makeEyeBlink`（左右ごとに `EyeOpenL`・`EyeOpenR`）・`makeMouthOpen`（`MouthOpen`）・`makeIdle` で、格子とパラメータを足した後の写しの上で作る
- 格子の id がパーツや骨の id とぶつかる時は `face_grid` のように変える
- **もうある物は残す**：顔の格子があればそれを使い、格子に入っているパーツは動かさない（`starterPartInGrid`）。キーの形のあるパラメータの下書きと、`idle` のアニメは作らない（`starterSkipped {step}`）。何度押しても壊れない
- 作った物ごとに info の note `starterMade {step, count}`（step は `grid`・`angles`・`blink`・`mouth`・`idle`）。顔のパーツが無い時は `starterNoFace`（格子と顔の向きだけ作らず、目・口・待機は作る）

`tests/starter_rig_test.mjs`：目を「左目」「右目」フォルダに入れた（レイヤーの名前に左右の無い）PSD から作り、書き込んで芯で動かすと、AngleX で顔だけが回り、EyeOpenL で左目だけが閉じ、MouthOpen で口が開き、待機のアニメで顔が動く。もう一度押すと何も足さない。

## 確かめたこと（`tests/eye_mouth_test.mjs`）

日本語の名前の左目と英語の名前の右目・唇 3 枚のモデルに範囲として入れて芯で動かすと、閉じた目で上まぶたの下の辺・下まぶたの上の辺・潰した白目と瞳がどれも同じ線に来る。EyeOpenL = 0.5 で半分、右目はそのまま。MouthOpen = 1 で下唇が 12 px 下・上唇が 1.8 px 上・口の中がその間。揺れ物は、髪の 3 本の線・スカートの枝分かれ・リボンのパーツの付いた腕の骨を挙げ、鎖・格子の中の骨を除き、上を向いた前髪の骨に警告を付ける。

`tests/idle_test.mjs`：見本のキャラに入れて芯で再生すると、全部のトラックが継ぎ目で跳ばず（差 0）・折れず、Breath が 0 → 1 → 0、2 回のまばたきが左右同時、AngleX が幅の 1 割（3°）まで。Breath の無いモデルでは体の骨が 1.2% 伸びて戻る。
