# 顔の向きの自動生成（`tools/face_angles.mjs`）

Live2D の「顔の動きの自動生成」に当たる初期案を作る。**2026-11-01 から既定は球の焼き込み**（`tools/sphere_bake.mjs`、`docs/球体デフォーマ.md`）：顔より少し大きい球（顔の縁が球の 0.9）を回し、キーは 10° ごと、制御点は最小二乗で合わせる。途中の角度でも正確な楕円体と半径の 1% 未満で合う（前のやり方は最大 9%）。返り値に `keys`（各パラメータのキーの並び）と `shape`（使った球）が増える。前のやり方は `method: 'points'` で使える（下の説明はそのやり方）。

顔のワープ格子（形式 0.5）と、その中の格子（目・眉・口など）の制御点を、左右・上下の向きの端と四隅で動かす。作り手が直すための下書き。

```js
import { makeFaceAngles } from '../tools/face_angles.mjs';
const { motions, warnings, center, radius } = makeFaceAngles(model, { warp: 'face', auto: 'parts' });
// motions: [{ at: { AngleX: 30 }, warps: { face: { dense: [dx0, dy0, ...] }, eyeL: { dense: [...] } } }, ...]
```

- `at`：どのキーの上での動きか（エディタが今のキーに合わせて書き込む）。左右の端 2 つ・上下の端 2 つ・四隅 4 つ
- 四隅は「2 軸に回した形 − 2 つの端の和」（Ugo9 の 2 軸の範囲は角でだけ足すので、端の動きと合わせると 2 軸に回した形になる）
- `warps` の中身は形式どおり（格子の基準の姿の px、制御点ごと）。顔の格子の中の格子（孫も）も同じ motion に入る。入れ子の格子の差分もモデル座標の px（コンパイラが親のマス目に直す）
- `warnings` の最初の 1 行に、使った中心と半径とその出どころを書く（例 `face centre [0, -180], radius [80, 100] (from part 顔)`）。`center`・`radius` でも返す

## 設定

| 設定 | 意味 | 既定 |
|---|---|---|
| `warp` | 顔の格子の id | `face`、無ければ親の無い最初の格子 |
| `paramX`・`paramY` | 左右・上下のパラメータ | `AngleX`・`AngleY`（無い時は −30・30 で作って警告し、戻り値の `params` に `[id, -30, 0, 30]`） |
| `auto` | `center`・`radius` を書かない時の決め方：`'rect'`（格子の四角）か `'parts'`（格子の中のパーツ。名前に face・顔・輪郭 が入るパーツがあればその外接矩形、無ければ髪 以外の全部） | `'rect'` |
| `center`・`radius` | 顔の中心と半径 [x, y]（モデル座標）。片方だけ書くと、もう片方は `auto` で決める | 格子の中心と半分の大きさ |
| `turnX`・`turnY` | パラメータの端で回す角度（度） | 30・20 |
| `depth` | 顔の奥行き（半径の割合） | 0.6 |
| `amount` | 動き全体の倍率 | 1 |
| `nested` | 中の格子も動かすか | `true` |

## 動かし方

顔を楕円体の前の面に描いたと見て、楕円体を回した時に、その点がどこに見えるか（正面から見た位置）へ制御点を動かす。手前の点ほど大きく動き、奥の側は詰まる。楕円の外の点は奥行き 0 として回す。パラメータの端が回しきった形、既定値が正面。

中の格子（目・口など）は親の格子の曲面に乗って動くが、顔の格子は粗くなめらかなので、それだけだと目は頬と同じようにしか動かない（下の確かめでは 3.8 px ずれる）。そこで中の格子の点も楕円体を回した位置を目標にし、親の曲面（芯と同じ B スプライン）がそこへ置くマス目の位置をニュートン法で解いて、残りの分を差分にする。四隅も「2 軸に回した形 − 2 つの端の和」（差分は足し算で効くので中の格子でもそのまま成り立つ）。途中は範囲の直線の補間（エディタで中間のキーを足して直せる）。

## 確かめたこと（`tests/face_angles_test.mjs`）

動きを範囲としてモデルに入れて芯で動かすと、端 4 つ・四隅 4 つの全部で、制御点が楕円体を回した位置と 0.001 px 未満で一致。AngleX = 30 で顔の中央が右へ 30 px、AngleY = 30 で上へ 20.5 px 動く。顔の中に目の格子、目の中に瞳の格子を入れても、端と四隅の全部で目と瞳の制御点が楕円体を回した位置と 0.002 px 未満で一致（中の格子を動かさないと 3.8 px ずれる）。`auto: 'parts'` は顔のパーツ（前髪が格子いっぱいでも）の外接矩形を使う。
