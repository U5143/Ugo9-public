# .ug9 から作業ファイルへ（`tools/import_ug9.mjs`）

配布用の `.ug9` から、作業用 JSON を作り直す（利用者の声 #41：作業データをなくした・`.ug9` しか手元に無い）。`.ug9` は [形式.md](形式.md) の説明どおりに読む。戻した JSON をコンパイルすると、同じモデルになる。

```sh
node tools/import_ug9.mjs face.ug9 out     # out/face.json と、face.ug9 の横にあるテクスチャを out へ
```

```js
import { importUg9 } from '../tools/import_ug9.mjs';
const { json, notes, warnings } = importUg9(bytes, { file: 'face.ug9' });
```

- 1.1 の曲線のキー（表 41〜43）は、`"bezier"` のキーに戻す（芯の分け方の印 n は書き直す時にコンパイラが決め直す）。smooth と同じ形の曲線は `"smooth"` に。色のトラックの曲線は、作業用 JSON では 3 つのチャンネルが 1 つのキーを持つので、芯が分ける直線にして戻す（`ug9ColorCurves`）
- 読む版：0.7 と 1.x。1.x は表の目次から読む。知らない種類の表は、目次の印が 0・1 なら飛ばして知らせ（`ug9SkippedTable`。1 は「絵が変わるかもしれない」で warn）、2 なら読まない（`ug9Newer`）。知らない種類のトラックも飛ばして知らせる（`ug9SkippedTracks`）
- 1.0 で足された物も戻す：回した格子（`rect` と `angle`。格子の中の格子・格子の中の骨も）、描画順（パーツの `order`、範囲の `order`、アニメの `order`）、表情（`expressions`。パラメータの名前で）
- 戻した JSON には `editor.restoredFrom = { file, format, bytes }` が付く（エディタが「.ug9 から戻した」と出せるように）
- 戻らない物と、名前の付け直しは `notes` で知らせる（[警告の一覧](警告の一覧.md#ug9-から作業ファイルへimportug9toolsimport_ug9mjs)）

## 戻る物・戻らない物

| | 戻る | 戻らない（代わりにどうなるか） |
|---|---|---|
| 名前 | パラメータ・骨・パーツ・テクスチャ・アニメ・ワープ格子・骨の鎖 | 制約・色・デフォーマ（`.ug9` に名前が無い：`constraint0`・`color0`・`morph0` と付ける） |
| 形 | メッシュ（位置・UV・三角形）、重み、マスク、合成、色、格子（等間隔の四角として。回した格子は角度も）、格子の中の骨、描画順、表情 | のり（重みと差分に焼かれた形で戻る） |
| 動き | 範囲と差分・骨・不透明度・色・格子の動き、物理、骨の鎖、制約 | デフォーマのまとまり（同じ範囲の物は 1 つにまとまることがある）、複数の骨の transform 制約（骨ごとに 1 つ） |
| アニメ | キー（16 ビットの時刻と値から）、飛び（同じ時刻のキー 2 つ）、なめらか（トラックの印） | 曲線の形（コンパイラが短い直線に分けた物はその直線のまま）、キーごとの補間の名前 |
| ほか | キャンバス | 取り込み元（PSD・Spine）とのつながり、エディタだけの情報（ガイド・選択セット・フォルダ・スクリプト） |

## 書き出す物を選ぶ（`tools/strip_model.mjs`、2026-11-10、機能の比べ #91）

ゲームが使うアニメが 2 本だけ、物理は自前、という時に、要らない物を入れずに書き出す。

    node tools/strip_model.mjs model.json --out game.ug9 [--anims idle,walk] [--no-physics] [--no-chains] [--no-expressions]

- `--anims`：そのアニメだけを残す（無い名前は知らせて止まる、`stripNoAnimation`）。`--no-physics`・`--no-chains`・`--no-expressions`：物理・骨の鎖の揺れ物・表情を外す
- エディタの情報（`editor`・`source`）はいつも外す（.ug9 に入らないので、JSON で書く時に軽くなるだけ）
- パーツ・骨・パラメータ・デフォーマはそのまま（パラメータを外すと、それで動くデフォーマや動きもほどく必要があるので、しない）
- `--out` が .json なら作業用 JSON を、.ug9 ならコンパイルした物を書く。入力に .ug9 も渡せる（作業用 JSON に戻してから）。前と後の .ug9 の大きさを出す
- `stripModel(json, opts)` はブラウザでも動く（エディタの書き出しの窓用）
- 確かめ（`tests/strip_model_test.mjs`）：何も選ばなければ同じ .ug9。idle だけ・物理・鎖・表情なしで、.ug9 はアニメ 1 本（トラック 11 → 8、キー 60 → 40）、物理・鎖・表情 0、位置・UV・パーツ・骨・パラメータ・デフォーマは同じ。無い名前、渡したモデルは変わらない、コマンド

## 確かめたこと（`tests/import_ug9_test.mjs`）

見本・テストのモデル 3 つ、1.0 の描画順の見本、回した格子・描画順・表情を持つ小さなモデルと、`samples/提供` の Spine のキャラ 9 体（確かめるためだけに使い、変換は build/ の中だけ）で、JSON → コンパイル（A）→ 戻す → コンパイル（B）。

| モデル | .ug9 のバイト | 違うバイト | 違う数（表ごと） | ugo_export の絵（2 を超えて違う画素） |
|---|---|---|---|---|
| basic | 229,852 | 0 | 0 | 0 / 320,000 |
| warp | 13,460 | 0 | 0 | 0 / 160,000 |
| pose | 14,340 | 39 | 骨 37、トラック 2 | （テクスチャ無し） |
| 提供の Spine のキャラ 9 体（3.7・3.8） | 237,420〜2,745,336 | 296〜1,672 | 骨 219〜1,074、トラック 15〜257、キー 0〜8、重み 0〜6 | 0 / 480,000（どれも最大 1） |

- 1.0（v08）で：回した格子は、角度を点から求め直すので、格子の点と格子の中の骨の数が 32 ビットの丸めで少し動く（最大 4e-6）。描画順・表情は同じ数。後の 1.3 を真似たファイル（長いヘッダ・知らない表・知らないトラック）は、知らない所を飛ばして読む
- 大きさはどれも同じ。違うのは、元の JSON の小数（倍精度）が `.ug9` では 32 ビットに丸まっているための物だけ
  - 骨：基準の逆行列（元の骨の位置の小数から作る）。差は最大 2.2e-4
  - トラック：16 ビットの値の 1 目盛りの幅（最大 10 ulp）。キー：そのため 16 ビットの値が 1 違う物が 1.4 M のうち数個
  - 重み：32 ビットの最後の 1 桁
- B をもう一度戻してコンパイルすると B と同じバイト（2 回目からは変わらない）
- 絵：各モデルのアニメ 2〜3 本 × 4 コマを 200×200 で描き、A と B の差は最大 1/255
- 壊れたファイル：JSON・版 0.6・切れた物はそれぞれの code で止まる。表の中の 4 バイトを変えたファイル 400 通りは、読めるか ug9 の code で止まる（ほかの例外は出ない）

## 2 つの .ug9 を比べる（`tools/ug9_diff.mjs`、2026-11-10）

新しい版を渡す前に、前の版から何が変わったかを見る。作業用 JSON を渡すと先にコンパイルして比べる。

    node tools/ug9_diff.mjs 前.ug9 後.ug9 [--json] [--all]

- 版・ファイルの大きさ・キャンバス
- バイナリの表ごとの数と大きさ（バイト）の前と後。既定は変わった表だけ、`--all` で全部
- 足された・消えた名前：パーツ・骨・パラメータ・アニメ・物理（動かすパラメータの名前で）・骨の鎖・表情。並びが変わった時はそう書く
- 同じ名前で中身が違う物と、どこが違うか（欄の名前。数の並びは、いくつ変わったかと一番大きな変わり幅）。1e-4 より近い数は同じ
- 残り（キャンバス・テクスチャ・色・デフォーマなど）はまとめて比べる。デフォーマは .ug9 に名前が無いので、名前では比べない
- 同じ時は終わりの値 0、違う時は 1。`--json` は結果をそのまま
- 両方を同じ道（`importUg9`）で読むので、.ug9 に入らない物（エディタの情報など）は比べない
- 確かめ（`tests/ug9_diff_test.mjs`）：同じファイルは同じ、作業用 JSON とそのコンパイル結果は同じ。見本に分かっている変更（頂点 2 つ、不透明度、骨の回転、パラメータを 1 つ足す、アニメを 1 つ消して 1 つの長さを変える）をすると、それだけが出て、増えた表もその分だけ。パーツ 2 つを入れ替えると「並びが変わった」だけ。1.0 と 1.1 で曲線の表が出る。コマンドの終わりの値
