# パラメータの名前（標準の表）

よく使うパラメータの、Ugo9 の標準の名前です。形式は名前を決めません（どんな名前でも動きます）。この表に合わせておくと、**表情のプリセット**（[形式](形式.md) の「表情」）や、アプリの顔のトラッキングの結び付けを、別のモデルにそのまま使えます。

- 名前は Ugo9 自前の物です（他のツールの ID は写していません）
- 範囲は目安です。違う範囲でも名前が同じならプリセットは当たりますが、`set` の値の意味が変わるので、範囲もそろえるのがおすすめです
- 左右のある物は、**キャラから見て**左が `L`、右が `R`（画面では左右が逆）
- 「正の向き」の上下・左右は**画面で見て**（x は右、y は上を向く・上へ動く）
- 今の道具（取り込み・下書き・見本）が作る名前は右の列。この表へ合わせるかは、各道具の担当とハブで決めます（合わせるまでは、プリセットで名前を付け替える）
- 道具が作る名前がこの表（標準か右の列）にあるかは、`tests/param_names_test.mjs` が道具を実際に動かして確かめます。表に無い名前を作り始めると落ちます
- **決めたこと（2026-11-12、ハブ）**：新しく作る物（下書き・取り込み・見本）は標準の名前を作る。読む側（Web の `UgoLook`・VTuber 表示の顔の追従・エンジンの助け）は、標準の名前と右の列の名前の両方を読む。各担当が合わせるまで、`tests/param_names_test.mjs` は右の列の名前を警告（WARN）にし、合わせ終わった道具は失敗にする。VTuber 表示の顔の追従（`web/tracking.js`）は合わせ済み（標準の名前を書き、モデルに無ければ右の列の名前や `Param` の付いた名前に書く）。見本（`samples/basic`）も標準の名前に変えた（2026-11-12。`BrowY`・`FaceColor` だけは見本だけの名前として残す）

## 表情のプリセットの例

この表の名前で書いた表情（プリセットのファイルは `.ug9x`）は、表の名前を持つどのモデルにも当たります（無い名前は飛ばされ、エディタは読み込む時に一覧で出します）。

```json
{ "format": "ugo9-expressions", "version": 1, "expressions": [
  { "id": "smile", "fadeIn": 0.4, "fadeOut": 0.4,
    "params": { "EyeSmileL": ["set", 1], "EyeSmileR": ["set", 1], "MouthShape": ["set", 1], "Cheek": ["set", 0.5] } },
  { "id": "angry", "fadeIn": 0.3, "fadeOut": 0.5,
    "params": { "BrowAngleL": ["set", -1], "BrowAngleR": ["set", -1], "BrowHeightL": ["add", -0.3], "BrowHeightR": ["add", -0.3], "MouthShape": ["set", -0.6] } },
  { "id": "surprised", "params": { "EyeWideL": ["set", 1], "EyeWideR": ["set", 1], "BrowHeightL": ["add", 0.6], "BrowHeightR": ["add", 0.6], "MouthOpen": ["add", 0.4] } },
  { "id": "sleepy", "params": { "EyeOpenL": ["multiply", 0.4], "EyeOpenR": ["multiply", 0.4] } }
] }
```

`multiply` は、まばたきやトラッキングで動いている値に掛けるので、「半分閉じた目のまま、まばたきも続く」ような表情に向きます。
