# PSD の描き方（Ugo9 に読み込む前に）

Ugo9 のエディタは、PSD のレイヤー 1 枚を 1 つのパーツにします。顔の向き・目と口の開け閉じ・揺れ物の候補・待機のアニメを自動で作るボタンは、**レイヤーの名前**でパーツを探します。名前と分け方を少し整えておくと、PSD を開いてすぐ動く所まで進めます。

## まず確かめること

| 確かめること | 理由 |
|---|---|
| カラーモードは **RGB**（グレースケールも可）。8 ビットか 16 ビット | 32 ビット・Lab・ビットマップは読めない（エラーで知らせる）。CMYK は読めるが、色が少し変わることがある |
| **動かす所ごとにレイヤーを分ける**（目・まぶた・口・前髪・後ろ髪など） | 1 枚の絵は 1 つのパーツとしてしか動かない |
| 隠れる所も描いておく（前髪の下のおでこ、まぶたの下の白目、口の中など） | 動かすと下が見えるため |
| **レイヤー効果**（境界線・ドロップシャドウ・光彩）は、絵にしておくと確か | 主な効果（影・境界線・光彩・オーバーレイなど）は読み込みで絵に描き込む（知らせが出る）。描き込めない種類（ベベルなど）は名前を挙げて知らせる。思った通りでない時は、Photoshop は「レイヤースタイルをラスタライズ」、クリスタは「ラスタライズ」 |
| **調整レイヤー**（レベル補正・トーンカーブ・色相など）は、下のレイヤーに結合しておくと確か | 届くレイヤーに焼き込んで読む（Photoshop と同じ物と近いだけの物があり、近いだけの物は知らせが出る） |
| キャンバスは縦横 4080 px まで | 超える時は 4080 px に縮めて読む（知らせが出る）。大きいほど読み込みに時間がかかる（4000 px で 2 秒ほど） |

文字・スマートオブジェクト・塗りつぶしのレイヤーは、PSD に入っている絵のまま読みます。非表示のレイヤーも読み、見えない（不透明度 0 の）パーツになります。

## レイヤーの名前

自動の道具は、下の言葉が名前に**含まれる**かで探します（英語は大文字・小文字を区別しません）。日本語と英語のどちらでもかまいません。

### 目（目の開け閉じ）

| 役目 | 名前の例 | 閉じる時の動き |
|---|---|---|
| 上まぶた・まつ毛 | `上まぶた`・`まつ毛`・`まつげ`・`eyelid`・`upper lash` | 下へ下がる |
| 下まぶた | `下まぶた`・`下まつ毛`・`lower lid` | 上へ上がる |
| 白目 | `白目`・`white`・`sclera` | 1 本の線に潰れる |
| 瞳・ハイライト | `瞳`・`黒目`・`ハイライト`・`iris`・`pupil`・`highlight` | 1 本の線に潰れる |
| その他の目の絵 | `目`・`eye` が入る物 | 1 本の線に潰れる |

- 眉（`眉`・`まゆ`・`brow`）は目に含めません
- **左右は名前で分けます**：`左`・`右`・`left`・`right`、または最後に `L`・`R`（`eyeUpperL`・`eye_L`・`白目.l`）。レイヤーの名前に無ければ、そのレイヤーが入っているフォルダの名前（`左目`・`右目`・`left eye` など）を見ます。どちらにも無い時は、画面の左にある目を L として作り、知らせを出します
- 「左目」フォルダの中に「白目」「瞳」「まつ毛」と置く描き方でもかまいません（PSD を開いた時のフォルダの道筋を、エディタが文書に残しているため）。`白目 左` のようにレイヤーの名前に左右を入れても同じです
- 左は「キャラから見た左」と「画面の左」のどちらでもかまいません。作られるパラメータは `EyeOpenL`・`EyeOpenR` です。逆だった時は、エディタでパラメータを入れ替えます

### 口（口の開け閉じ）

| 役目 | 名前の例 | 開く時の動き |
|---|---|---|
| 下唇・あご | `下唇`・`あご`・`lower lip`・`jaw` | 下へ下がる |
| 上唇 | `上唇`・`upper lip` | 少し上がる |
| 口の中 | `口の中`・`口内`・`歯`・`舌`・`teeth`・`tongue`・`inside` | 上下に伸びる |
| 口（1 枚） | `口`・`mouth` | 上下に伸びるだけ（知らせが出る） |

口は、**上唇・下唇・口の中の 3 枚に分ける**と、開け閉じがきれいに作れます。

### 顔（顔の向き）

- 顔の輪郭の絵の名前に `顔`・`輪郭`・`face` を入れてください。その絵の大きさから、顔の中心と丸みを決めます
- 前髪・もみあげ（`髪`・`前髪`・`hair`・`bang`）は、顔の大きさを決める時に外します

### 揺れ物（揺れ物の候補）

| 種類 | 名前の例 |
|---|---|
| 髪 | `前髪`・`後ろ髪`・`横髪`・`もみあげ`・`アホ毛`・`ポニーテール`・`ツインテ`・`三つ編み`・`hair`・`bang`・`ponytail`・`braid` |
| リボン・紐 | `リボン`・`紐`・`ネクタイ`・`ribbon`・`bow`・`tie` |
| スカート | `スカート`・`裾`・`skirt`・`hem` |
| しっぽ・耳 | `しっぽ`・`尻尾`・`耳`・`tail`・`ear` |
| 布 | `マント`・`マフラー`・`袖`・`フリル`・`ベール`・`cape`・`scarf`・`sleeve`・`frill` |
| 飾り | `イヤリング`・`ピアス`・`ペンダント`・`羽`・`房`・`earring`・`pendant`・`feather` |

揺れ物の候補は、骨（または骨に付いたパーツ全部）の名前から作ります。エディタで「PSD のグループを骨に」に印を付けて PSD を開くと、フォルダの名前が骨の名前になるので、`前髪` のようなフォルダに分けておくと候補に出ます。

### 体（待機のアニメ）

呼吸のパラメータ（`Breath`）が無い時は、体の骨（`体`・`胸`・`胴`・`上半身`・`body`・`chest`）の高さを少し動かして呼吸にします。

## 名前で骨を決める（2026-11-10、ユーザーの決定。Bones from layer names）

レイヤーやフォルダの名前の終わりに、角かっこの印を書くと、読み込む時に骨ができる。印の言葉は日本語でも英語でもよい（エディタの言語の設定に関係なく、どちらも読む）。全角の［］＝と全角の空白は半角と同じ。英字の大文字小文字は区別しない。印は名前に入らない（「腕 [骨]」のパーツと骨の名前は「腕」）。

Write a tag in square brackets at the end of a layer's or folder's name, and a bone is made when the PSD is read. The words can be Japanese or English, whatever the editor's language. Full-width ［］＝ and spaces count as half-width; letters in any case. The tag is not part of the name (a part and bone from 「arm [bone]」 are named "arm").

| 日本語 | English | 意味 / Meaning |
|---|---|---|
| `[骨]` | `[bone]` | 骨を作る（印の最初の言葉。これが無い角かっこは名前のまま） / make a bone (the tag's first word; brackets without it stay in the name) |
| `親=腕` | `parent=arm` | 親の骨の名前。無ければ、外側の印付きフォルダの骨、それも無ければ root / the parent bone's name; else the bone of the tagged folder around it, else root |
| `根元=上`（既定） | `root=top` (default) | 骨の始まる所：絵の上の中央から下へ向く / where the bone starts: the top middle of the picture, pointing down |
| `根元=下` | `root=bottom` | 下の中央から上へ / the bottom middle, pointing up |
| `根元=左` | `root=left` | 左の中央から右へ / the left middle, pointing right |
| `根元=右` | `root=right` | 右の中央から左へ / the right middle, pointing left |
| `根元=中`（`中央`） | `root=center` (`centre`, `middle`) | 絵の真ん中、向き無し（長さ 0） / the middle of the picture, no direction (length 0) |

- レイヤーに付けると、そのレイヤーがその骨で動く。フォルダに付けると、中のレイヤーが全部その骨で動き、中の印付きのレイヤーはその子の骨になる / On a layer: it moves with the bone. On a folder: every layer in it does; tagged layers inside become child bones
- 骨の長さは、根元から向いた方への絵の大きさ。向きと根元はエディタで後から直せる / The bone's length is the picture's size along its direction; both can be changed in the editor later
- 例 / Examples：`体 [骨 根元=下]`（フォルダ）の中に `上腕 [骨 根元=左]`・`前腕 [骨 親=上腕 根元=左]`、`Hair [bone]`、`Hand [Bone parent=前腕 root=Left]`
- 知らせ / Notes：分からない言葉（`psdBoneTagWord`）、無い親（`psdBoneParentMissing`、外側の骨か root に）、親が輪になる（`psdBoneParentCircle`、root に）、骨を作った数（`psdBones`、info）。「フォルダごとに骨」（`groupBones`）と一緒の時は印を使わない（`psdBoneTagsIgnored`）。`boneTags: false` で骨を作らない（印は名前から外す）

## ほかの名前の印（読まない・まとめる・メッシュ。Other name tags）

骨の印と同じ書き方（角かっこ、日本語でも英語でも、全角も可）で、次の印も書ける。いくつか続けて書いてよい（`腕 [骨] [メッシュ=四角]`）。印は名前に入らない。

Written like the bone tag (square brackets, Japanese or English, full-width allowed). Several can follow each other (`arm [bone] [mesh=quad]`). Tags are not part of the name.

| 日本語 | English | 意味 / Meaning |
|---|---|---|
| `[無視]` | `[ignore]` | 読まない。フォルダに付けると中のレイヤーも全部 / not read; on a folder, nothing in it is read |
| `[結合]` | `[merge]` | フォルダの中を描いた通りに重ねて 1 枚のパーツにする（合成モード・クリッピング・不透明度も）。パーツの名前はフォルダの名前、フォルダの不透明度はパーツの不透明度に / draws a folder's layers together into one part as the drawing app shows them (blend modes, clipping, opacity); the part takes the folder's name, the folder's opacity becomes the part's |
| `[メッシュ=格子]` | `[mesh=grid]` | そのレイヤーのメッシュを格子に / a grid mesh for that layer |
| `[メッシュ=輪郭]` | `[mesh=contour]` | 絵の輪郭に沿ったメッシュに / a mesh following the picture's outline |
| `[メッシュ=四角]` | `[mesh=quad]` | 4 点の四角に（動かさない小物に） / a 4-point rectangle (for small things that don't bend) |

- `[メッシュ=…]` をフォルダに付けると、中のレイヤー全部に。中のレイヤー自身の印が優先 / On a folder, for every layer in it; a layer's own tag wins
- 知らせ / Notes：読まなかったレイヤー（`psdTagIgnored`、info）、まとめたフォルダ（`psdTagMerged`、info）

## 分け方とフォルダ

| 描き方 | 読み込んだ後 |
|---|---|
| フォルダ | パーツのまとまり（グループ）になる。「PSD のグループを骨に」に印を付けると、フォルダごとに骨も作る |
| クリッピング（下のレイヤーでクリッピング） | 下のレイヤーの形の中だけに描くパーツになる（マスク） |
| 合成モード：乗算・スクリーン・加算（覆い焼き（リニア）） | そのまま使う |
| ほかの合成モード（オーバーレイ・ソフトライトなど） | 通常として描く（知らせが出る） |
| 同じ名前のレイヤー | 2 枚目から `_2`・`_3` を付けたパーツになる |
| 空のレイヤー | 読み飛ばす |

- 1 枚のレイヤーに離れた絵（両目など）を描くと、1 つのパーツとして一緒にしか動きません。左右の目は別のレイヤーにしてください
- 名前の無いレイヤーは `layer` になります。自動の道具が探せないので、名前を付けてください

## クリップスタジオと Photoshop

| | クリップスタジオ（CLIP STUDIO PAINT） | Photoshop |
|---|---|---|
| 書き出し | 「ファイル → 複製を保存 → .psd」または「画像を統合して書き出し」ではなく、レイヤーを残す保存にする | そのまま保存（.psd・.psb） |
| 用紙 | 「用紙」レイヤーが白い背景のパーツになる。要らなければ非表示か削除にしてから保存 | 「背景」レイヤーが背景のパーツになる |
| ベクターレイヤー・テキスト | 保存の時に絵になる | テキストは、PSD に入っている絵のまま読む |
| 色調補正レイヤー | 調整レイヤーとして焼き込んで読む（近いだけの物もある）。確かにするなら下に結合しておく | 同じ |
| レイヤー効果 | 「境界効果」などは描き込んで読む。確かにするならラスタライズしておく | 主な効果は描き込んで読む。確かにするなら「レイヤースタイルをラスタライズ」 |

クリップスタジオのフォルダは、そのままフォルダとして読みます。クリッピングも同じです。

## 自動の道具が効かない時

| 起きたこと | 直し方 |
|---|---|
| 「目のパーツが見つからない」 | 目の絵の名前に `目`・`白目`・`瞳`・`まぶた`・`eye` などを入れる |
| 「目の名前に左右が無い」 | レイヤーの名前か、入っているフォルダの名前に `左`・`右`（または最後に `L`・`R`）を入れる（`左目` フォルダなど） |
| 「上まぶたが無い」（目が潰れるだけ） | まつ毛・上まぶたを別のレイヤーにし、`まつ毛` や `上まぶた` の名前にする |
| 「口が 1 枚の絵」 | 上唇・下唇・口の中に分ける |
| 「口のパーツが見つからない」 | `口`・`唇`・`mouth` などを名前に入れる |
| 顔の向きで顔が大きく・小さく回る | 輪郭のレイヤーの名前に `顔` か `輪郭` を入れる（無い時は格子の中の全部の絵から大きさを決める） |
| 揺れ物の候補が出ない | 髪やリボンを名前の付いたフォルダに分け、「PSD のグループを骨に」に印を付けて開き直す |
| 頭ごと揺れる候補が出る | 頭の骨に、揺れない物（顔など）と揺れる物（前髪）が一緒に付いている。前髪を別のフォルダにする |

## 読み込む前に確かめる（`tools/psd_check.mjs`、2026-11-10）

描画アプリで直す物の一覧を、PSD を開く前に出す。エディタと同じように PSD を読み、自動の道具（目・口・揺れ物の候補）を当ててみるので、ここで出た物がそのまま上の表の「起きたこと」になる。

    node tools/psd_check.mjs 絵.psd

- 読み込みの知らせ（ラスタライズするレイヤー効果・調整レイヤー、通常で描く合成モード、大きいキャンバスなど）
- 名前の無いレイヤー（`レイヤー 1`・`layer` など）、同じ名前が 2 つ以上
- 1 枚のレイヤーに離れた絵（両目など）：一緒にしか動かない
- 目・口の道具の知らせ（左右・上まぶた・口が 1 枚など）、顔の絵が名前で見つからない
- **重なりの下が描かれていない**（`checkNotPaintedUnder`、2026-11-12、利用者の声：パーツ分け）：上のレイヤーの縁で、下のレイヤーがちょうど切れている所（前髪の下で額が切れている、あごの下で首が切れているなど）。上のレイヤーが動くと、そこに穴が見える。下のレイヤーを、上のレイヤーの下まで少し描き足す。間に別のレイヤーがあって穴が見えない所は出さない。上のレイヤーが動く物（髪・まぶた・唇・顔・頭・腕・手・耳）なら warn、ほかは info
- **よくあるパーツが名前で見つからない**（`checkPartMissing`、info）：顔のあるキャラで、前髪・後ろ髪・眉・白目・瞳・首のうち、名前で見つからない物を 1 行で
- 直す物が無ければ「nothing to fix」で終わりの値 0、あれば 1。`--json` で一覧をそのまま
- Photoshop の中で同じことをするパネルは、PC でしか確かめられないので後で（ハブに相談）
- 確かめ（`tests/psd_check_test.mjs`）：この文書どおりの顔（左目・右目のフォルダ、白目・瞳・上まぶた、口を 3 枚、顔、前髪）は直す物なし、目・口・顔が見つかる。両目を 1 枚・既定の名前・口 1 枚・顔なしの PSD は、それぞれ出る。額を前髪の縁で切った顔・あごで切った首は出て、下まで描いた物は出ない。よくあるパーツの足りない物（後ろ髪・眉・首）が 1 行で出る

知らせの一覧（エディタに出る文の元）は [警告の一覧.md](警告の一覧.md) にあります。読み込みのくわしい動きは [PSD.md](PSD.md) にあります。
