**著作権者は U5143**（2026-11-13、ユーザーの決定）。全部のファイルの `SPDX-FileCopyrightText` と `REUSE.toml`、MIT の全文の Copyright の行を `2026 U5143` にした（C・C++ も同じ表記で ASCII）。

## 先頭の行の書き方

どの言語でも、ファイルのいちばん先頭（`#!` の行や `<!doctype html>` がある時はその次）に 2 行を書く。ライセンスの名前は SPDX の書き方（`MIT`・`CC0-1.0`・`CC-BY-4.0`）。

C・C++・GLSL のファイル（`.c`・`.h`・`.cpp`・`.glsl` など）：
<!-- REUSE-IgnoreStart -->（ここから下の例の行は、この文書自身のライセンスではない）
```c
/* SPDX-FileCopyrightText: 2026 U5143
 * SPDX-License-Identifier: MIT */
```
C・C++ のファイルは、著作権者の表記も ASCII にする（`U5143` は ASCII なので、そのまま）。日本語の Windows の MSVC は、`/utf-8` を付けないとソースを CP932 として読み、日本語に C4819 の警告を出すため。芯のヘッダーを自分のプロジェクトに入れる人にも、この警告が出ないようにする。

JavaScript（`.js`・`.mjs`）・C#・GDScript 以外の `//` で書ける言語：
```js
// SPDX-FileCopyrightText: 2026 U5143
// SPDX-License-Identifier: MIT
```
JS の中の GLSL（テンプレート文字列のシェーダー）は、JS のファイルの行で足りる。シェーダーを別のファイルにする時は、`#version` の次の行に `//` の 2 行を書く（`#version` は先頭でないといけないため）。

CMake・シェル・GDScript・Python・YAML（`#` で書く物）：
```cmake
# SPDX-FileCopyrightText: 2026 U5143
# SPDX-License-Identifier: MIT
```
シェルのように `#!` で始まる物は、その次の行から。

HTML（`<!doctype html>` の次の行）・Markdown（先頭）：
```html
<!-- SPDX-FileCopyrightText: 2026 U5143 -->
<!-- SPDX-License-Identifier: MIT -->
```

コメントを書けない物（`.wasm`・画像・`.ugo`・JSON・PSD など）は、ルートの `REUSE.toml` に場所を足す：
```toml
[[annotations]]
path = ["tests/psd/face.psd", "tests/psd/**.png"]
precedence = "aggregate"
SPDX-FileCopyrightText = "2026 U5143"
SPDX-License-Identifier = "MIT"
```
<!-- REUSE-IgnoreEnd -->

道具が作るファイル（`tools/make_sample.mjs` の見本、`tests/warp/make_model.mjs` のデータなど）も、作られた場所を `REUSE.toml` に書いておく。

## 配る時

ビルドした物（`ugo.wasm`・共有ライブラリ・`ugo_export`・エンジンのプラグインの zip）には、`LICENSES/MIT.txt` を一緒に入れる。CI の成果物に足すのは、GitHub Actions の枠が戻ってから。
