# 調査：キーフォームの操作（Live2D Cubism Editor と Spine）

エディタの「キーフォームの編集」を作るための調べ物。公式のマニュアルだけを読んだ（Live2D は日本語版 Cubism Editor 5 マニュアル、Spine は公式ユーザーガイド。サンプルモデル・SDK・ランタイムのコードは読んでいない）。確認日 2026-10-30。画面や名前をそのまま真似ず、考え方を参考にする。

## Live2D 1. キーの追加・移動・削除

出典：https://docs.live2d.com/cubism-editor-manual/edit-parameters/ ・ https://docs.live2d.com/cubism-editor-manual/palametorpalatte/ ・ https://docs.live2d.com/cubism-editor-manual/palametor-modifyication/

- キーは「オブジェクト（アートメッシュかデフォーマ）× パラメータ」ごとに持つ。対象とパラメータを選んでから操作する
- 追加：「2 点追加」は最小と最大、「3 点追加」は最小・中間・最大にキーを入れる
- 手で編集：パラメータ名のダブルクリックなどで編集のダイアログを開き、目盛りのクリックで任意の値にキーを入れる、値の欄でキーの位置を変える。OK で確定
- スライダーの小窓：今の値にキーを 1 点作る（＋）、選んだキーを消す（−）、数値を直接入れる。スライダーで作ると端数になりやすいので、ダイアログで直すよう注意がある
- 既にあるキーの値を別の値へ移す・入れ替える「調整」、キーの値を逆向きにする「反転」（複数のパラメータを一括でも）
- 削除：選んだオブジェクト × パラメータのキーを全部消す。どのオブジェクトにもキーの無いパラメータを消す
- キーが 1 点だけだと、その値でしか表示されない。両端にもキーを置くよう勧めている

## Live2D 2. キーの上で形を作る流れ・キーの間

出典：https://docs.live2d.com/cubism-editor-manual/keyform-xydirection/ ・ https://docs.live2d.com/cubism-editor-manual/palametor/ ・ https://docs.live2d.com/cubism-editor-manual/how-to-edit/

- スライダーをキーの値（-1・0・1 など）に合わせてから、デフォーマや頂点を動かす。その形がそのキーのキーフォームになる
- 編集の道具：頂点の選択（矢印・投げ縄・ブラシ）と移動・回転・拡縮、全体の枠での変形、ワープデフォーマの点、元の形に戻す
- キーとキーの間は自動で補間して表示する
- キーの間で編集しようとした時（止める・警告・キーを自動で作る）の扱いは、読んだページには書かれていない（未確認）。今の値の印が「キーフォームの無い値」か「有る値」かで変わることだけ書かれている。キーの外では形を編集できない扱いと思われる（推測）

## Live2D 3. 2 つのパラメータの組み合わせと自動生成

出典：keyform-xydirection・palametorpalatte・ https://docs.live2d.com/cubism-editor-manual/synthesize-corners/ ・ https://docs.live2d.com/cubism-editor-manual/inversion-of-movement/ ・ https://docs.live2d.com/cubism-editor-manual/face-auto-edit/ ・ https://docs.live2d.com/cubism-editor-manual/blend-shape/ ・ https://docs.live2d.com/cubism-editor-manual/multi-key/

- 組み合わせ：X に 3 点、Y に 3 点なら 3 × 3 = 9 のキーフォーム（掛け算の格子）
- パラメータの結合：2 つのパラメータを 1 つの XY の面（9 点の格子）にまとめて表示する。表示だけでキーは変わらない。Shift で 1 軸に固定
- 1 つのオブジェクトに付けたパラメータの数の検査：3 つで黄、4 つ以上で赤（格子が大きくなりすぎる注意）
- ブレンドシェイプ：掛け算にしない方式。既定の形との差を足すので、組み合わせの形が要らない
- 四隅の自動生成：上下左右の 4 方向を先に作ってから実行する。設定はパラメータ 2 つ、基準（既定値か中央）、上書きする隅。手直しが要ることがあり、実行し直すと手で直した形は消える
- 動きの反転：片側の形を反転して反対側のキーに書き込む（焼き込み）。ワープデフォーマに入れ、3 点キーを打ち、片側を作ってから。軸はデフォーマの中心で、既定値を中心に水平か垂直に反転。鏡写しが続くわけではなく、直したら実行し直す
- 顔の動きの自動生成：顔のデフォーマを作り、角度 X・角度 Y と四隅を自動で作る。量と変形の度合いを調整できる。正面向きの顔が対象
- マルチキー編集：格子の複数のキーを選び、描く順・不透明度・乗算色・スクリーン色をまとめて書き換える（形は対象外）

## Live2D 4. キーの見せ方

出典：edit-parameters・palametorpalatte・blend-shape

- スライダーの点：キー＝緑、今の値＝黒（＋で緑に）、選んだキー＝赤い枠、ダイアログで入れたキー＝赤
- オブジェクトを選んでいる・いないでキーの表示が変わる。複数を選んでキーフォームがそろわない時は黄
- 今の値の印は、キーフォーム無し・有り・リピートの 3 通り（色は画像だけで、本文に説明なし。未確認）
- 右クリックで近くのキーに吸い付いて選べる。ブレンドシェイプのキーは四角。結合した面の線は、両方キーあり＝黒の実線、両方なし＝黒の破線、片方だけ＝緑の破線

## Spine 5. メッシュの変形（deform）キー

出典：https://esotericsoftware.com/spine-meshes ・ https://esotericsoftware.com/spine-keys

- セットアップのモードで頂点を動かすと基準の形が変わり、アニメーションのモードで動かすと変形のキーになる
- キーの打ち方：アタッチメントの横のキーのボタン、K（変えた所をまとめて）、自動キー（変えるたびに）。キーを打たずに時間を動かすと変更は消える。ボタンの色：緑＝この時間にキー無し、橙＝変えたが未設定、赤＝キーあり
- 変形のキーはアタッチメントの全頂点で 1 つ。一部だけ別に動かすのは難しい。頂点の位置だけを持ち、キーの間は直線で補間。動かした頂点はピンクで表示
- 重み付きのメッシュ：骨（重み）で動かし、変形のキーは控えめにするよう勧めている。変形のキーは頂点ごとに影響する骨の数だけ位置を持つ（データが重い）。後で頂点を足すと全部のキーを直す必要がある
- メッシュの作り直し（Reset・Generate・Trace など）で重みと変形のキーが消える。リンクメッシュは元のキーを引き継げる
- Live2D との違い：Spine のキーは時間の上（アニメーションごと）、Live2D のキーフォームはパラメータの値の上（複数のパラメータは掛け算の格子）。Live2D の時間の動きは、パラメータを別の段階で動かして作る

## Ugo9 のエディタへの提案（ハブ）

- Ugo9 は両方を持っている：「組み立て」モードはパラメータの上のキーフォーム（作業用 JSON の deformers と範囲）、「アニメ」モードは時間の上のキー（animations のトラック）。この 2 つを画面の上ではっきり分ける
- キーの間で形を動かした時は、黙って捨てず、「ここにキーを作る」を出すなど、Live2D より分かりやすくできる
- Ugo9 の範囲は 2 軸の積で「角だけの補正」を持てる（docs/形式.md）。四隅の自動生成は「4 方向の和との差を角に入れる」形で作れる見込み（推測）
- 反転は焼き込み（一度だけ写す）にするか、鏡写しを持ち続けるかを選べると便利（推測）
- 1 つのオブジェクトにパラメータが増えすぎる注意（格子の大きさ）は Ugo9 にも要る。Ugo9 は差分の足し算なので、Live2D のブレンドシェイプに近く、格子の掛け算になりにくい
