# 調査：エディタの画面の作り（Live2D Cubism Editor／Spine／Blender）と Ugo9 への当てはめ

- 目的：Ugo9 の画面を「どこに何があるか」がいつも分かる形にする。案内役（ウィザード）や自動の誘導は使わない。
- 調べ方：公式のページだけを開いて読んだ（2026-11-03）。位置などページの文に無い物は（推測）と書く。ランタイム・SDK・サンプルのコードは読んでいない。
- 使い方：画面の並びや名前をそのまま真似ず、「どこに何があるか分かる」ための考え方（5 節）を参考にする。6 節の案は、ユーザーが選ぶまで決まりではない。
- 本文の (L3) (S4) (B2) などは、1 節の番号のページを指す。

## 2. Live2D Cubism Editor の画面の作り

**メニューバー（9 つ）** (L2)
- ファイル：新規作成（モデル／アニメーション）、ファイルを開く、前回開いたファイルを開く、最近開いたファイルを開く、閉じる、保存、別名保存、画像/動画書き出し（画像・GIFアニメ・静止画(連番)・PSD画像(β)・動画）、組み込み用ファイル書き出し（moc3・物理演算設定・モーションファイル）、環境設定、キーボードショートカット、キャンバス設定、終了 など (L5)
- 編集：元に戻す、やり直す、切り取り、コピー、貼り付け、削除、パラメータ値をコピー／貼り付け、選択を解除、すべて選択、検索と置換 (L6)
- 表示：グリッド、ガイド、アートメッシュの頂点を表示、親デフォーマからはみ出した頂点をハイライト、重なったポリゴンをハイライト、選択オブジェクトをフォーカス、表示品質、オニオンスキン、トラックの軌道 など (L9)
- モデリング：デフォーマ（作成・自動生成・検証）、パラメータ（パラメータ設定・四隅のフォームを自動生成・動きの反転・顔の動きを自動生成・揺れの動きを自動生成 など）、アートメッシュ（メッシュ編集・メッシュの自動生成）、アートパス、グルー、スキニング、フォームの編集、一時変形ツール、クリッピング、モデルテンプレート、テクスチャアトラス、ロック、表示/非表示、編集レベル、物理演算設定 など (L7)
- アニメーション：素材、シーン、トラック（各種ベイク・音声からリップシンク）、タイムライン<インジケーター>（1フレーム／1キーフレーム戻る・進む など）、タイムライン、フェード、パラメータコントローラ、マーカーを追加、再生、編集モードの切り替え（ドープシートとグラフエディタ） など (L8)
- フォームアニメーション（FA）、メッシュ編集モード：名前のみ確認 (L2)
- ウィンドウ：ワークスペース（モデリング／アニメーション／フォームアニメーション、現在のレイアウトをリセット、ワークスペース設定）、パレットを隠す／表示する、パレットの表示切り替え（デフォーマ・インスペクタ・ツール詳細・ログ・パラメータ・パーツ・プロジェクト・タイムライン・シーン・テンプレート） など (L10)
- ヘルプ：使い方マニュアル、サンプルモデル、動画チュートリアル、ホーム、ライセンス関係、操作を可視化、ログファイルを開く、更新履歴 など (L11)

**ワークスペース** (L3)
- 作業ごとに保存された画面の並び。既定は 3 つ：モデリング（変形とキーフォームを作る）、アニメーション（シーンを作り、タイムラインにキーフレームを置く）、フォームアニメーション（モデルのデータを変えずに形を直接直す）。
- 切り替え：エディタの左上に今のワークスペースが出ていて、そこで選ぶ。ビューエリアのタブを選ぶと自動で切り替わる（既定でオン。環境設定で止められる）。
- ウィンドウ ＞ ワークスペース ＞ 現在のレイアウトをリセット で最初の並びに戻る。既定 3 つの最初の並びは変えられない。
- 古いチュートリアルでは、左上の [Modeler][Animator] のアイコンで切り替えると書かれている (L21)。

**パレット（パネル）と位置**
- パレットはタブで重ねる・間に差し込む・外に浮かせることができる。橙色の線や枠が落とし先を示す。表示・非表示はウィンドウメニューかタブの右クリック (L12)。
- 位置について文で確かめられたのは 2 つだけ：タイムラインパレットは「画面下」、ワークスペースの切り替えは「左上」(L21)(L3)。他のパレットの既定の位置は本文に無い（画面写真のみ）。
- パーツパレット：パーツ（フォルダ）ごとにオブジェクトを PSD の重なり順で並べ、種類のアイコン・名前・描画順を出す。目（表示）と鍵（ロック）。描画順の数値が並び順より優先 (L14)。
- デフォーマパレット：親子関係の木。同じ親の子の並べ替えはパーツパレットで行う (L15)。
- インスペクタパレット：選んだ物の設定。アートメッシュなら名前・ID・パーツ・デフォーマ・クリッピング・描画順・不透明度・乗算色・スクリーン色・カラーブレンド・アルファブレンド など。選んだ物の種類で項目が変わる (L16)。
- パラメータパレット：パラメータ 1 つにつき 1 本のバー（名前・スライダー・今の値）。キーはスライダー上の点。「キーの2点追加」「キーの3点追加」「すべてのキーを削除」「キーの手動編集」。グループ（1 段）に分けられる。「絞り込み」で選んだ物にキーがあるパラメータだけ出す (L13)。
- タイムラインパレット：A 再生とタイムラインの移動、B トラックとプロパティ（「Live2D パラメータ」の行）、C タイムライン（インジケーター・ワークエリア・キーフレーム）。ドープシートとグラフエディタをボタンで切り替え。補間はリニア・自動スムーズ・ステップ・ベジェ など (L18)。
- ツール詳細パレット：選んだツールの設定だけを出す。ツールを変えると中身が変わる (L20)。
- ビューエリア：モデルを出す場所。モデリング／アニメーション／FA のビューがあり、それぞれタブで複数開ける (L17)。
- ログパレットがある（名前のみ確認）(L2)(L10)。

**ツールバー（ツールパレット）** (L4)
- どのワークスペースでも出る物：ターゲットバージョン選択、ワークスペース切り替え、編集レベル切り替え、ホーム。
- モデリングだけの物（13 個）：テクスチャアトラス編集、メッシュの手動編集、メッシュの自動生成、ワープデフォーマの作成、回転デフォーマの作成、回転デフォーマ作成ツール、矢印ツール、投げ縄選択ツール、ブラシ選択ツール、変形パスツール、変形ブラシツール、グルーツール、アートパスツール。
- アニメーションだけの物（2 個）：選択・編集ツール、パラメータコントローラツール。2 つのワークスペースで同じツールは無い。
- 編集レベル 1／2／3（キー 1・2・3）で、見せる制御点の細かさを変える。既定は 2 (L19)。

**キーフォームとパラメータの見せ方**
- キーはパラメータ上の点で形を覚える。その形を「キーフォーム」と呼ぶ。パラメータは変形や位置を覚える (L22)。
- 流れ：オブジェクトを選ぶ → パラメータにキーを足す（2 点／3 点）→ スライダーをキーに合わせてビューで形を直す＝そのキーのキーフォームになる (L13)（手順の並べ方は（推測）。各ボタンの働きは確認済み）。
- アニメーションでは、タイムラインの「Live2D パラメータ」の行でスライダーを動かすと、その時刻にキーフレームが置かれる (L21)。つまり「形はパラメータのキーフォーム」「時間の動きはパラメータの値のキーフレーム」の 2 段。

## 3. Spine の画面の作り

**メインメニュー**（左上の Spine のロゴ、または alt+F）(S2)
- 開く・保存・インポート／エクスポート・設定。確認できた項目名：Open Project、Recent project、Import Project、Import Data、Import PSD、Export（ctrl+E）、Settings（F12）(S2)(S14)(S15)(S16)(S17)。
- ロゴの横（タイトルバー）に、開く・保存・アンドゥ・リドゥ・ウェルカムスクリーンのボタン (S2)。
- 書き出しの種類：データ（JSON・Binary）、画像（GIF・PNG・APNG・PSD・JPEG）、動画（AVI・MOV）(S14)。

**2 つのモード**（日本語版の名前は「設定モード」「アニメ化モード」）(S2)
- 切り替えはビューポート左上のアイコン。設定モードはスケルトンを作って整える。アニメ化モードはアニメを作る。
- 設定モードの既定：左にビューポート、右にツリービュー。アニメ化モードの既定：下にグラフビュー、その隣のタブにドープシートビュー。
- アニメ化モードの方が開けるビューが多い (S2)。

**メインツールバー**（ビューポートの下）(S2)(S3)
- ツールと切り替えキー：Pose（B）、Create（N）、Weights（G）、Rotate（C）、Translate（V）、Scale（X）、Shear（Z）。
- 専用の選択ツールは無い。クリックで選び、ctrl でまとめて選ぶ（スマートな選択）。
- ビューポートで右クリックすると、今のツールと前のツールが入れ替わる。
- Create（ボーン作成）は設定モードだけ。
- ほかに：軸（Local／Parent／World）、Compensation（Images／Bones）、自動キー（Auto key）、ビューポートオプション（ボーン・領域とメッシュ・その他の、選択可否／表示／名前の表示）。

**ビュー（パネル）**
- 右上の「Views」選択ボックスから開く。閉じたビューもここから戻せる。開いている物は薄い灰色 (S2)(S7)。
- タブを引いて動かす。橙色の四角が落とし先。端を引いて大きさを変える。最小化（F9 で全部）。ウィンドウの外には出せない (S7)。
- ツリービュー：スケルトンと中身の全部を階層で出す（ボーン・スロット・描画順・スキン・コンストレイント・アニメーション・イベント）。選んだ物のプロパティはツリーの下に出て、右上に複製・名前変更・削除。上に検索欄（F3 で次へ）とフィルター (S2)(S4)。
- ドープシート：キーの時刻だけを多く並べる。ボーンごとに行をまとめる。キーの線の形で補間が分かる（直線＝リニア、曲線＝ベジェ、点線＝ステップ）(S5)。
- グラフ：時刻と値の両方。曲線の種類は Stepped・Linear・Bezier、ベジェのプリセットあり (S6)。
- アニメーションビュー：アニメの一覧。クリックで今のアニメにする。新規作成のアイコン (S21)。
- ほか：タイムライン（ビューポートの下に置ける）、再生（FPS・速度・Stepped・Interpolated）、ウェイト、メッシュツール、スキン など (S1)(S20)(S22)。

**スキン・コンストレイント・物理の置き場所**
- スキン：ツリーの「Skins」で New… ＞ Skin。複数を同時に見るのはスキンビュー (S12)。
- コンストレイント：ツリーの「Constraints」の下に並び、上から順にかかる。設定モードで順番を変えられる (S9)。
- IK：ボーンを選び、ツリーのプロパティの New… ＞ IK Constraint (S10)。
- 物理：ボーンを選び、ツリーのプロパティの New… ＞ Physics Constraint。慣性・強さ・減衰・重さ・風・重力 など (S11)。
- メッシュ：ツリーのプロパティの「Edit Mesh」で編集に入る。Modify／Create／Delete、New、Reset、Generate、Trace (S18)。
- ウェイト：ウェイトビューの Bind でボーンを結ぶと、最初は自動で重みが付く。Weights ツールで塗る。Auto・Smooth・Prune (S13)。

**キーの打ち方** (S8)
- アニメ化モードで、今のアニメを選んでから。
- 回転などは、ツールバーの数値の横のキーボタン。それ以外（スロットの色・描画順・デフォーム など）はツリーのキーボタン。
- キーボタンの色：緑＝この時刻にキーが無い、橙＝変えたがまだキーにしていない、赤＝キーがある。
- K で変えた物を全部キーにする。Auto Key をオンにすると変えるたびにキーが付く。
- ボーンのキーはセットアップのポーズからの差で持つ（ポーズを直すとアニメも変わる）。

**ツールチップ・ショートカット**
- 設定の Behavior で Tooltips を切れる。切っても F1 で出せる。インターフェースの大きさも変えられる (S17)。
- ホットキーは全部変えられる (S2)(S17)。

## 4. Blender の画面の作り（「どこにあるか分かる」仕組みを中心に）

**全体は 3 段** (B1)
- 一番上の Topbar（メインメニュー：保存・読み込み・書き出し・設定・レンダリングなど）、真ん中の Areas（作業場所）、一番下の Status Bar（ショートカットの手がかりと統計を出す）。

**Topbar のメニュー** (B2)
- Blender：Splash Screen、About Blender、Install Application Template。
- File：New、Open、Open Recent、Revert、Recover、Save、Save As…、Save Copy…、Save Incremental、Link…／Append…、Import、Export、External Data、Clean Up、Defaults、Quit。
- Edit：Undo・Redo・Undo History、Adjust Last Operation・Repeat Last、Menu Search、Operator Search、Rename Active Item、Batch Rename、Preferences。
- Render：Render Image（F12）、Render Animation（Ctrl-F12）、Render Audio、View Render、View Animation など。
- Window：New Window、Toggle Window Fullscreen、Next／Previous Workspace、Show Status Bar、Save Screenshot など。
- Help：Manual、Support、User Communities、Release Notes、Report a Bug、Save System Info など (B12)。
- Topbar には、ほかにワークスペースのタブと、シーン／ビューレイヤーの選択がある (B2)。

**ワークスペース（Topbar のタブ）** (B3)
- 作業向けに決めた画面の並び。タブをクリックで切り替え。Ctrl-PageUp／PageDown で前後へ。
- 既定の Layout：左上 3D Viewport、右上 Outliner、右下 Properties、左下 Timeline。
- ほかに Modeling、Sculpting、UV Editing、Texture Paint、Shading、Animation（物の値を時間で変える）、Rendering、Compositing、Geometry Nodes、Scripting。追加で 2D Animation など。

**エディタとヘッダー** (B4)(B5)(B6)
- どの場所にもどのエディタでも置ける。ヘッダーの一番左の「Editor Type」で中身を変える (B5)。
- すべてのエディタにヘッダーがあり、メニューとよく使う道具を持つ。中身はエディタの種類・選んだ物・モードで変わる (B4)。
- 3D Viewport のヘッダー：Mode（Ctrl-Tab）、View、Select、Add（Shift-A）、Object（モードで変わる）(B6)。
- Outliner：ファイルの中身を木で出す。選ぶ・隠す・親子を整える (B16)。
- Properties：左の縦のアイコン（タブ）で、ツール・シーン・物・素材などの設定を切り替える (B15)。
- Dope Sheet：キーフレームを時間の軸に並べて一望する。ヘッダーでモードを選ぶ (B17)。

**Toolbar（T）と Sidebar（N）** (B4)(B7)(B8)(B9)
- Toolbar はエディタの左。T で出し入れ。中身はモードごとに違う (B4)(B7)。
- ツールに少し乗せると名前、長く乗せると全部の説明が出る。右下に三角のある物はツールのまとまり（長押しで開く）(B9)。
- Shift-Spacebar でカーソルの所に小さなツールバー。右に切り替えキーが出る (B9)。
- Sidebar はエディタの右。N で出し入れ。Item（位置など）・Tool（今のツールとワークスペースの設定）・View のタブ (B4)(B8)。
- ツールの設定は 3 か所で同じ物を出す：Sidebar の Tool、Properties の Active Tool タブ、ヘッダーの下の Tool Settings (B9)。
- 操作の直後に、その操作の数値を直せる「Adjust Last Operation」(F9) が出る (B4)(B10)(B14)。

**名前で探す：Menu Search（F3）** (B10)
- Edit ＞ Menu Search。名前の一部を打つと操作が絞られ、そのまま実行できる。

## 5. 3 つに共通する「どこに何があるか分かる」ための決まり

1. **一番上に固定のメニュー。名前は作業の種類で分ける。** Live2D はファイル／編集／表示／モデリング／アニメーション／ウィンドウ／ヘルプ (L2)。Blender は File／Edit／Render／Window／Help (B2)。Spine はロゴの 1 つのメニュー (S2)。
2. **大きな作業の切り替えは 1 か所で、左上か上の端。** Live2D は左上の切り替え (L3)、Spine はビューポート左上のアイコン (S2)、Blender は Topbar のタブ (B3)。
3. **切り替えるとツールとパネルの並びが変わるが、メニューの場所は変わらない。** Live2D のツールはモデリング 13 個・アニメーション 2 個で重ならない (L4)。Spine の Create は設定モードだけ (S3)。Blender のワークスペースは並びの保存 (B3)。
4. **「構造の木」と「選んだ物の設定」は、それぞれ 1 か所。** Live2D はパーツ／デフォーマの木＋インスペクタ (L14)(L15)(L16)。Spine はツリー＋その下のプロパティ (S4)。Blender は Outliner＋Properties (B16)(B15)。
5. **ツールの細かい設定は、ツールとは別の決まった場所に出る。** Live2D のツール詳細パレット (L20)、Blender の Tool Settings／Sidebar の Tool (B9)。
6. **閉じたパネルを必ず戻せる。並びを最初に戻せる。** Live2D のウィンドウ ＞ パレットの表示切り替え／現在のレイアウトをリセット (L10)(L12)、Spine の Views 選択ボックス (S7)。
7. **時間（アニメ）は画面の下。ドープシートとグラフは同じ場所でタブ。** Live2D のタイムラインは画面下で、ドープシート⇔グラフをボタンで切り替え (L21)(L18)。Spine はグラフが下、隣のタブにドープシート (S2)。Blender の Layout は左下に Timeline (B3)。
8. **ショートカットはメニューとツールチップに書く。キーは変えられる。** Blender のメニュー項目とツールチップ (B11)(B12)、Spine の F1 ツールチップ (S17)、Live2D はファイル ＞ キーボードショートカット (L5)。
9. **名前で探す道を 1 つ置く。結果に「どのメニューにあるか」を出す。** Blender の F3 Menu Search (B10)。Spine のツリー検索 (S4)、Live2D の 編集 ＞ 検索と置換 (L6) はオブジェクトを探す物。これは誘導ではなく、引ける索引。
10. **自動で作る機能は、その対象のメニューの中に置く（別の案内画面にしない）。** Live2D の モデリング ＞ パラメータ ＞ 顔の動きを自動生成／揺れの動きを自動生成、アートメッシュ ＞ メッシュの自動生成 (L7)。Spine のメッシュの Generate／Trace はメッシュの編集の中 (S18)。
