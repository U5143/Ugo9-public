# 動きを別のモデルへ写す（`tools/copy_animation.mjs`、2026-11-10、利用者の声 #23）

あるモデルの作業用 JSON のアニメを、別のモデルへ写す。パラメータ・骨・パーツ・差分・色・制約を名前（id）で合わせ、相手のモデルに合わせて値を直す。

```
node tools/copy_animation.mjs 元.json 先.json --out 結果.json [--anims idle,walk] [--existing rename|replace|skip] [--no-remap] [--no-scale] [--add-bones] [--add-params]
    [--map 元=先,...] [--map-file 対応.json] [--auto-map]
node tools/copy_animation.mjs --template 元.json --out 名前.anim.json [--anims walk,run]
```

元・先・テンプレートの元には `.ug9` も渡せる（作業用 JSON に戻して読む、`tools/import_ug9.mjs`）。

```js
import { copyAnimations } from './tools/copy_animation.mjs';
const { model, notes, copied } = copyAnimations(from, to, { anims: ['idle'] });
```

- **パラメータ**：元の範囲から先の範囲へ、既定の値を境に上と下で別々に割合で移す（AngleX が −30〜30 から −45〜45 なら 10 は 15。−60〜15 なら −10 は −20、10 は 5）。`remapParams: false`（`--no-remap`）でそのまま
- **骨の移動（x・y）**：2 体の大きさの比を掛ける。両方の骨に長さがあればその比、無ければキャンバスの高さの比。回転・拡大・せん断はそのまま。`scaleMoves: false`（`--no-scale`）でそのまま
- 不透明度・描画順・色・制約の mix はそのまま
- 曲線のキー（形式 1.1）の値の手は、値と同じに直す
- 先のモデルに無い物は写さず、名前を挙げて知らせる（`copyMissing`）。次の 2 つで一緒に持ってこられる
- 同じ名前のアニメがある時：`rename`（既定、`idle_2` のように）・`replace`（置き換える）・`skip`（写さない）
- 渡したモデルは変えない（結果は新しいモデル）。エディタのメニューに出すのはエディタの担当

## 足りない骨・パラメータも持ってくる（2026-11-10、機能の比べ #79）

- `addBones: true`（`--add-bones`）：アニメが動かす骨が先に無い時、その骨と、先にある骨まで（無ければ一番上まで）の親を、親から順に足す。親は id で先の骨に付く。場所（x・y）と長さは骨の移動と同じ比（キャンバスの高さの比）で直す。回転などはそのまま。足した骨にはウェイトが無いので、絵は付いてこない（お知らせ `copyBonesAdded`）。先に無いワープ格子の中の骨は持ってこない（`copyBoneNoWarp`）
- `addParams: true`（`--add-params`）：アニメが動かすパラメータが先に無い時、元の範囲のまま足す（`copyParamAdded`）
- 結果に `addedBones`・`addedParams`（足した id の並び）

## パラメータの ID が違う時の対応表（2026-11-13、要望シート 11/10）

元と先でパラメータの ID が違う時（`ParamAngleX` と `HeadTurnX` など）、どれをどれに写すかを決められる。値は上と同じに、元の範囲から先の範囲へ移す（曲線の手も）。

- `paramMap: { 元の ID: 先の ID }`（`--map 元=先,元=先`、または `--map-file 対応.json` に `{ "元": "先" }`）。先を `null`（`--map 元=`）にすると、そのトラックは写さない（知らせも出さない）
- `paramMap: 'auto'`（`--auto-map`）：下の候補をそのまま使う
- 写した組は知らせる（`copyParamMapped`、info）。2 つのトラックが同じ先へ行く時は、先の方を残して知らせる（`copyParamTwice`）
- **候補を出す**：`suggestParamMap(元, 先)`（`tools/param_map.mjs`、ブラウザでも動く。エディタの対応表の画面が使う） → `{ map, how, unmatched }`。アニメが動かすパラメータごとに、この順で探し、先の ID は 1 回だけ使う
  1. 同じ ID（`same`）
  2. 標準の名前と前の名前（`HeadTurnX` と `AngleX`、`PupilX` と `EyeBallX` など、`tools/lib/paramnames.js` の表。`standard`）
  3. 頭の `Param` を付けた・外した名前と、その標準・前の名前（`ParamAngleX` → `AngleX` → `HeadTurnX`。`prefix`）
  4. 大文字小文字・`_`・`-`・`Param` を除いて同じ文字、または 2 文字以内の違いで一番近い物が 1 つだけ（5 文字以上の名前。`similar`）
  5. 見つからない物は `unmatched`
- Live2D の書き出したファイル（motion3.json など）を読む道は作らない（このプロジェクトの決まり）。外のアニメは、作業用 JSON か `.ug9` にしてから写す
- 確かめ（`tests/param_map_test.mjs`）：候補（Param 付き・標準と前の名前・文字の違い・近い綴り・見つからない物）、先の ID は 1 回、写した値の範囲と曲線の手、`null` で外す、`'auto'` は候補と同じ、同じ先へ 2 つは先の方、コマンドの `--map`・`--map-file`・`--auto-map`

## アニメのテンプレート（2026-11-10、機能の比べ #81）

アニメの組を 1 つのファイルに保存して、後で別のモデルへ当てる。

```js
import { makeTemplate, copyAnimations } from './tools/copy_animation.mjs';
const tpl = makeTemplate(model, { anims: ['walk', 'run'] });   // 保存する
copyAnimations(tpl, other, { addBones: true, addParams: true });   // 当てる
```

- テンプレートは作業用 JSON そのもの（新しい形式ではない）：キャンバス（大きさの比のため）、アニメが動かすパラメータ、動かす骨とその親、パーツは空、アニメ。なので `copyAnimations` やエディタで、ほかのモデルと同じに読める。名前は `名前.anim.json` を勧める
- 骨はワープ格子の印を外して入れる（テンプレートには格子が無い）

確かめたこと（`tests/copy_animation_test.mjs`）：同じモデルを 2 倍にした物（`tools/scale_model.mjs`）へ写すと、2 倍にしたモデルのアニメと JSON も .ug9 も同じ。範囲の違うパラメータ・無い物・同じ名前の 3 つの扱い。尾（骨 2 本とパラメータ）を 2 倍のモデルへ：足さない時は 3 つ知らせて外す、足す時は親から順に体に付き、場所と長さが 2 倍、トラックが残り、コンパイルが通る。先に tail1 がある時は tail2 だけ。テンプレートは使う物だけを持ち、保存して読んだ物を当てると元のモデル全体から写すのと同じ JSON。コマンド（.ug9 からのテンプレートも）。

## 物理を足す（`tools/copy_physics.mjs`、2026-11-13、利用者の声 #26）

別のモデルの物理（揺れるパラメータの `physics`）と骨の鎖（`chains`）を、今のモデルに 1 つずつ足します。今のモデルにある物は上書きしません（「読み込むと今のグループが全部上書きされる」への対応）。

- 物理は出力のパラメータで見分ける。同じ出力を今のモデルが揺らしていれば、今の物を残して知らせる（`--replace` で持ってきた物に替える）
- 入力・出力の ID は同じ名前のまま。違う時は、アニメと同じ対応表（`--map`・`--map-file`・`--auto-map`）で合わせる
- 範囲が違えば、同じ動きで同じに揺れるように直す。入力の重みは範囲の幅の比（-30..30 → -45..45 なら 2/3 倍）、gain は出力の範囲の幅の比、min・max はアニメの値と同じ決まりで写す（`--no-remap` で直さない）
- 入力のパラメータが無い時は、その入力を外して知らせる。出力が無い時、入力が 1 つも無い時は持ってこない
- 骨の鎖は ID で見分け、骨が全部ある時だけ持ってくる。骨が別の鎖で揺れていれば持ってこない（1 本の骨は 1 つの鎖だけ）。重力はキャンバスの高さの比で直す（`--no-scale` で直さない）
- `--only 出力または鎖の ID,...` で選ぶ。`--no-physics`・`--no-chains` で片方だけ

```
node tools/copy_physics.mjs 元.json 今.json --out 出力.json [--only HairSideSway,hairL] [--replace] [--auto-map]
```

エディタからも import できる（Node の物はコマンドの時だけ読む）。`copyPhysics(from, to, opts)` は `{ model, notes, physics, chains }` を返す。知らせの code：`copyPhysicsKept`・`copyPhysicsReplaced`（`{id}`）、`copyPhysicsMissing`（`{id, kind, missing}`、kind は parameter・input・bone）、`copyPhysicsInputLeft`（`{id, input}`）、`copyPhysicsBoneTaken`（`{id, bone, chain}`）、対応表は `copyParamMapped`。

確かめたこと（`tests/copy_physics_test.mjs`）：ID と範囲の違うモデルへ持ってきた物理を芯で 120 コマ動かすと、出力が元の出力を新しい範囲に写した値と一致する（差 1e-6 以下）。今の物理・鎖は残る（`--replace` で替わる）。足りない入力・出力・骨、別の鎖の骨はそれぞれ知らせる。重力はキャンバスと一緒に 2 倍。コマンドの `--map`・`--no-chains`。
