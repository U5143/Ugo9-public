# エンジンの使い方（エディタで作ったキャラをゲームで動かす）

エディタで作ったキャラを、Unity・Godot・Web（three.js）で動かすまでの道筋です。仕組みと API の一覧は [エンジン.md](エンジン.md) にあります。

## 1. エディタから書き出す

| エディタのメニュー | できる物 | ゲームで使う所 |
|---|---|---|
| ファイル → 書き出し：Ugo9 データ（.ug9） | `model.ug9` と、同じフォルダのアトラスの PNG（`atlas.png` など） | モデル。**.ug9 と PNG は同じフォルダに置いたまま** 入れる（.ug9 の中は PNG の名前を持っている） |
| 表情の画面の「書き出し」 | 表情のプリセット `.ug9x`（JSON） | 別のモデルにも同じ表情をかけたい時だけ。モデルの中の表情は .ug9 に入っているので、要らない |

- 曲線のキーを 1 つでも使うと、.ug9 は形式 1.1 になります。エンジンのプラグインも 1.1 を読める物にしてください（読めない時は「プラグインを新しく」と出ます）
- パラメータの名前を [パラメータの名前](パラメータの名前.md) の表に合わせておくと、下の「助け」（見る方向・まばたき・口）がそのまま効きます

## 2. エンジンに入れる

### Unity（6000.3 以上、URP）

1. Package Manager →「Add package from disk…」で `engines/unity/com.ugo9.runtime/package.json` を選ぶ（芯のライブラリは [engines/unity/README.md](../engines/unity/README.md) のとおりに作る）
2. `model.ug9` と PNG を Assets の同じフォルダへ落とす。.ug9 が **UgoModel** のアセットになる。ドット絵は取り込みの設定の **Pixel Art** に印
3. 空の GameObject に **UgoCharacter** を付け、`model` に UgoModel を入れる。インスペクタでアニメと表情を名前から選べ、Play しなくてもシーンで動く
4. 大勢を出す時は、親に **UgoBatch** を付けて、その下に UgoCharacter を置く（モデルごとに 1 回で描く）

### Godot（4.4 以上）

1. `engines/godot` をビルドし（[engines/godot/README.md](../engines/godot/README.md)）、`addons/ugo9` をプロジェクトに入れる
2. `model.ug9` と PNG を `res://` の同じフォルダへ。`load("res://…/model.ug9")` で **UgoModel** になる。ドット絵は `model.pixel_art = true`
3. シーンに **UgoCharacter** を置き、`model` を選ぶ。インスペクタに animation・expression の候補と `parameters/<名前>` のスライダーが出る
4. 大勢は **UgoBatch** の下に置く

### Unreal（5.6 以上、作っている途中）

1. C++ のプロジェクトに、`node engines/unreal/package_plugin.mjs <プロジェクト>/Plugins` でプラグインを写し、プロジェクトを開いて再ビルド（[engines/unreal/README.md](../engines/unreal/README.md)）
2. `model.ug9` と PNG を同じフォルダから Content Browser へ取り込む（.ug9 だけ選べば、隣の PNG も一緒に入る）。**Ugo Model** のアセットになる
3. Actor に **Ugo Character** のコンポーネントを足し、Model と Animation を選ぶ。キャラは X–Z の面に立ち、−Y を向く（Right／Left の表示で正面）。Play しなくてもビューポートで動く
4. 大勢：何体置いても、同じモデルなら描く回数は同じ（モデルごとにまとめて描く）

### Web だけで使う（ugo.js、素の JS）

エンジン無しで、ページの canvas に描く形。部品の一覧と毎フレームの流れは [芯の API](芯のAPI.md)（型は `web/ugo.d.ts`）。

```js
import { UgoRuntime, UgoRenderer, loadImage } from './ugo.js';
const rt = await UgoRuntime.load();                       // ugo.wasm（SIMD が使える所は ugo_simd.wasm）は ugo.js の隣から
const model = rt.loadModel(await (await fetch('model.ug9')).arrayBuffer());
const canvas = document.querySelector('canvas');
// 背景を透明にする：alpha と premultipliedAlpha を true に、毎フレーム透明で消す
const gl = canvas.getContext('webgl2', { alpha: true, premultipliedAlpha: true, antialias: true });
const renderer = new UgoRenderer(gl, model, [await loadImage('atlas.png')]);
const hero = model.createInstance();
let last = performance.now();
function frame(now) {
  const dt = (now - last) / 1000; last = now;
  hero.reset();                                            // 毎フレーム、パラメータを既定に戻す
  hero.play('idle', now / 1000);                           // 時間（秒）を進めて渡す（同じ値のままだと止まって見える）
  hero.setTransform(1, 0, 0, 1, canvas.width / 2, canvas.height);
  hero.update(dt);
  gl.viewport(0, 0, canvas.width, canvas.height);
  gl.clearColor(0, 0, 0, 0); gl.clear(gl.COLOR_BUFFER_BIT);
  renderer.draw([hero], canvas.width, canvas.height);
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
```

- **動かない**：`play` に渡す時間が毎フレーム同じ（0 など）だと止まって見える。経った秒を渡す。`reset` → `play` → `update` の順も守る
- **ループ**：ループするかはアニメごとにファイルに入っている（エディタのアニメの「ループ」）。ループするアニメは、長さを超えた時間を渡せば頭に戻る。ループしないアニメは最後の姿で止まる。切り替え・終わりの知らせ・層は `UgoAnimator`（下の「アニメの終わりとループ」）
- **Nuxt・Next.js で「window is not defined」**：`ugo.js` は読み込むだけなら `window` に触らない（`tests/ssr_test.mjs` が Node で確かめている）。触るのは描く所（`UgoRenderer`・`loadImage`、canvas が要る）なので、それをサーバーで描く時（SSR）に呼ばない。描く所は画面の側だけで行う：Nuxt は `onMounted(async () => { const { UgoRuntime } = await import('…/ugo.js'); … })` か `<ClientOnly>`、Next.js は `useEffect` の中で `import()` か `dynamic(…, { ssr: false })`

### Web（three.js）

```js
import { UgoRuntime, loadImage } from './ugo.js';
import { UgoThreeCharacterFactory } from './ugo_three.js';
const rt = await UgoRuntime.load();
const model = rt.loadModel(await (await fetch('model.ug9')).arrayBuffer());
const factory = new UgoThreeCharacterFactory(THREE, model, new THREE.Texture(await loadImage('atlas.png')) /* , { sampling: 'nearest' } */);
const hero = factory.create({ metresPerPixel: 1.6 / model.canvas[1] });  // キャンバスの高さを 1.6 m に
scene.add(hero);
// 毎フレーム
hero.instance.reset(); hero.instance.play('idle', t); hero.place(); hero.instance.update(dt); hero.sync(renderer);
```

見本は `web/three3d.html`。表情は Web の `UgoExpressionMixer` をそのまま使います。

TypeScript では、`web/ugo.d.ts` などの型の定義が `.js` の隣にあるので、そのまま型が付きます（[エンジンのAPI.md](エンジンのAPI.md) の「型」）。

### Web（PixiJS・Phaser）

```js
import { UgoRuntime, loadImage } from './ugo.js';
import { UgoLayer } from './ugo_layer.js';
import { UgoPixiLayer } from './ugo_pixi.js';          // Phaser は ugo_phaser.js の UgoPhaserLayer
const rt = await UgoRuntime.load();
const model = rt.loadModel(await (await fetch('model.ug9')).arrayBuffer());
const layer = new UgoLayer(rt, { width: app.screen.width, height: app.screen.height });
const kind = layer.addModel(model, [await loadImage('atlas.png')]);
const hero = layer.add(kind, { x: 400, y: 560, scale: 0.8 });
const ugo = new UgoPixiLayer(PIXI, layer);
app.stage.addChild(ugo.sprite);
app.ticker.add((t) => { hero.instance.reset(); hero.instance.play('idle', performance.now() / 1000); ugo.update(t.deltaMS / 1000); });
```

キャラは 1 枚の絵（層）にまとめて描かれ、その絵がほかのスプライトと同じに並びます。キャラの間に木や建物を挟みたい時は、層を 2 枚にします。キャラ 1 体ずつをスプライトにしたい時は `UgoSpriteSheet` と `ugo.spriteFor(キャラ)`（Phaser は `imageFor`）。クリックは `ugo.pick(x, y)`（キャラとパーツの名前）。

### RPG ツクール MZ（プラグイン）

1. `node engines/rpgmaker_mz/build.mjs` で作った `Ugo9.js` を、プロジェクトの `js/plugins/` に置いて ON
2. `img/ugo9/<名前>/` に `model.ug9` と PNG
3. イベントのプラグインコマンド「出す」「アニメ」「表情」「話し手」など。話し手にしたキャラは、メッセージの文字が出ている間しゃべる（[engines/rpgmaker_mz/README.md](../engines/rpgmaker_mz/README.md)）

### GameMaker（拡張、作り始め）

拡張（`ugo9_gm.dll`）・スクリプト（`Ugo9.gml`）・シェーダー（`shd_ugo9`）を入れ、`new Ugo9Model(パス)` と `new Ugo9Character(モデル)`、Step で `step(秒)`、Draw で `draw()`。入れ方と関数の表は [engines/gamemaker/README.md](../engines/gamemaker/README.md)。マスクはまだ。

### GDevelop（スクリプト、作り始め）

`Ugo9GDevelop.js` を読み込み、JavaScript のイベントで `gdjs.ugo9.show(runtimeScene, 'hero', 'ugo9/hero/model.ug9', x, y)`、`play`・`onlyExpressions`・`setMouthLevel`・`partAt`（[engines/gdevelop/README.md](../engines/gdevelop/README.md)）。

## 3. よく使う形

名前は Unity／Godot の順。three.js は Web の API（`web/ugo.js`）と同じです。

### 会話の場面（表情・口・見る方向・まばたき）

| したいこと | Unity | Godot |
|---|---|---|
| マウスやほかのキャラを見る | `lookTarget = 物の Transform`、または毎フレーム `LookAt(ワールドの点)`。やめる時は `StopLooking()` | `look_target = NodePath`、または `look_at_point(点)`・`stop_looking()` |
| 顔の位置を合わせる | `lookFrom`（モデルのピクセル。0,0 ならキャンバスの上から 4 分の 1） | `look_from`、向き切る距離は `look_range` |
| 自分でまばたき | `autoBlink = true` | `auto_blink = true` |
| 声に合わせて口 | `lipSyncSource = AudioSource`（大きさで開く。`lipSyncGain` で強さ）、自前の値なら `SetMouthLevel(0〜1)`。負の値でアニメに戻す | `lip_sync_bus = "Voice"` など、または `set_mouth_level(0〜1)` |
| 表情を出す | `ShowExpression("smile")`・`HideExpression`・`OnlyExpressions("angry")` | `show_expression("smile")`・`hide_expression`・`only_expressions(["angry"])` |
| 別のモデルの表情を使う | `LoadExpressions(.ug9x の TextAsset)` | `load_expressions(FileAccess.get_file_as_string("res://x.ug9x"))` |

かける順は「アニメ → set_param → 表情 → 助け」。助けはアニメの上に重なるので、アニメに首振りがあっても見る方向へ向きます。

### アニメの切り替え

```csharp
c.Play("walk", 0, 0.3f);            // 0.3 秒で混ぜて切り替え
c.Play("jump"); c.PlayNext("idle", 0.2f);   // jump（ループしない）が終わったら idle へ
c.AnimationFinished += name => Debug.Log(name + " が終わった");
```

```gdscript
c.play("walk", 0.0, 0.3)
c.play("jump"); c.play_next("idle", 0.2)
c.animation_finished.connect(func(n): print(n, " が終わった"))
```

切り替えの後に前のアニメの値が残ることは無い：パラメータは毎フレーム既定に戻してからアニメをかけ直すので、混ぜている間（`fade` 秒）だけ前のアニメが混ざり、終われば消える。混ぜる秒の既定は、主のアニメの `Play` が 0（すぐ切り替え）、層の `PlayLayer` が 0.25 秒。重みを自分で決めて混ぜたい時（ゲームの速さで歩き → 走りを混ぜる、など）は、毎フレーム `AddBlend`（Unity）・`add_blend`（Godot）で重みを渡す：

```gdscript
var run := clamp(speed / 300.0, 0.0, 1.0)
c.animation = "walk"
c.add_blend("run", t, run)        # 0 で歩きだけ、1 で走りだけ。毎フレーム呼ぶ
```

### アニメの終わりとループ

| | Unity | Godot | Unreal | Web |
|---|---|---|---|---|
| ループしないアニメの終わり | `AnimationFinished += name => …` | `animation_finished`（signal） | `OnAnimationFinished` | `UgoAnimator.on('end', ({ layer, name }) => …)` |
| 層の終わり | `LayerFinished` | `layer_finished` | `OnLayerFinished` | 同じ `on('end')`（`layer` が 1 以上） |
| 終わったら次へ | `PlayNext` | `play_next` | `PlayNext` | `UgoAnimator.queue` |
| 終わったか | `IsFinished` | `is_finished()` | `IsFinished` | エントリの `done` |

- ループするかはアニメごとにファイルで決まる（エディタのアニメの「ループ」）。主のアニメで変えたい時は、エディタで変えて書き出し直す。ゲームの中だけで変えたい時は、層（`PlayLayer` の `loop`（Unity）・`Loop`（Unreal）・`UgoAnimator.play(名前, { loop })`（Web））を使うか、ループしないアニメを `animation_finished` で `play` し直す
- ループするアニメは「終わった」を出さない（終わらない）。ループの境目で何かしたい時は、時間（`time`）が長さを超えたかを見る
- 「終わった」の中で `Play`・`play` を呼んでよい（その場で次のアニメに替わる。固まらない）。`Play` は待ち（`PlayNext` に入れておいた物）を空にするので、その時は中で呼んだ物だけが効く
- ループが遅れる・止まる時は、時間が進んでいるかを見る：Unity は `playing`・`manual`（`manual` なら `Advance` を呼ぶ）、Godot も `playing`・`manual`、`speed` が 0 でないか

### アニメを重ねる（層）

```csharp
var arm = c.MakeMask(bones: new[] { "armR", "handR" });   // 一度作って使い回す
c.Play("walk");                                  // 層 0：体全体
c.PlayLayer(1, "wave", 0.2f, mask: arm);         // 層 1：右腕だけ手を振る
c.PlayLayer(2, "nod", 0.1f, additive: true);     // 層 2：今の姿に頷きを足す
c.StopLayer(1, 0.3f);                            // 腕を歩きに戻す
```

```gdscript
c.play("walk")
c.play_layer(1, "wave", 0.2, false, { "bones": ["armR", "handR"] })
c.play_layer(2, "nod", 0.1, true)
c.stop_layer(1, 0.3)
```

Unreal（Blueprint）は同じ名前です：`Play`（Name・From Time・Fade）、`PlayNext`、`OnAnimationFinished`、`PlayLayer`（Layer は 1 から。Mask Bones／Parts／Parameters に名前を並べる。Additive）、`StopLayer`、`ShowExpression`・`HideExpression`・`OnlyExpressions`・`LoadExpressions`（JSON の文字列）、`LookTarget`（Actor）・`LookAt`・`StopLooking`、`bAutoBlink`、`LipSyncSource`（Audio Component）・`SetMouthLevel`・`SetVoiceLoudness`（dB）、`PartAt`・`AreaAt`・`RayToPlane`（マウスの線から面の上の点）、`GetBoneTransform`・`ReachFor`、`Color`、`Wind`。一覧は [engines/unreal/README.md](../engines/unreal/README.md)。

### 時間軸で動かす（カットシーン）

- **Unreal の Sequencer**：キャラの Actor を Sequencer に入れ、「+ Track」→ Ugo Character →「Time」（アニメの秒）と「Animation」（名前、文字列のトラック）をキーにする。**Playing** は切る（切らないと、Sequencer の秒にゲームの時間が足される）。「Color」「Expression」「Wind」もキーにできる
- **Unity の Timeline**：Timeline の窓で「Ugo9 Animation Track」を足し、キャラ（UgoCharacter）を結ぶ。クリップを置いて、インスペクタでアニメの名前を書く。クリップを重ねると、なめらかに切り替わる
- **Godot の AnimationPlayer**：キャラの `playing` を切り、AnimationPlayer で `time`（アニメの時間）や `parameters/HeadTurnX` などをキーにする。`animation` もキーにできる

### 群衆

UgoBatch の下に何百体置いても、同じモデルなら 1 回で描きます。キャラごとに `speed` と `play(名前, 始める時間)` をずらすと、動きがそろいません。描画順が変わるモデル（形式 0.8 の描画順のキー）は、同じ並びの隣どうしでまとめて描くので、回数は少し増えるだけです。

### クリック・タップでパーツを知る

```csharp
var world = Camera.main.ScreenToWorldPoint(Input.mousePosition);
string part = character.PartAt(world);       // "face"・"bangs" など、無ければ null
if (part == "face") character.ShowExpression("smile");
```

```gdscript
func _unhandled_input(event):
	if event is InputEventMouseButton and event.pressed:
		var part := character.get_part_at(get_global_mouse_position())   # 無ければ ""
```

three.js は `raycaster.setFromCamera(mouse, camera)` の後に `ch.partAt(raycaster)`。

左右反転（Unity の `localScale.x = -1`、Godot の `scale.x = -1`、GameMaker の `xscale = -1`）や回転をしても、当たりは見た目と合う：点はキャラのノードの変換を通してモデルの座標に戻すため（Unity は `InverseTransformPoint`、Godot はノードのグローバルの変換、GameMaker は拡張の中で置き方の逆。Godot と GameMaker は、片側のパーツ（`hairSideL` など）が反転したキャラでは鏡の位置で見つかることを試しで確かめている）。キャラを入れた親を反転しても同じ。ずれる時は、絵だけを別の所（カメラ・別のスプライト）で反転していないかを見る。GDevelop・RPG ツクール MZ には、まだ反転の指定が無い。

キャラ全体の四角は、Unity は `PartBounds()`（引数無し、ワールドの Bounds）、Godot は `get_part_rect()`（ノードの中の座標）、Unreal は `PartBounds("")`。パーツの四角は `PartBounds`／`get_part_rect`／`ch.partBounds`。名前はエディタのパーツの名前（PSD のレイヤー名から付いた物）です。

### 色と前後

| したいこと | Unity | Godot | three.js |
|---|---|---|---|
| キャラ全体の色・透明 | `color = new Color(1, 0.6, 0.6, 0.5)` | `modulate`（子にも）・`self_modulate` | `ch.color.set(…)`・`ch.opacity` |
| UgoBatch の中で前に出す | `sortingOrder`（大きい物が前） | `z_index` | `renderOrder` |
| 下にいるキャラを前に（見下ろしの場面） | UgoBatch の `sortByY` | UgoBatch の `y_sort_enabled` | 自分で `renderOrder` |

並べ方は 1 つの UgoBatch の中の同じモデルのキャラの間で効きます。UgoBatch 同士（と、UgoBatch の外で自分を描くキャラ）は、`sortingOrder`（Unity の UgoBatch・UgoCharacter）の大きい方が前、同じならカメラに近い方が前で、1 つずつ丸ごと描きます（部品が入り交じらない）。違うモデルを前後させたい時は、UgoBatch を分けて Sorting Order を付けます。Unity の Sorting Layer（ほかのスプライトとの前後）はまだ効きません。

### 骨に物を持たせる・手を伸ばす・風

| したいこと | Unity | Godot | Unreal |
|---|---|---|---|
| 手に剣を持たせる（毎フレーム骨の位置に合わせる） | `BonePosition("handR")`・`BoneRotation("handR")` | `get_bone_transform("handR")`（グローバルの Transform2D） | `GetBoneTransform`（Location と Rotation） |
| 手を点へ伸ばす（ドアノブ、相手の肩） | `ReachFor("handR", 点, 2)` を毎フレーム | `reach_for("handR", 点, 2)` | `ReachFor` |
| 髪や服を風になびかせる | `wind = new Vector2(300, 0)`・`windGust = 0.5f` | `wind = Vector2(300, 0)`・`wind_gust = 0.5` | `Wind`・`WindGust` |
| 揺れ物を止める（場面の切り替え） | `ResetPhysics()` | `reset_physics()` | （Model を入れ直す） |

骨の名前はエディタの骨の名前です。`ReachFor` は呼んだフレームだけ効くので、伸ばしている間は毎フレーム呼びます。風の単位はモデルのピクセル/秒²で、揺れ物（髪・服の骨の鎖）にだけ効きます（パラメータの揺れには効きません）。

### 当たりの範囲（頭・体を叩く）

エディタでパーツの名前を `hit:head`（または `当たり:head`）にすると、そのパーツは「head」の当たりになります（描かなくてよい。見えない形だけの当たり）。

| | Unity | Godot | Unreal | Web（web/ugo.js） |
|---|---|---|---|---|
| 点の当たり | `AreaAt(点)` | `get_area_at(点)` | `AreaAt(点)` | `instance.hitTest(x, y)`（モデルのピクセル） |
| 当たりの名前の一覧 | `AreaNames` | `get_area_names()` | `GetAreaNames()` | `model.hitAreas` |

### パラメータを直に動かす

`SetParam("HeadTurnX", 30)`／`set_param("HeadTurnX", 30)` で置いた値は、`ClearParam`／`clear_param` まで残ります。インスペクタのスライダーで置いた値はその下（ゲームの set_param が上）にかかります。

### 自作のエンジン（C・C++、D3D11・OpenGL・Metal など）

芯は C99 の 1 つのファイル（`core/src/ugo.c`）と見出し（`core/include/ugo.h`）で、メモリもファイルも自分では触らない。自作のエンジンには、それをそのまま組み込む：

1. `core/src` と `core/include` のファイルをビルドに入れる（ほかに要る物は無い）
2. .ug9 のバイト列を自分で読み、`ugo_model_mem_size_for` の大きさのメモリ（16 バイト境界）を渡して `ugo_model_init_sized`。キャラごとに `ugo_instance_mem_size` のメモリで `ugo_instance_init`
3. 毎フレーム：`ugo_reset_params` → `ugo_apply_animation` → `ugo_set_param` → `ugo_set_transform` → `ugo_update(dt)`
4. 描く：一番かんたんなのは `ugo_deform_cpu` で頂点の位置を受け取り、`ugo_uvs`・`ugo_indices` と一緒に自分の頂点バッファへ（GameMaker の拡張 `engines/gamemaker/extension/ugo9_gm.c` がこの形）。速くしたい時は、ほかのエンジンと同じに `ugo_frame` のフレームの塊を GPU へ送り、シェーダーで変形する（Unity の `Ugo9Character.shader`・Unreal の `Ugo9.usf` が見本）

関数の一覧と決まりは [芯の API](芯のAPI.md) と `core/include/ugo.h` のコメント。ライセンスは MIT（[ライセンス](ライセンス.md)）。

## 4. 見本

**開けばすぐ動く見本**（どれも見本のキャラ samples/basic で、アニメを選ぶ・パラメータのつまみ・自分でまばたき・マイクで口（雑音の門つき）・クリックしたパーツの名前、が試せる）：

| エンジン | 開き方 |
|---|---|
| Unity | Package Manager → Ugo9 → Samples →「Playground」を Import。空のシーンに空の GameObject、UgoPlayground を付けて Model に basic、Play |
| Godot | `engines/godot/project` を開き、`demo/playground.tscn` を開いて F6（このシーンを実行） |
| Unreal | Place Actors で「Ugo Playground Actor」をレベルに置き、Details の Character → Model に取り込んだ `model`、Play。N／P でアニメ、E で表情、B でまばたき、Space で口、クリックでパーツの名前（画面の左上に出る） |
| three.js | `web/engines/three.html`（右ドラッグでカメラを回す） |
| PixiJS | `web/engines/pixi.html` |
| Phaser | `web/engines/phaser.html` |

Web の 3 つは、リポジトリの頭で `node tools/serve.mjs 8080` を立てて `http://localhost:8080/web/engines/` を開く（エンジンは CDN から読む）。

| 見本 | 中身 |
|---|---|
| Unity「Conversation」・Godot `demo/conversation.tscn` | 1 体がマウスを見て、まばたきし、1〜4 で表情、Space の間しゃべる（口）、A でアニメを混ぜて切り替え |
| Godot `demo/ordering.tscn` | 並べ方（y の順・`z_index`・UgoBatch ごとほかのノードと前後）、色（`modulate`）、クリックでキャラ・パーツ・当たりの名前 |
| Unity「Demo」・Godot `demo/main.tscn` | 群衆を 1 回で描き、手前の 1 体がマウスを見る。上下で数を倍・半分、Space で idle と talk |

## 5. 困った時

| 出る物 | 直し方 |
|---|---|
| キャラが白い・四角い | PNG が .ug9 と同じフォルダに無い。書き出した時の名前のまま並べる |
| 「プラグインを新しく」 | .ug9 の形式（1.1 など）がプラグインより新しい。プラグインを更新する |
| 「作業用 JSON からコンパイルし直す」 | .ug9 が古すぎる。エディタで開き直して書き出し直す |
| 「飛ばした表があります」の警告 | 新しい副の版の機能をこのプラグインが知らない。動くが、その機能だけ効かない |
| 見る方向・まばたき・口が効かない | モデルにその名前のパラメータが無い（[パラメータの名前](パラメータの名前.md)）。Unity は `Helpers` で名前を変えられる |
| ドット絵がぼやける | Unity は取り込みの Pixel Art、Godot は `pixel_art`、three.js は `sampling: 'nearest'`。PNG 側の Filter Mode は効かない |
| 縁に色がにじむ | テクスチャを自分で作っている。`UgoModel.LoadTexture`（Unity）を使う（アルファを前もって掛ける） |
| アニメが動かない・止まる | 時間が進んでいない。`playing`・`manual`・`speed` を見る。Web は `play` に毎フレーム経った秒を渡す |
| ループしない | ループはアニメごとにファイルで決まる。エディタでループにして書き出し直すか、「アニメの終わりとループ」の形で |
| 背景が透明にならない（Web） | canvas を `alpha: true, premultipliedAlpha: true` で作り、毎フレーム `clearColor(0, 0, 0, 0)` で消す |
| 「window is not defined」（Nuxt・Next.js） | 描く所はサーバーで動かせない。画面の側だけで読み込む（上の「Web だけで使う」） |
| 口パクがエディタでは動くのに、ビルドした物では動かない | Unity：`lipSyncSource` の AudioSource が実際に鳴っているか（Play On Awake・音量・AudioListener がシーンにあるか）。マイクは、ビルドでは OS の許可（macOS・スマホ）が要る。Godot：書き出しにバスの設定（`default_bus_layout.tres`）が入っているか、`lip_sync_bus` の名前がそのバスにあるか、マイクならプロジェクトの「Audio → Driver → Enable Input」 |
| クリックの当たりが見た目とずれる | 絵だけを別の所で反転・移動していないか。キャラのノードを動かせば当たりもついてくる（「クリック・タップでパーツを知る」） |
