# Ugo9 エディタの使い方（下書き、v11 まで）

Ugo9 のキャラを作って動かすためのアプリです。（「2D モーフィング」「動く立ち絵」「一枚絵を動かす」などと呼ばれることと同じです。はじめての人は「ヘルプ → チュートリアル」から。F3 でこの呼び名を打っても出ます）顔は Live2D のように「パラメータとキーの形」で、体は Spine のように「骨・ウェイト・タイムライン」で動かします。どちらも 1 つの画面で使えます。

> ブラウザ版（Chrome・Edge などの Chromium 系で確かめています）と、デスクトップ版（Windows、配布の準備中）があります。操作は同じです。

## 始め方

1. リポジトリのフォルダで `node tools/serve.mjs` を実行します
2. 表示された `http://localhost:8099/editor/` を開きます。見本のキャラが開きます。ビューの左下に入口のボタンが 2 つ出ます：**PSD を読み込む**（自分の絵から始める）と **見本を開いて再生**（アニメの場で見本の動きを再生して、何ができるかを見る）。見本を編集するか、別のファイルを開くと消えます
3. 自分の絵から始める時は、入口の「PSD を読み込む」か「ファイル → 開く…」で PSD を選ぶか、画面に落とします

| 開ける物 | 中身 |
|---|---|
| PSD | レイヤーごとにパーツになります。「ファイル → PSD を開く時：グループを骨に」に印を付けておくと、グループごとに骨ができ、中のパーツがその骨で動きます。グループの中のレイヤーもパーツになります。クリッピングはマスク、乗算・スクリーン・覆い焼き（リニア）は重ね方として読みます。パーツは、Live2D と同じく絵の四角（4 点）で入ります。なめらかに曲げたいパーツだけ、選んで「パーツ → メッシュを作る」で絵の形に沿ったメッシュを作ります（下の「1. パーツとメッシュを整える」）。開く時に全部のパーツへメッシュを作りたい時は「ファイル → PSD を開く時：メッシュを自動で作る」に印を付けます（初めは外れています。選んだ形は覚えておきます）。「ファイル → PSD を開く時：アトラスをもっと小さくする（絵がわずかにぼやける）」に印を付けると、斜めの細長い絵を回してアトラスに詰めます（初めは外れています。読み直す時は、開いた時と同じ置き方で読みます） |
| 大きな絵 | 「ファイル → 読む大きさ」（自動・× 1・× 1/2・× 1/4。このパソコンに残る）。自動は 4080 px を超えるキャンバスだけ縮めます。3000 px より大きいキャンバスをそのまま開くと、軽くする方法を言います。× 1/2 で開けば動かすのが軽くなり、PSD を読み直す時も同じ大きさで読みます |
| Krita（.kra）・OpenRaster（.ora）・PNG の組 | PSD と同じに、レイヤーごとにパーツになります（グループ・不透明度・隠れたレイヤー・重ね方も同じに読みます）。.ora は GIMP・MyPaint などからも書き出せます。PNG の組は、JSON の無い PNG だけを選ぶか落とすと、1 枚が 1 レイヤーになります。重なりは名前の順で下から（`01 体.png` の上に `02 顔.png`）、並びを決めたい時は `order.txt`（1 行に 1 つ、上のレイヤーから）を一緒に選びます。フォルダを落とすと、中のフォルダがグループになります。ベクター・塗りつぶし・クローンのレイヤーは画素が無いので飛ばし、下の行に出ます（Krita でペイントレイヤーに変えると読めます）。「PSD を読み直す」「PSD の更新を見張る」「描いたマスクを PSD に足す」は、PSD から作ったモデルの時だけ使えます |
| Aseprite（.aseprite・.ase） | ドット絵。はじめは最初のコマを、PSD と同じにレイヤーごとのパーツにします。ファイル → 「Aseprite を開く時：コマもアニメとして読む」を入れると、すべてのコマを読み、タグ（無ければ全体）がアニメになります（レイヤーの絵がコマで変わる所は「名前#コマ」のパーツになり、コマごとに出し入れ）。コマの絵のフォルダはパーツ一覧で畳んであります（開けば開いたまま）。読めない物（タイルマップ・2 コマ目から・タグなど）は下の行に出ます。点をくっきり保つには、書き出しで「近い色で描く」がおすすめです |
| SVG（.svg） | ベクターの絵。一番上の要素ごとにパーツ、Inkscape のレイヤーはフォルダになります。描くのはこのアプリの中の SVG の描き方なので、文字はこの PC のフォントで描き、外のファイルを指す絵や foreignObject は描けません（下の行に出ます）。SVG でないファイルは開かず、開いていたモデルはそのままです |
| Procreate（.procreate） | PSD と同じに、レイヤーごとにパーツ、グループがフォルダになります |
| .ugo9 | 保存した作業ファイルを開きます（作業用 JSON と画像が 1 つに入っています）。デスクトップ版は、.ugo9 をダブルクリックしても開きます |
| model.json と画像 | 前の形の作業ファイル（JSON と画像が別々）も開けます。JSON と画像（atlas.png など）を一緒に選びます |
| .ug9（.ugo） | 書き出したファイル（ゲームやアプリが読む物）から、作業ファイルに戻します（作業ファイルを無くした時など）。使っている絵（atlas.png など）も一緒に選びます。.ug9 に無い物（PSD とのつながり、グルー、曲線の形、エディタだけの情報など）は戻らないので、下の行で知らせます。もう一度書き出すと同じ .ug9 になります。保存すると .ugo9 になり、.ug9 は上書きしません |

**PSD を開く時に読む物**（v11 まで。くわしくは [PSD.md](PSD.md)・[PSDの描き方.md](PSDの描き方.md)）：
- **レイヤー効果**（ドロップシャドウ・境界線・光彩・カラーオーバーレイなど）は、絵に描き込んで読みます。下の行に「描き込みました」と出ます。描き込めない種類（ベベルなど）は名前を挙げて知らせます
- **調整レイヤー**（レベル補正・トーンカーブ・色相・彩度・カラーバランス・グラデーションマップなど）は、届くレイヤーの絵に焼き込んで読みます。Photoshop と同じ物と、近いだけの物があり、近いだけの物は知らせます
- **名前の印で骨**：レイヤーやフォルダの名前の終わりに `[骨]`（`[bone]`）を書くと骨ができます。`[骨 親=上腕 根元=左]` のように親と根元も決められます（印は名前に入りません）。「グループを骨に」と一緒の時は印を使いません
- **クリッピング**はマスクに、**乗算・スクリーン・加算**はそのまま、ほかの合成モードは通常として描きます（知らせが出ます）
- 開く前に名前の決まりを確かめたい時：Photoshop のパネル（[Photoshopのパネル.md](Photoshopのパネル.md)）か、`node tools/psd_check.mjs 絵.psd`

**エディタではまだ開けない物**（読み込みの部品はあり、エディタの「開く」に足すのはエディタの担当）：
- **Procreate（.procreate）**：コマンドで作業ファイルにしてから開きます：`node tools/ugo9.mjs import 絵.procreate --out 絵.ugo9` → ファイル → 開く… で 絵.ugo9
- **SVG**（Illustrator・Inkscape）：読み込みの部品（`tools/import_svg.mjs`）は形を描くのにブラウザが要り、今はエディタからもコマンドからも開けません
- **Spine の JSON**：`node tools/ugo9.mjs import 骨.json --out 名前.ugo9`（横に .atlas を置く）→ .ugo9 を開く（[Spine.md](Spine.md)）

とても大きな PSD（何千 px 四方で、レイヤーが何百枚）は、読む前に「メモリが足りず落ちるかもしれません。開きますか？」と聞きます。開く前に作業を保存してください。読んでいる間は、下の行に何枚目まで読んだかが出ます（読み込みの側が対応したら）。

デスクトップ版では、「ファイル → 最近開いたファイル」から、最近開いた・保存したファイル（5 つまで）をもう一度開けます。.ugo9 は 1 つで開き、JSON は同じフォルダの絵と一緒に開きます。見つからないファイルは一覧から外れます。一覧はこのコンピューターの中だけにあります。

**権利について**：他の人が描いた絵を使う時は、その絵を使ってよいか、使う人が確かめてください。Live2D の書き出しファイル（.moc3 など）は開けません。Spine の JSON を読み込んで作った物を Spine の公式ランタイムで使う時は、Spine のライセンスが必要です。


## やりたいことから探す（F3）

名前が分からない道具は、F3 でやりたいことを打つと出ます（例：「汗を流したい」「口を声に合わせたい」「腕を曲げたい」「重なって触れない」「崩れを探す」「動きを録る」）。Live2D や Spine の言葉でも出ます（例：「マルチキー編集」「ミラー編集」「ブレンドシェイプ」「デフォーマを初期化」「クリッピングをまとめて」「Krita のファイルを開きたい」「文字を大きくしたい」「自動化したい」）。主な物の場所は「ヘルプ → 動きの仕組み」（F1）の「やりたいことから探す」の表にもあります。
## 画面

```
メニュー   ファイル・編集・パーツ・変形・パラメータ・アニメ・表示・ウィンドウ・ヘルプ
その下     [組み立て｜アニメ]（作業の場）と道具（選ぶ V・骨を作る B・ウェイトを塗る W）
左         物の木：パーツ（上が手前）／変形（骨とワープデフォーマ）／問題
真ん中     ビューポート（キャラ）。アニメの時は下に時間軸
右         上：インスペクタ（選んだ物の設定）　下：パラメータ（つまみ）
下         状態の行（コンパイルの結果・注意・数）
```

- すべての機能は上のメニューにあります。どこにあるか分からない時は **F3**（編集 → 機能を名前で探す）で名前を打つと、メニューの場所と一緒に出ます
- 作る機能（ワープデフォーマ・骨のチェーン・顔の向き・まばたき・口・下書き・待機のアニメなど）は、作る物のメニューにあります。右の欄は、選んだ物の設定とつまみだけです
- **組み立て**：パーツ・メッシュ・骨・ウェイト・パラメータとキーの形を作ります
- **アニメ**：時間に沿ってキーを打ち、動きを作ります
- Ugo9 で動きができる仕組みは「ヘルプ → 動きの仕組み」（F1）にあります。Live2D・Spine・Blender の言葉との対応も載っています

### ポーズを覚えて戻す（値のコピー）

- 「パラメータ → 値をコピー（今のポーズ）」で、パラメータの今の値を覚えます（物理で揺れる物は除く）。「パラメータ → 値を貼り付け」で、覚えた値に戻ります
- 組み立ての場では見た目（つまみ）だけが動きます。アニメの場で自動キーなら、変わるパラメータに今の時間のキーが打たれます（1 歩で取り消せます）。同じポーズをアニメの別の時間にもう一度、などに

### グリッドとガイド

- **グリッド**：「表示 → グリッド」で、キャンバスに方眼が出ます（原点の線は紫、5 マスごとに少し濃く）。1 マスの大きさは「表示 → グリッドの間隔…」（モデルの px）。この PC の設定です
- **ガイド**：「表示 → 定規（ガイドを引く）」で、ビューの上と左に定規が出ます。定規からビューへドラッグすると、ガイド（水色の線）が引けます。上の定規からは縦の線、左の定規からは横の線。定規の上の印をつかむと動かせ、定規へ戻すと消えます。「表示 → ガイドを全部消す」も。ガイドは作業ファイル（.ugo9）に入り、取り消せます。書き出しには入りません
- **吸い付く**：「表示 → グリッドとガイドに吸い付く」をオンにすると、頂点をドラッグした時に近くの方眼の線・ガイドへ吸い付きます（縦と横それぞれ）。左右の目の高さをそろえる、体の中心線に合わせる、などに

### パネルの場所を変える

左・右・下の欄にあるパネル（パーツ・変形、インスペクタ、パラメータ、時間軸）は、Photoshop や CLIP STUDIO のように動かせます。

- **移す**：パネルの見出しのタブを、ドラッグで別の場所へ。左・右・下の欄の中、ほかのパネルの上（タブで重なる）、ほかのパネルの上下の端（並ぶ）。ビューポートの端の近くへ落とすと、その側の欄へ
- **大きさ**：欄とビューポートの境目をドラッグで幅・高さ。同じ欄の中のパネルの境目も、ドラッグで分け方が変わります
- **たたむ・隠す**：見出しの「▾」で見出しだけに、「×」で隠します。隠したパネルは「ウィンドウ」メニューのチェックで出し直せます（初めの場所に戻ります）
- **保存と切り替え**：「ウィンドウ → レイアウトに名前を付けて保存…」（例：組み立て用・アニメ用）。保存したレイアウトは同じメニューに並び、押すと切り替わります。「レイアウトを初期に戻す」で初めの形に
- **別ウィンドウ**：見出しの「⧉」（またはタブを画面の外へドラッグ）で、そのパネルが独立したウィンドウになります。2 枚目のモニタにも置けます。中身は同じエディタなので、どちらで触っても同じ物が動き、取り消し（Ctrl+Z）も 1 つです。ウィンドウを閉じると、パネルは初めの欄に戻ります。エディタを開き直すと、別ウィンドウだったパネルは欄に戻っています。ブラウザで使う時は、このサイトのポップアップを許可してください
- レイアウトはこの PC に残り、作業ファイルには入りません（人に渡したファイルの見た目は変わりません）
- 時間軸のパネルは、アニメの作業の場でだけ出ます

| メニュー | 入っている物 |
|---|---|
| ファイル | 開く・最近開いたファイル・PSD を開く時の設定・PSD を読み直す・保存・書き出し（.ug9／画像・動画） |
| 編集 | 元に戻す・やり直す・名前を変える・削除・機能を名前で探す |
| パーツ | 描画順・メッシュを作る／作り直す・重ね方とマスクと色・グルー |
| 変形 | 骨を作る・ウェイト（自動・塗る）・IK を付ける・ワープデフォーマを作る・ワープデフォーマを細かくする・球と円柱（作る・焼く・外す）・物理（パラメータの揺れ）・物理のチェーン |
| パラメータ | パラメータを足す・値を戻す・値をコピー／貼り付け（ポーズ）・キー・自動で作る（顔の向き・まばたき・口・下書き） |
| アニメ | 新しいアニメ・待機のアニメを作る・口パク（音声から）・再生・キーを打つ／消す・自動でキーを打つ |
| 表示 | 全体を表示・骨を表示・物理を動かす・グリッド（間隔・吸い付く）・定規とガイド・問題の一覧・時間を測る・UI の大きさ・言語 |
| ウィンドウ | 組み立て・アニメ・パネルを出す／隠す・レイアウトを初期に戻す・名前を付けて保存・切り替え |
| ヘルプ | 動きの仕組み・PSD の描き方・チュートリアル・使い方・キー操作・Ugo9 エディタについて |

**キーの曲線**（形式 1.1）：時間軸でキーを選び、上の帯の動き方を「曲線」にすると、次のキーまでの動きを曲線で決められます。はじめは「なめらか」と同じ形です。帯の下に小さな窓が出て、2 つの丸（手）をドラッグして曲げます（横が時間、縦が値。離すと 1 歩）。決まった形のボタンもあります：ゆっくり始まる・ゆっくり止まる・ゆっくり始まり止まる・行き過ぎて戻る・溜めてから。キーの値を変えると、そのキーにつながる手も一緒に動きます。曲線の途中にキーを打つと、曲線はその場所で 2 つに分かれ、動きは変わりません。キーを消すと、前の曲線は次のキーまで伸びます。色のトラックは曲線にできません。曲線を 1 つでも使うと、書き出す .ug9 は形式 1.1 になります（1.0 のランタイムでは読めません）

**UI の大きさ**（表示 → UI の大きさ）：メニュー・パネル・文字を 80〜175% にします。デスクトップ版は、パネルを出した窓も含めて全部の窓が変わり、この PC に覚えて次の起動でもその大きさです。ブラウザでは、ページは自分の大きさを変えられないので、ブラウザの拡大（Ctrl ＋ ＋／−、Mac は ⌘）を使います（同じように全体が大きくなります）

**表示品質**（表示 → 表示品質）：ビューでキャラを描く細かさを、高（画面の画素のまま）・ふつう（75%）・軽い（50%）から選びます。骨・頂点・線などの印はいつも細かいままです。重いモデルや GPU の弱いパソコンで、作業を軽くします（160 パーツのモデルで、1 コマの描画が 205 → 142 → 91 ms）。「動かしている間は軽く」にすると、押している間・ホイール・再生中だけ「軽い」になり、止まると戻ります。書き出しはいつも高（表示品質に関係なく同じ絵）。この PC に覚えます。Ctrl+Alt+T の時間の内訳に「1 コマの描画」と今の表示品質が出ます

### ビューポートの操作

| 操作 | 動き |
|---|---|
| 中ボタン・右ボタンのドラッグ、Space ＋ドラッグ | 画面を動かす |
| 右クリック（動かさずに離す） | 選んだ物に合うメニュー（パーツ・ワープデフォーマ・骨・パラメータごと）。何も選んでいない時は、カーソルの下のパーツを選んで出します。一番上に、それを動かす物の道筋（‹ ワープデフォーマ ‹ 骨 …。押すとそれを選ぶ）、下に「ここに重なったパーツ ▸」「これを動かすパラメータ ▸」「画面で隠す」「ロック」 |
| Ctrl ＋右クリック | その場所に重なったパーツの一覧（押すと選ぶ。下に隠れたパーツを選ぶ時に） |
| ホイール | 拡大・縮小（カーソルの所を中心に） |
| 2 本指でつまむ・広げる（タブレット・スマホ・タッチパネル） | 拡大・縮小（2 本の指の真ん中を中心に）。2 本指のまま動かすと画面を動かす。1 本指はマウスの左ボタンと同じ（タップで選ぶ・ドラッグで動かす）。2 本目を置くと、1 本目で始めていた操作はそこで止まり、何も変わりません |
| 指で長押し（半秒、動かさずに） | 右クリックと同じメニュー（その場所のパーツ・頂点の操作）。動かすと長押しになりません |
| 指で頂点・点をつかむ | 指では、つかめる範囲が少なくとも 14 px になります（マウスは「つかむ範囲」の設定のまま）。タッチの画面では、メニューの行・タイムラインの行とキー・スライダーのつまみ・小さなボタンも大きくなります |
| ペンで塗る | タブレットのペン・スタイラスでは、押す強さでブラシが変わります：ウェイトの強さ、マスクの太さ、レタッチの濃さ（軽く押すと弱く・細く・薄く）。「表示 → ペンの筆圧」で切れます（このパソコンに残る）。マウスと指はいつも同じ強さ |
| スマホ・幅の狭い画面（760 px 以下） | ビューが画面いっぱいになり、パネルは下の帯から 1 つずつ開きます（「ビュー」「パーツ・変形」「インスペクタ・パラメータ」など、今のパネルの名前のボタン）。開いたパネルはビューの下半分に重なります。同じボタンか「ビュー」で閉じます。道具の行は横に滑らせて選びます |
| 画面の左下の Shift・Ctrl・Alt（指やペンで触ると出ます） | 押すと入り、もう一度押すまで、ビューの指やペンの操作でそのキーを押したままと同じになります（Shift で選び足す、Alt で逆向きなど）。マウスには効きません |

**パーツ・変形の木**：

- パーツの行の左の目（👁）で、そのパーツを画面で隠す・出す（見るためだけ。保存・書き出しには効きません）。鍵（·／🔒）で、画面で触れないようにします（選べない・頂点を動かせない）。目・鍵の上をドラッグすると、何行もまとめて切り替わります
- **木の上で引いて移す**：行の真ん中に落とすと「その子にする」（行が囲まれます）、行の上・下の縁に落とすと「その隣へ移す」（線が出ます。パーツの一覧では描く順の手前・奥）。落とす前に、カーソルの横に「face の子にする」「hair へ移す」のように出ます。できない所（自分の子の中・パーツの子など）では「できません：…」と出て、落とせません
- 「変形」の木では、骨とワープデフォーマの下に、それで動くパーツ（▭）が並びます（ウェイトのあるパーツは、一番重い骨の下に ⋯ 付きで）。パーツを別の骨の上へドラッグすると、その骨だけで動くようになり、ワープデフォーマの上へドラッグすると、その中に入ります（取り消せます）

**下絵**（表示 → 下絵…）：作業の目安にする絵（元の絵・参考の絵など）を、キャラの下か上に置きます。「絵を足す…」で選ぶと、キャンバスの高さに合わせて真ん中に、濃さ 50% で置かれます。窓で、表示する・しない、位置（x・y）、大きさ、濃さ、キャラの下か上、外す、を選べます（どれも 1 歩で取り消せます）。下絵は書き出しには入らず、絵は作業ファイル（.ugo9）の中に入ります

**スクリプト**（編集 → スクリプト…）：エディタの操作を JavaScript で書いて走らせます。スクリプトは窓・ファイル・ネットに触れない別の所で走り、エディタには `ugo9` を通して頼みます（`await ugo9.parts()`・`params()`・`bones()`・`warps()`・`animations()`・`get([道])`・`set([道], 値)`・`select(種類, id)`・`selection()`・`setParam(id, 値)`・`param(id)`・`menu(メニューの id)`・`log(…)`）。1 回走らせた分が 1 歩で取り消せ、途中で失敗したら走らせる前に戻ります。ファイル・ヘルプのメニューと、PSD への書き込みは使えません。「この PC に残す」（全部のモデルで使える）か「このモデルに入れる」（作業ファイルと一緒に渡る）で残し、.js に書き出す・読み込むこともできます。モデルに入って届いたスクリプトは、開いても走らず、その PC で初めて走らせる時に、中身を見せて確かめます（「はい」なら、その中身を覚えて次からは聞きません）

例：目のパーツを全部半透明にする
```js
const parts = await ugo9.parts();
for (const [i, p] of parts.entries()) if (/eye/i.test(p.id)) await ugo9.set(['parts', i, 'opacity'], 0.5);
```

**マクロを記録**（編集 → マクロを記録）：押してから使ったメニュー・選んだ物・パラメータ（引いた時は止めた所）を書き留め、もう一度押すと、その手順がスクリプトとして開きます。名前を付けて残せば、何度でも走らせられます（メニューが自分で選んだ物などは書きません）

**ランダムポーズ**（表示 → ランダムポーズ）：パラメータが、次々にばらばらの値へなめらかに動きます（半分はキーの値へ。角の形が崩れやすい所です）。穴・はみ出し・角の形の崩れを、つまみを 1 本ずつ動かさずに探せます。物理で動くパラメータ（髪の揺れなど）は物理に任せます。気になる形が出たら Esc（かもう一度メニュー）で、その形のまま止まります。直し始めても止まります。変わるのは見ている値だけで、文書は変わりません
  - **自分で動かしたつまみは動かしません**（その形のまま、ほかを動かして確かめられます）
  - 「表示 → ランダムポーズの対象…」で、動かすパラメータを選べます（この PC に残ります）
  - 「表示 → ランダムポーズの前に戻す」で、始める前の値に 1 手で戻ります

**PSD の更新を見張る**（ファイル → PSD の更新を見張る。最初から入っています）：開いた・読み込み直した PSD を 2 秒ごとに見て、変わったら自分で読み込み直します（今の「PSD を読み込み直す」と同じで、1 歩で取り消せます）。保存中のファイルを読まないよう、変わってからもう一度見て同じだったら読みます。デスクトップ版はいつでも、ブラウザ版は「開く」の窓から PSD を選んだ時だけ見張れます（ファイルを落として開いた時は見張れません）

**ワープデフォーマのマスの数**：パーツの大きさから決まります。上の帯で「マスの大きさで」（1 マスの px）か「〈ワープ〉と同じ細かさ」を選びます。作る前に、ボタンとメニューに数が出ます（例「ワープデフォーマを作る （6×4）」）。設定はこの PC に残ります

**名前をまとめて変える**（編集 → 名前をまとめて変える…）：パーツ・骨・ワープデフォーマ・パラメータの名前を、置き換え（文字か正規表現）・前に足す・後ろに足す・探す文字の前／後ろに足す・探す文字を消す・連番（始まりの数と桁）で、まとめて変えます。前と後の一覧を見てから「変える」。同じ名前・空の名前になる時は変えられません。1 歩で取り消せ、名前を使っている所（キーの形・アニメ・ウェイトなど）も一緒に変わります

**ビューの上の帯（文脈の帯）**：選んだ物で次にできることが出ます。

- 組み立て：パーツ →［メッシュを作り直す］［ワープデフォーマを作る］［ウェイトを自動で付ける］［パラメータを足す］、ワープデフォーマ →［顔の向き］［細かくする］［球］、骨 →［物理のチェーン］［ウェイト］、パラメータ →［2 点］［3 点］［既定に］。何も選んでいない時は「次の一手」の 1 行
- アニメ：「自動キー：入／切」（押すと切り替わる）、今のアニメと時間、選んだ物を動かすパラメータの小さなつまみ。つまみを動かすと今の時間にキーが入ります（アニメが無ければ、最初に動かした時に作ります）。骨は画面でつかんで回してもキーが入ります。パーツを画面でつかんで引くと、そのパーツが付いている骨が回って、キーが入ります（Spine と同じ。クリックだけならパーツを選びます。根の骨にしか付いていないパーツ・ワープデフォーマの中のパーツは、上の帯のつまみで動かします）
- 右端の虫眼鏡：機能を名前で探す（F3）。名前のほか、したいこと（「腕を曲げる」「揺らす」「まばたき」「隠す」「左右」など）でも引けます（名前で見つかった物が先、したいことで見つかった物はその言葉を（）で添えて後に）

道具はメニューの下：**選ぶ**／**骨を作る**／**ウェイトを塗る**／**変形ブラシ**（D）。ウェイトの筆には、**柔らかさ**（0 で円の中はどこも同じだけ、100 で縁に向かって弱くなる。はじめは 100）と**上限**（塗る時、骨の重みをこの % までにする。それより高い所はそのまま。消す時は効かない）があります（この PC に覚えます）。変形ブラシは、選んだパーツの頂点を筆でなでて動かします（真ん中ほど引いた通りに、縁へ行くほど少なく。1 回なでるのが 1 歩）。キーの上ならそのキーの形に、そうでなければ基準の形になります。筆の大きさと強さは道具の右の帯で（[ と ] でも大きさ）。強さは真ん中が引いた分の何 % 動くか（はじめは 100%）。頂点の動かし方のモードに従います（格子に沿う＋Shift で格子の線の片方だけ、辺に沿うで各頂点が自分の辺の上だけ、吸い付く・Ctrl で近くの頂点や格子に吸い付く）。

**ウェイトを写す**（変形 → ウェイトを写す…）：選んだパーツのウェイトを、ほかのパーツへ 1 歩で写します。はじめは「左右反転」が入り、反対側のパーツ（armL なら armR、髪_左 なら 髪_右）にチェックが付いています。写す先の各頂点は、元のメッシュの同じ場所（左右反転なら鏡に映した場所）のウェイトを読み、骨は反対側の名前（armL ↔ armR、Left ↔ Right、左 ↔ 右）があればそれに入れ替わります。鏡の x は、はじめは元と先を合わせた真ん中です（自分にチェックすれば左右対称に）。左右反転を外すと、そのまま別のメッシュへ写せます（服の袖に腕のウェイトを写す、など）。ワープデフォーマの中のパーツには写しません

**クリック時の選択範囲**：パーツ（またはワープデフォーマ）を選んでいる時、道具の右に出ます。カーソルからこの距離（画面の px、既定 5、2〜40）の中にある頂点・ワープデフォーマの点を、クリックで拾います。メッシュの編集の中では、範囲の中に点があればクリックでその点を選び、無ければ頂点を打ちます（2 つ以上あれば一番近い点）。カーソルを乗せると、拾われる頂点の周りに範囲の輪が出ます（見た目と判定が同じ大きさ）。範囲を変えている間は、全部の頂点に輪が出るので、隣と重なっているかが分かります（重なる所は一番近い頂点）。Alt を押している間は、カーソルの周りに範囲の輪が出ます。

**穴を探す**（パーツ → 穴を探す（動かすと抜ける所）…）：各パラメータを両端まで動かした姿と、いくつかのランダムポーズで、絵の無い所（背景が抜ける所）を探します。休みの姿にもある切れ目（腕と体の間など）は数えず、外へ開いている所（腕を広げた跡など）も穴にしません。見つかった姿が穴の大きい順に窓に並び、一番大きい物がビューに桃色で出ます。「見る」でその姿と穴を出し、「描き足す」を押すと、その姿のまま、穴を覆っているパーツ（同じなら後ろの物）の絵に描き足しが始まります（桃色は描き足しを終えるまで残ります）。描いたら「もう一度探す」で確かめます。覆うパーツが無い時は、後ろのパーツのメッシュを広げてから探します

**絵を描き足す**（パーツを選んで「パーツ → 絵を描き足す」）：選んだパーツの絵に、ビューの上で直接描きます。動かした姿の上でも描けます（帯の「ランダムポーズ」で動かしたまま、パーツの間のすき間を見つけて描けます）。帯で、筆・消しゴム、色、大きさ、濃さ（%）を選びます。Alt＋クリックで、パーツの絵のその所の色を取ります（スポイト）。「縁を塗り足す」は、パーツの絵の縁を打った px だけ外へ広げます（となりの色で）。動かした時に、パーツの間から背景が見えにくくなります。描けるのは、そのパーツのアトラスの四角の中だけで、ほかのパーツの絵は変わりません。1 回なでるのが 1 歩で、保存の .ugo9 に入ります。Esc か「終わる」で終わります。**PSD への書き戻し**（ファイル → 描き足しを PSD に書き戻す…）：描き足したパーツの絵を、元の PSD のそのレイヤーに書き戻します（ほかのレイヤーはそのまま。マスクのあるレイヤーは、マスクを掛けた分を戻して書くので、マスクが 2 度掛かりません）。PSD は見張っている物、無ければ選んだ物です。はじめは別の名前（「〇〇_直し.psd」）で保存します。デスクトップ版で元の PSD そのものを選ぶと、上書きしてよいか聞き、先に同じ所へ控え（「〇〇_控え_日時.psd」）を残します。ブラウザ版はダウンロードです。文字・スマートオブジェクト・塗りつぶし・調整のレイヤー、同じ名前のレイヤーが 2 つある時などは書き戻せず、理由が出ます。マスクが外を隠すレイヤーでマスクの外に描いた所は、PSD では見えないと知らせます。書き戻すまでの描き足したパーツは作業ファイルに覚えます

**デフォーマが動かす物・上のデフォーマへ**：ワープデフォーマか骨を選ぶと、それが動かす物（中のワープデフォーマ・子の骨・パーツ）が、一覧で色付きになります。深い物ほど薄くなります。ワープデフォーマの時は、ビューでもそのパーツがうっすら色付きになります。ビューで（選ぶ道具で）パーツをダブルクリックすると、そのパーツのワープデフォーマか骨（1 つ上のデフォーマ）が選ばれます。もう一度ダブルクリックすると、さらに上へ上がります。インスペクタの「↑ 〇〇 へ」も同じです。パラメータを選ぶと、インスペクタに「このパラメータで動く：」と、そのパラメータで動くワープデフォーマと骨が並び、押すとそれが選ばれます

**描いて足す**（パーツを選んで「パーツ → 描いて足す…」）：選んだパーツのすぐ手前に、同じに動く新しいパーツを作り、そこに線や形を描きます（口の線、口の中の影、ハイライトなど）。「空の絵から」か「この絵の写しから」（PSD のレイヤーの絵を元に描き直す）を選ぶと、そのまま「絵を描き足す」の筆・消しゴム・縁の塗り足しになります。新しいパーツは、元のパーツのメッシュ・骨とウェイト・ワープデフォーマ・キーの形・不透明度・グルーを受け継ぐので、同じに動きます。描いた物は、そのパーツだけの絵（draw_〇〇.png）としてモデルに入ります。ふつうのパーツなので、メッシュを直す・マスクを掛ける・マスクに使う、ができます。書き出した .ug9 の中では絵なので、Unity・Godot・Unreal・Web のどれでもそのまま動きます（形式は変わりません）。描ける所は、元のパーツのメッシュの広さです。口の中を切り抜くマスクは「マスクを描く」で作ります。PSD を読み直しても、描いたパーツの絵は残ります。作るのも 1 回なでるのも 1 歩です

**線と形**（描いて足したパーツで「絵を描き足す」の帯 →「線」「形」）：「線」は、なぞった線を離した所で置きます。太さの変え方は「太さ一定」「入り・抜き」（両端を細く）「真ん中を細く」で、いちばん細い所を % で決めます。ペンの筆圧も掛かります。色は「一色」「始め→終わり」「両端だけ別の色」で、2 つ目の色は右の色です（例：両端だけ黒、真ん中は赤茶）。置いた直後なら、太さや色を変えるとその線が置き直されます（1 歩のまま）。「形」は、ぐるりとなぞった形の中を塗ります。2 つ目の色を選ぶと、長い方の向きに 2 色のグラデーションになります。線の途中に切れ目を入れる時は、消しゴムで 1 回クリックします。動きで切れ目を開け閉めしたい時は、マスクのパーツ（「マスクを描く」）で隠します（白目と黒目と同じ仕組み）。**限り**：描いた線は絵（アトラスの中の画素）です。口が大きく開いてメッシュが伸びると、線の太さも一緒に伸びます。開いた時に線を細くしたい・形を変えたい時は、開いた口用の線を別に描いて不透明度のキーで入れ替えるか、メッシュの形のキーで細らせます。開け閉めしても太さが変わらない線（ベクターのまま描く線）は、形式に足す物なので、今はありません

**マスクの一覧**（パーツ → マスクの一覧…）：どのパーツがどのパーツの形の中に描かれるか（マスク・反転・マスク専用）を、全部のパーツについて一つの表で見られます。行に印を付けたパーツについて、上で選んだパーツ（または 📁 PSD のフォルダ）を「マスクに足す」「マスクから外す」、「マスクを全部外す」、反転・マスク専用のオン・オフをまとめてできます（どれも 1 歩）。PSD のフォルダをマスクにすると、その中のパーツ全部がマスクになり、PSD を読み直すとフォルダの今の中身に合わせて直ります（手で足したパーツはそのまま）。書き出す .ug9 には、その時のパーツの並びが入ります

**マスクを描く**（パーツを選んで「パーツ → マスクを描く」、上の帯にも）：選んだパーツに、筆と消しゴムで描くマスクを付けます。マスク専用のパーツ（「パーツ名_mask」。同じメッシュ・骨・ウェイト・キーの形）と、その絵ができ、はじめは全部見えるので何も変わりません。消しゴムでなぞった所はパーツが見えなくなり、筆でなぞると戻ります（Alt を押している間は逆）。帯のつまみで筆の大きさ。1 回なぞるのが 1 歩の取り消し。Esc か「終わる」で終わり、もう一度「マスクを描く」で続きを描けます。基準の形の時だけ描けます。もうマスクのあるパーツには付けられません（描いたマスクと足し合わされて、見える所が広がるため）。描いた絵は保存の時に `mask_パーツ名_mask.png` として書かれます。「ファイル → 描いたマスクを PSD に足す…」で、描いたマスクを元の PSD に隠したレイヤー（白、名前はマスクのパーツの名前）として足して保存できます（見張っている PSD、無ければ選んだ PSD）。描くアプリでそのレイヤーを直して PSD を読み直すと、直した形がマスクに戻ります（メッシュはそのまま）

**メッシュの編集**（パーツを選んで Ctrl+E、パーツのダブルクリック、「パーツ → メッシュを編集」）：絵は変えずに、網（頂点と三角形）だけを直す作業の場です。ほかのパーツは薄くなります。基準の形の時だけ入れます。

- クリック：範囲の中に頂点があれば選ぶ（引けば動く）、無ければ頂点を打つ。網の中なら三角形が分かれ、網の外なら一番近い縁とつながります
- Alt＋クリック：範囲の中の頂点を消す。Delete でも選んだ頂点を消せます
- 「三角形をつなぎ直す」（Ctrl+R）：頂点はそのままで、三角形だけを作り直します（細長い三角形が減ります）。キーの形・ウェイトはそのまま
- 「メッシュを作り直す」：絵から作り直します
- 「外周に均等なメッシュ」：絵の外形に「間隔」ごとに点を打ち、「幅」だけ内側に同じ数の点の帯を作り、中は粗く埋めます（輪郭に沿って曲がる髪・服のすそなど向け）。キーの形・ウェイトは新しい点へ移ります
- **ミラー**（上の帯）：オンの間、頂点を打つ・消す・動かすと、軸の反対側の頂点にも同じことをします（動きは左右反対、上下は同じ。Live2D のミラー編集）。軸は「キャンバスの中心」か「パーツの中心」で、点線で見えます。軸の上の頂点は 1 つだけです。オン・オフと軸はこの PC に覚えます
- **細かさを変える**（上の帯）：マス目の大きさ（px）を打って押すと、メッシュを作り直します（小さいほど細かい）。キーの形とウェイトは新しい頂点へ移ります。メッシュの編集の 1 歩に入ります
- **ならす**（上の帯）：「ならす筆」でなでた所の頂点が、まわりの頂点の真ん中へ寄ってジグザグが取れます（1 回なでて 1 歩。大きさと強さは道具の右の帯、[ と ] でも大きさ）。「選んだ点をならす」は、選んだ頂点（選んでいなければ外周の内側の全部）を 3 回ならします。どちらも外周の点は動かさず、絵はその場に残ります（網だけが絵の上で動きます）
- **辺の上に点**：Shift＋クリックで、近くの辺の上に点を打ちます。辺に付いた三角形（1 つか 2 つ）が 2 つずつに分かれ、UV・ウェイト・キーの形は辺の両端から混ぜるので、形は変わりません
- **輪で選ぶ**：頂点をダブルクリックすると、その点と同じだけ外周から内側にある点の輪を選びます（外周の点なら外周の全部）。Shift＋ダブルクリックで今の選びに足します。輪をそのまま動かしたり、「選んだ点をならす」で流れをそろえたりできます
- Ctrl+A でパーツの頂点を全部選び、Delete で選んだ頂点を消します（ミラーの時は反対側も）
- 終わるのは Ctrl+E か「終わる」。1 回の編集が 1 歩で取り消せます。Esc か「やめる」で、入る前の網に戻ります

- 細かいメッシュで、隣の頂点に拾われて打てない時は、範囲を小さくするか、**拡大**します（範囲は画面の px なので、拡大すると頂点の間が広がります。F で選んだパーツを画面いっぱいにできます）
- 頂点を動かしたいのに新しい頂点ができてしまう時は、範囲を大きくします
- メッシュの外には打てません（下の行に出ます）
- 範囲はこの PC の設定で、ファイルには入りません。次に開いた時も残ります

**揺らす…**（変形メニューの一番上）：髪などを揺らしたい時は、まずこれ。選んだ物を動かすパラメータに物理がもうあれば、その物理の窓を開きます。無ければ、選んだ物で道が分かれます（骨の鎖は、骨に長さがあり下を向いている時だけ。横を向いた骨・長さの無い骨は、引き直すように言います）：骨（または、その骨にだけ付いた髪のパーツ）なら、その骨から先が揺れる骨の鎖に。パラメータ（または、パーツを動かす揺らし向きのパラメータ）なら、頭の動きでそのパラメータが揺れるように（物理の窓が開くので強さを決める）。何も選んでいなければ、何を選ぶかを言います。今までの「物理（パラメータの揺れ）…」「物理のチェーンを作る」なども、そのまま使えます

**次の一手**：上の帯で、選んだ物に次にすることのボタンが 1 つだけ色付きになります（4 点のパーツ → メッシュを作る、まだ何も動かさないパーツ → ワープデフォーマを作る／パラメータを足す、キーの形の無いワープデフォーマ → 顔の向きを自動で作る）。ほかのボタンはそのままです

**つまみの値は場ごと**：組み立てで動かしたつまみ（見るための値）は、アニメの場では効きません（アニメはキーだけで動く。Live2D と同じ）。アニメに移る時に、効かなくなった本数を下の行に出します。組み立てに戻ると元の値に戻ります

**選択セット**（Blender のローカルビューに当たる）：重なったパーツを分けて触りたい時、体の部位ごとに作りたい時に使います。左の欄の上の「セット」で：
- ＋：選んでいる物からセットを作ります（名前を聞きます）。パーツならそれだけ、骨ならその骨と下の骨・それで動くパーツ・ワープデフォーマ、ワープデフォーマならその中の物
- セットを選ぶと、その中だけを表示・選択できます。外のパーツは薄くなって選べず、欄でも灰色になります（「外を隠す」で隠す）。骨はセットの中の物だけが出ます
- 「全部に戻る」か **/** キー（表示 → セットの中だけ表示）で全部に戻り、もう一度 / で最後のセットに入ります。入る・出るは取り消しの歩に入りません
- ✎：中身（パーツ・骨・ワープデフォーマのチェック）と名前を直す、セットを消す。作る・直す・消すはそれぞれ 1 歩で取り消せます。セットは作業用の JSON（editor 欄）に入り、.ug9 には入りません

**組み立ての直しは全部のアニメに効く**：アニメのあるファイルで、開いた後やアニメの場から戻った後、組み立てで最初に直した時に、ビューの上に「組み立ての直しは、全部のアニメ（idle・talk）に効きます」と数秒出ます（1 回だけ。押す所はありません）。1 つのアニメの中だけ変えたい時は、アニメの場でキーを打ちます

**下の帯の 1 行**：今の道具で、クリック・ドラッグ・右クリックが何をするかが出ます（選ぶ道具でパーツを選んでいる時は「クリック：頂点を選ぶ · ドラッグ：頂点を動かす…」、ウェイトの筆なら「ドラッグ：選んだ骨のウェイトを塗る · Alt：逆向き」など）。Shift・Ctrl・Alt・Space を押している間は、その時の使い方に変わります

その右の **物理** のチェックが物理のオン・オフです（外すと髪などが止まり、止まった姿で編集できます。「表示 → 物理を動かす」でも同じ）。「表示 → 骨を表示」で骨を見せます。

## はじめての 1 体（近道・7 手）

手持ちの PSD で、開いてから GIF と .ug9 を書き出すまでの最短の道です。PSD のレイヤーの名前と分け方は [PSD の描き方](PSDの描き方.md) にまとめてあります（アプリの「ヘルプ → PSD の描き方」でも読めます）。顔・目・口・体のレイヤーが分かれている PSD を使います。目のレイヤー名に「目」「eye」、口に「口」「mouth」、左右に「L」「R」「左」「右」（または「左目」のようなフォルダ）が入っていると、自動の部分がうまく働きます。

| 手 | すること | 見える物 |
|---|---|---|
| 1 | 「ファイル → 開く…」で PSD を選ぶ（画面に落としてもよい） | 「〇〇 を読んでいます…」の後、左の「パーツ」にレイヤーが並ぶ |
| 2 | 「パラメータ → 自動で作る：下書きをまとめて」 | 顔と目・口のワープデフォーマ、顔の向き（HeadTurnX・HeadTurnY。前のエディタで作ったモデルでは AngleX・AngleY のまま）、目と口の開け閉じ、待機のアニメが一度にできる。下の行に「下書きを作りました：ワープデフォーマ …」 |
| 3 | 右のスライダー（HeadTurnX・EyeOpenL など）を動かして確かめ、「パラメータ → 値をすべて戻す」 | 顔が振り向き、目が閉じる。おかしい所は下の行の「PSD の描き方を見る」から直し方が分かる |
| 4 | 左上の「アニメ」に切り替え、下の「再生」を押す（Space でも） | 待機のアニメ（idle）で、呼吸・まばたき・小さなゆらぎが動く |
| 5 | 「ファイル → 書き出し：画像・動画（GIF・APNG・WebM・MP4）…」で GIF に印を付けて「書き出す」 | GIF ができる（ブラウザでは「ダウンロード」、デスクトップ版では保存先を聞かれる） |
| 6 | 「ファイル → 書き出し：Ugo9 データ（.ug9）」 | ゲームや Web で使う .ug9 ができる |
| 7 | 「ファイル → 保存（.ugo9）」（Ctrl+S）で作業ファイル（.ugo9）を残す | 作業用の JSON とアトラスが 1 つのファイルに入る。次はそれを開くだけ（デスクトップ版はダブルクリックや「最近開いたファイル」からも）。人に渡す時もこの 1 つ |

- 間違えたら「編集 → 元に戻す」（Ctrl+Z）で戻せます。下書きは取り消し 1 回で全部戻ります。もう一度押しても、もうある物は作り直しません
- ここから先（体を骨で動かす、自分でキーを打つ、物理）は、下の「1 つずつ作る（15 手）」と「作る流れ」へ

## 1 つずつ作る（15 手）

近道で作られる物を、自分の手で 1 つずつ作る道です。骨・ウェイト・ワープデフォーマ・キーの打ち方が分かります。

| 手 | すること | 見える物 |
|---|---|---|
| 1 | 「ファイル → 開く…」で PSD を選ぶ（画面に落としてもよい） | 左の「パーツ」にレイヤーが並ぶ。隠れたレイヤーがあると下の行に出る（透明で読み込まれる） |
| 2 | 左の「変形」を押し、メニューの下の道具「骨を作る」（B）を押す | 骨の一覧に root だけ。作り方の説明が出る |
| 3 | 体の下から首までドラッグする | 骨（bone）ができる |
| 4 | 続けて、首から頭のてっぺんまでドラッグする | 1 本目の子の骨（bone2）ができる。これが頭の骨 |
| 5 | 「選ぶ」（V）に戻す。左の「パーツ」で体のパーツを選び、「変形 → ウェイトを自動で付ける」 | 体が骨に付く（体のパーツが複数あれば、それぞれで押す） |
| 6 | 顔（輪郭）のパーツを選び、左の「変形」を押してから「変形 → ワープデフォーマを作る」 | 顔を囲む緑のワープデフォーマができる |
| 7 | 右の「動かす元」で頭の骨（bone2）を選ぶ | ワープデフォーマが頭と一緒に動くようになる |
| 8 | 「パラメータ → 自動で作る：顔の向き（選んだワープデフォーマ）」。「ワープデフォーマに入れますか？」と聞かれたら OK | 目・眉・頬などもワープデフォーマに入る。右上に AngleX（左右）・AngleY（上下）ができる |
| 9 | 「パラメータ → 自動で作る：まばたき」（口のレイヤーがあれば「自動で作る：口の開け閉じ」も） | EyeOpenL・EyeOpenR（と MouthOpen）ができる。足りない物は下の行に出る |
| 10 | 右のスライダーを動かして確かめ、「パラメータ → 値をすべて戻す」 | 顔が振り向き、目が閉じる |
| 11 | 左上の「アニメ」に切り替え、「アニメ → 新しいアニメ」 | 長さ 2 秒のアニメができる |
| 12 | 下の目盛りの 0 を押し、HeadTurnX を左端へ動かして I（キーを打つ） | HeadTurnX の行にひし形のキー |
| 13 | 目盛りの 1 で HeadTurnX を右端へ → I、2 で左端へ → I。「再生」で確かめる | 顔が左右に振り向く |
| 14 | 「ファイル → 書き出し：画像・動画…」で GIF に印を付けて「書き出す」。続けて「ファイル → 書き出し：Ugo9 データ（.ug9）」 | GIF と .ug9 ができる（ブラウザでは「ダウンロード」、デスクトップ版では保存先を聞かれる） |
| 15 | 「ファイル → 保存（.ugo9）」（Ctrl+S）で作業ファイル（.ugo9）を残す | 次に開く時はこの 1 つを開く |

- 間違えたら「編集 → 元に戻す」（Ctrl+Z）で 1 手ずつ戻せます。自動で作る物（8・9）も 1 回で戻ります
- 骨の名前は、骨を選んで「編集 → 名前を変える」（F2）で変えられます（例：bone2 → head）
- 目盛りは 0.05 秒ごとに止まります。Shift を押しながらだと好きな所に置けます
- 髪の骨を頭から下へ垂らすと、左の「変形」の「物理の候補」に出ます。「変形 → 物理のチェーンをまとめて作る」で揺れます

## 作る流れ（PSD から 1 体）

### 1. パーツとメッシュを整える

- パーツを選ぶと、メッシュ（三角形）の線と頂点が出ます
- インスペクタの「細かさ」（px）を決めて「パーツ → メッシュを作り直す」で作り直します。PSD から来たパーツは、絵の輪郭に沿ったメッシュになります
- PSD を開いた直後のパーツは 4 点の四角です。パーツを選んで「パーツ → メッシュを作る」で、そのパーツだけにメッシュを作ります。何も選んでいない時は、まだ 4 点のパーツ全部に作ります（1 回で取り消せます）
- 4 点のままでも、ワープデフォーマ・ウェイトは付けられます（粗く曲がるだけです。聞く画面は出ません）。ワープデフォーマやいくつかの骨で曲げている 4 点のパーツは「問題」の一覧に出るので、そこからメッシュを作るパーツが分かります
- 「パラメータ → 自動で作る」の下書き（まばたき・口・顔の向き・まとめて）は、形を変えるパーツが 4 点なら、そのパーツにだけメッシュを作ってから形を作ります（同じ操作なので、取り消しは 1 回です。下の行に、どのパーツに作ったかが出ます）
- 作り直しても、作ってあるキーの形とウェイトは新しい頂点に移ります
- 描く順は「パーツ → 描画順：手前へ／奥へ」で変えます（インスペクタにもあります）
- 重ね方（通常・加算・乗算・スクリーン）、マスク（このパーツの形の中だけに描く・反転）、色（乗算色・スクリーン色）もインスペクタで決めます（「パーツ → 重ね方・マスク・色…」でその欄へ行けます）

### 2. 骨を置いて、ウェイトを付ける

- 「骨を作る」でドラッグすると骨ができます。選んでいる骨の子になります
- 骨は、**線（針）をつかんで引くと根元を中心に回り**、根元の丸をつかむと動きます（時計の針のように）。回している間は角度が数字で出ます。Shift を押しながらだと 15° 刻みです。選んだ骨の先の白い丸もつかめます。長さの無い骨（PSD のグループから作った骨など）も、40 px の点線の線で出るので、そこをつかめます
- **基準の姿（組み立てで、キーの上でない時）で骨を回す・動かすと、付いているパーツの絵も一緒に付いてきます**（Spine・Live2D と同じ）。キーの形（パラメータの差分）の向きも一緒に回るので、口の開き方などがずれません。1 回の引きを 1 歩で取り消せます
  - 骨の置き場所だけを変えたい時は、Alt を押しながら回すか、上の帯で「骨だけ」を選びます（Alt はその時だけ逆になります）
  - ワープデフォーマの中のパーツは、回転には付いてきません（下の行に出ます）。移動には付いてきます。回して動かしたい時は、パラメータのキーの上かアニメで回します
  - 変わるのは作業用 JSON の頂点とキーの形の値だけで、.ug9 の形は変わりません。「PSD を読み込み直す」と、頂点は PSD の位置から作り直されるので、基準の姿で回した分は戻ります
- 骨を選ぶと、その骨（と子の骨）で動くパーツが薄く色で塗られ、上の帯に「この骨を回すと動くパーツ：…」と出ます。「動かしてみる」で、骨を ±10° ゆらして見せます（文書は変わりません）。動くパーツが無い時は「パーツを付ける…」「ウェイトを塗る」が出ます
- パーツを選ぶと、インスペクタの上に「動かす物：骨 …／パラメータ …」が出ます
- 選んだ骨が動かす物が見えます：その骨にウェイトの付いた頂点に点（青＝少し、赤＝全部）、その骨と子の骨で動くパーツに薄い線
- パーツの「骨」で、パーツを 1 本の骨に付けます。骨を選ぶと出る「この骨で動くパーツ」で、何枚かまとめて付けることもできます
- 何本かの骨で曲げたい時は「変形 → ウェイトを自動で付ける」、「ウェイトを塗る」（W）で直します（パーツを選び、骨を選んでからなぞる。Alt で逆）。「ウェイトを塗る」の間は、道具の右に筆の設定が出ます：大きさ（[ と ] でも）・強さ（1 回になぞって足す量）・「塗る／消す」。どれもこの PC に残ります。パーツを選んだまま骨を選ぶと、ウェイトが色で見えます（青＝0、赤＝1）
- 揺れる髪は、根元の骨を選んで「変形 → 物理のチェーンを作る（選んだ骨から）」。重力・戻る強さなどはその欄で直します
- **IK（腕・脚を先で引いて曲げる）**：腕なら前腕、脚ならすねの骨を選んで「変形 → IK を付ける（選んだ骨の先で引く）」。その骨の先に目標（丸に十字）ができ、丸をドラッグすると、骨 2 本（選んだ骨と親）が肘・膝で曲がって、先が丸に付いてきます。親に長さが無い時は、選んだ骨 1 本が丸の方を向きます。付けても今の姿は変わりません。1 歩で取り消せます
  - 組み立てで丸を動かすと基準の姿、アニメで動かすとその時間に目標の骨の位置のキーが入ります
  - 骨の欄の「IK」：**効き具合**（0 で効かない。アニメではキー）、**曲がる向きを反対にする**（肘・膝の曲がる側。アニメではその時間からのキー）、**目標を選ぶ**、**IK を外す**（目標の骨が IK のためだけの物なら一緒に消えます）
  - 付けられない骨は、メニューに指を置くと理由が出ます：長さの無い骨（先が無い）、ワープデフォーマの中の骨、揺れる鎖の骨、もう IK のある骨
  - 書く物は形式の IK 制約（`constraints` の `type: "ik"`）と、ふつうの骨 1 本（目標）です。目標の骨は、鎖の 1 本目の親の子になるので、体と一緒に動きます
- **パラメータの揺れ**（変形 → 物理（パラメータの揺れ）…）：骨ではなくパラメータを揺らす物理です（Live2D の物理の設定と同じ並び）。左のグループ 1 つが揺れるパラメータ 1 本で、「＋ グループ」で足し、「消す」で消します。右で、入力（揺れを起こすパラメータと重み、「逆向き」で反対へ）、出力（揺れるパラメータ・倍率・最小・最大）、揺れ方（戻る強さ：大きいほど早く追いつく、減衰：大きいほど早く止まる）を直します。1 回の変更が 1 歩。同じパラメータを 2 度入力にする・ほかのグループの出力と同じにするのは、理由を出して止めます。左の一覧で **Ctrl+クリック**すると揺れをいくつも選べ、下の数（倍率・最小・最大・戻る強さ・減衰）を変えると、選んだ全部に入ります（1 歩）。**「ほかのモデルから足す…」**で、ほかの Ugo9 のモデル（.ugo9・.json）の揺れを、今の揺れに足します（Live2D の読み込みと違い、今の揺れは消しません）。出力のパラメータがこのモデルにあり、まだ揺れていない物だけが入り、無い入力は外します。入らなかった物は理由と一緒に下の行に出ます（1 歩で取り消せます）
  - **分かりやすく**：揺れ方の下に、今の数で「1 秒に約 1.1 回揺れて、1 回ほどで止まります（よく揺れる）」のように言葉で出ます（減衰が小さすぎると「暴れやすい：減衰を上げると落ち着きます」）。その下の曲線は、頭を回して戻した時（灰色）の揺れ（色の線、点線は出力の端）で、ランタイムと同じ計算です。「試す（頭を回してみる）」で、ビューのキャラで 1 つ目の入力を端まで回して戻し、揺れを見られます（保存しません）
  - **型から始める**：髪（後ろ髪）・前髪・スカート・胸・アクセサリー・落ち着いた から選んで「この型にする」で、選んだ揺れ（Ctrl+クリックで選んだ物も）の 戻る強さ・減衰・強さ・入力 を、その型の落ち着いた値にします（1 歩）。強さは、頭をいっぱいに回しても出力の範囲を越えないように決めます。型は名前（Hair・前髪・Skirt・Ribbon…）から最初に選ばれます。「＋ グループ」の新しい揺れも、名前の型（無ければ落ち着いた）の値で始まります
- 左の「変形」の「物理の候補」に、名前（髪・リボン・スカート・しっぽなど）から物理で揺れそうな骨の並びが出ます。候補の「チェーンにする」か「変形 → 物理のチェーンをまとめて作る」でチェーンにします。⚠ は上向きの骨です（チェーンは根元から垂れるので、下へ向けて作り直します）

### 3. パラメータとキーの形（顔の動き）

- 「パラメータ → パラメータを足す」で作り、名前・最小・既定・最大を決めます
- パラメータを選んで「両端に（2 点）」「両端と中（3 点）」でキーを作ります。スライダーの上の小さな点（結合した格子では丸）がキーです
- **パラメータのバー**（Live2D と同じ作り）：
  - キーの点の色：パーツ・ワープデフォーマ・骨を選んでいると、その物がそのキーに形を持てば緑の塗り、持たなければ白抜き。何も選んでいない時は灰の白抜き。今の値が乗っているキーは赤い輪
  - 今の値は橙の点。キーの上では塗り、キーの間（形を作れない所）では白抜き
  - 右の欄に値を打てます。欄の上を横にドラッグしても変わります
  - スライダーを押す（またはキーの点を押す）と、下に小窓が出ます：「＋」今の値にキーを足す、「−」このキーを消す（既定の値のキーは消せません）、「▼」このパラメータのキーに形を持つ物の一覧（押すとその物を選ぶ）
  - **まとめて編集**（Live2D のマルチキー編集）：キーの点を **Ctrl+クリック**（小窓の「◇」でも）すると、そのキーがまとめて編集に入ります（点がひし形に）。入れたキーの 1 つに合わせて頂点・ワープデフォーマの点を動かすと、入れた全部のキーに同じ動きが入ります（1 歩で取り消せます）。もう一度 Ctrl+クリックで外します。既定の値のキーは入れられません（基準の形は、もう全部のキーに効いています）。保存はされません。頂点の回転・拡大縮小（枠のつまみ）、変形ブラシ、骨の回転・移動（ビューで引く）も、入れた全部のキーに同じだけ入ります。キーの所では、骨のインスペクタに「そのキーでの」回転・拡大・位置が出て、打った値が入れた全部のキーに入ります。パーツの不透明度・色（キーの所）も同じです
  - **キーを全部まとめて編集**（パラメータ → 選んだパラメータのキーを全部まとめて編集）：選んだパラメータの既定以外のキーを全部まとめて編集に入れます（もう一度で外す）。Ctrl+クリックを知らなくても使えます
  - **パラメータをまとめて動かす**（Live2D の複数パラメータの同時操作）：パラメータの名前を **Ctrl+クリック**（または選んで「パラメータ → 選んだパラメータをまとめて動かす組に入れる」、もう一度で外す）で 2 つ以上選ぶと（名前に ⇆）、そのどれかのつまみを動かすと、全部が範囲の同じ割合だけ動きます（例：BodyAngleX を 0 → 5（範囲の 4 分の 1）で、BrowY も 0 → 0.5）。アニメの場で自動キーなら、全部にキーが入って 1 歩です。もう一度 Ctrl+クリックで外します。保存はされません
  - スライダーの右クリックで、一番近いキーへ。ダブルクリックで既定の値へ
  - 名前をドラッグすると並べ替えられます（結合した 2 本は一緒に動きます）。並びはファイル（作業用 JSON の `editor`）に保存されます
  - 名前の右クリック：名前を変える・パラメータを足す・複製（範囲だけ。キーは写しません）・消す
  - 名前の右の「：」を左右にドラッグすると、名前の幅が変わります（この PC の設定）
  - 名前をダブルクリックすると（または「パラメータ → キーを手で編集…」）、キーの窓が開きます。目盛りを押すとそこにキーを足し、キーの印を押すと消します。表の値を打ち直すと、キーがその値へ動きます（形はそのまま。隣のキーを越えては動かせません。既定の値のキーは動きません）
- **パラメータのグループ**（パラメータ → パラメータのグループを作る）：パラメータの欄に 1 段のフォルダを作ります（選んでいるパラメータはその中へ）。名前をグループの見出しへ引くと中に入り、グループの外の行の間へ引くと出ます（結合した 2 本は一緒）。見出しのクリックで開く・閉じる、ダブルクリックで名前を変える、右クリックで消す（中のパラメータは残る）。グループはファイル（作業用 JSON の `editor`）に保存されます
- **パラメータの一覧**（パラメータ → パラメータの一覧…）：すべてのパラメータの名前・最小・既定・最大を 1 つの表で直せます。名前を変えると、使っている所も一緒に変わります。キーが外に出る範囲や、キーの形がある間の既定の値の変更は、理由を出して止めます。右の数（キーの数）を押すと、そのパラメータのキーの窓が開きます
  - 欄の上の帯：「2 点」「3 点」（選んだパラメータにキーを作る）、「キーを全部消す」（既定の値のキーだけ残す）、「絞り込み」（選んだパーツ・ワープデフォーマ・骨を動かすパラメータだけ出す）
- **キーの上で**頂点・骨・ワープデフォーマの点を動かすと、そのキーの形になります。キーとキーの間は形が混ざります
- キーの間で動かそうとすると「ここにキーを作る」が出ます
- 2 本のパラメータを両方キーの上に置くと、**角の形**（例：右を向きながら上を向いた時だけの補正）を作れます
- **パラメータの結合**：各行の左の鎖のボタンを押すと、すぐ下のパラメータと結合し、2 本のつまみが 1 つの格子になります（横が上のパラメータ、縦が下のパラメータ）。AngleX と AngleY は、はじめから結合しています。格子の中をドラッグすると 2 本が一度に動くので、四隅（角の形）を確かめられます。丸はキーの組み合わせで、選んだ物がそこに形を持つと緑に塗られます。近くまで動かすと吸い付きます（Alt で吸い付かない）。Shift を押しながらだと横か縦だけ、右クリックで一番近い丸へ、ダブルクリックで既定の値へ。右の欄に打つと 1 本だけ変わり、欄の右の「＋」「−」でその値にキーを足す・消すができます。もう一度鎖を押すと外れます。離れたパラメータと組む時は、片方を選んで「パラメータ → 相手をすぐ下に動かして結合 ▸」から相手を選びます。組はファイル（作業用 JSON の `editor`）に保存されます
- **一部だけ直した角**：結合した 2 つ（顔の向きなど）で、あるパーツの角の形を 1 つだけ直し、ほかの角が 2 つの形の足し算のままだと、動かした途中で形が飛ぶ事があります。その時は問題の一覧（表示 → 問題の一覧）に「face：AngleX×AngleY の角を 30×30 だけ直してあり、-30×-30・… は足し算のまま」と出ます。クリックするとそのパーツを選び、足りない角にスライダーを動かすので、そこで形を直してください（全部の角を直すか、全部を足し算に戻す（パラメータ → 四隅の形を作り直す）と消えます）
- 不透明度と色も、キーの上で変えるとそのキーの値になります
- **動きを反転して反対のキーへ**（パラメータ → 動きを反転して反対のキーへ）：選んだパーツ・ワープデフォーマ・骨の、今のキーの形を左右反転して、既定の値の反対側のキー（AngleX の +30 なら −30）に入れます。キーが無ければ作ります。名前で左右の相手（eyeL と eyeR、_L と _R、左と右など）が分かる時は、相手の形を反転して入れます（顔を回すと、近い目と遠い目が入れ替わるため）。片側だけ作れば反対側は 1 手です。四隅（AngleX 30 × AngleY 30 など）でも使え、左右の軸（名前に X のあるパラメータ）だけを反対側へ移します（AngleX −30 × AngleY 30）。名前の左右は、後ろ（eyeL・eye_L）だけでなく前（L_eye）でも分かります
- **形を初期に戻す**（パラメータ → 形を初期に戻す（このキー）・（全部のキー））：選んだワープデフォーマ・骨・パーツの、今のキー（四隅も）の形を消して基準の形に戻します（Live2D のデフォーマの初期化）。まとめて編集で入れたキーがあれば、その全部に。「全部のキー」は、どのキーにも形が無い、作った時の姿に戻します。どちらも 1 歩で取り消せます
- **形をコピー・貼り付け**（編集 → 形をコピー Ctrl+Alt+C／形を貼り付け Ctrl+Alt+V）：選んだ物の今のキーの形を覚え、別のキーに入れます。同じ物か、同じ数の点の物（パーツの頂点・ワープデフォーマのマス）に貼れます
- **四隅の形を作り直す**（パラメータ → 四隅の形を作り直す、Ctrl+4）：結合した 2 本の片方を選ぶと、2 本の角の補正を消し、四隅を 2 本の形の足し算に戻します（聞いてから。取り消せます）
- **今の形を基準にする**（パラメータ → 今の形を基準にする）：つまみを動かして見えている形を、パーツの基準の形（パラメータが全部既定の時の形）にします。動かしているパラメータのキーは、見た目が変わらないように直ります（例：口を AngleX +30 にして押すと、既定の形が +30 の形になり、+30・-30 のキーはそのまま）。パーツを選んでいればそれだけ、選んでいなければ全部のパーツ。2 本以上を既定から動かしている時は、混ぜた時の形が少し変わるので、押す前に聞きます。1 歩で取り消せます。対象はパーツの頂点の形だけです（ワープの格子・骨・不透明度は変わりません）
- **記録する物**：キー（か角）の上にいる時、ビューの上の帯に「記録：形・不透明度・色・骨」のスイッチが出ます（押すと入・切。この PC に残ります）。切った物は、キーの上で変えても、キーではなく基準（パーツ自身の不透明度・色、基準の形・姿）が変わります。例：口の開くキーの上で、目の不透明度だけを全体で下げたい時は「不透明度」を切って変えます。形を切るとワープデフォーマの点は動かせません（基準の点は、キーの外で動かします）
- 記録する物ごとに、キーのデフォーマが分かれます（形・不透明度・色・骨）。同じキーでも、あとから不透明度のキーだけを消す・直す時に、形を巻き込みません
- ビューポートの左下に、今何を編集しているかが出ます

- 「パラメータ → 自動で作る：まばたき」「自動で作る：口の開け閉じ」で、パーツの名前（目・まぶた・口・唇など、日本語・英語）から、目を閉じた形（EyeOpenL・EyeOpenR が 0）と口を開いた形（MouthOpen が 1）のたたき台を作ります。足りないパラメータは作ります。見つからない物や、うまく分かれていないレイヤーは状態の行に出ます。もう作ってある形を置き換える時は確かめます

**形の足し方（Live2D のブレンドシェイプ）**：Ugo9 のキーの形は、もともと全部「基準の形との差を足す」作り（Live2D のブレンドシェイプと同じ）です。パラメータを選ぶとインスペクタに「形の足し方」が出ます。結合した 2 本は「四隅も直せる」（2 本を一緒に動かした時の形を直せる。Live2D の通常のパラメータ）、それ以外は「足し算だけ」。ボタン 1 つで行き来できます（パラメータ → 足し算だけにする（ブレンドシェイプ）、も）。

**負の側（Live2D の負の重み）**：「パラメータ → 反対側に −1 倍のキーを作る」で、既定より上のキーの形を −1 倍にしたキーが、既定より下の同じ所にできます（範囲も広がります）。口を開くキーから、口が反対に動く形がすぐできます。

**基準の形**：パラメータが全部既定の時の形は、そのまま「基準の形」として直せます（左下に「基準の形を編集」）。今見えている形を基準にするのは「パラメータ → 今の形を基準にする」。

### 4. ワープデフォーマ（顔全体を曲げる）

- パーツを選び、「変形 → ワープデフォーマを作る」で、そのパーツを囲むワープデフォーマができます
- **ワープデフォーマをまとめて作る…**（変形 → ワープデフォーマをまとめて作る…）：印を付けたパーツに 1 つずつ、そのパーツをぴったり囲むワープデフォーマを一度に作ります（Live2D では 1 つずつ）。名前は「パーツ名_warp」、マス目の数はパーツの大きさとマス目の大きさ（px）から、余白（px）も選べます。初めは、まだワープデフォーマに入っていないパーツに印が付いています。ワープデフォーマの中のパーツは、その中に作ります。ウェイトのあるパーツ（ワープデフォーマに入れるとウェイトが外れる）とマスク専用のパーツは選べず、理由が出ます。1 歩で取り消せます。パーツの向きに合わせて斜めに囲む形は、形式 0.8 の後で
- ワープデフォーマの点は、パラメータをキーの上に置いてから動かします（振り向きの形など）
- 基準の形（パラメータが全部既定）では、ワープデフォーマの**四角そのもの**を変えられます：選んだワープデフォーマの線を引くと動き、四隅（塗りつぶした四角）を引くと、反対の隅を止めて大きさが変わります。中のパーツ・骨・中のワープデフォーマも一緒に動き、大きさを変えた時はキーの動きも同じ割合で伸び縮みします（形の見た目が崩れない）。**Ctrl** を押しながらだと四角だけが変わり、中の物はそのままです。1 回の引きが 1 歩
- 顔を囲むワープデフォーマを選んで「パラメータ → 自動で作る：顔の向き（選んだワープデフォーマ）」で、HeadTurnX（左右）と HeadTurnY（上下）の両端と 4 つの角に、振り向きの形が一度にできます（パラメータがなければ作ります）。そこから点を動かして直します。取り消しは 1 回で戻ります
- ワープデフォーマを選んで「骨を作る」でドラッグすると、ワープデフォーマの中の骨（回転デフォーマ）になります。目や眉を、ワープデフォーマと一緒に回せます

### 4b. 球・円柱（顔や体を丸く回す）

四角のワープデフォーマだけで顔を回すと、四隅で歪みます。球（楕円体）や円柱が回るように動かす道具を使うと、顔は球の面に沿って回り、外はなめらかに止まります。結果はワープデフォーマのキーの形に**焼き込む**ので、書き出す .ug9 の形は今までと同じです。

- 顔のパーツ（または顔のワープデフォーマ）を選び、「変形 → 球を作る」（体のひねり・腕・脚は「変形 → 円柱を作る」）。作った球は左の「変形」の「球・円柱」に並ぶ
- ビューポートで、真ん中の四角をつかむと動き、右と下の四角で大きさが変わる。実線が球、破線が「正確な球の範囲」、点線が「動きが 0 になる所」（減り方の幅）
- インスペクタで、奥行き・回すパラメータ・端で回す角度・キーの間隔（既定 10°）・伸び縮みを決めて「変形 → 球・円柱を焼く」。設定を変えたら同じ項目でもう一度焼く（前に焼いた物だけが置き換わり、手で作ったキーは残る）。「変形 → 球・円柱の焼いた物を外す」で消せる。どれも取り消し 1 回で戻る
- ワープデフォーマが無いパーツに作った時は、焼く時に 14×14 のワープデフォーマを作る
- 焼いたワープデフォーマが球に対して粗い（球の幅に 7 マスより少ない）と、左の「問題」に出る。ワープデフォーマを選んで「変形 → ワープデフォーマを細かくする」（縦横 2 倍。キーの形はそのままで、見た目は変わらない）の後、もう一度「変形 → 球・円柱を焼く」
- **減り方の幅は球ごとに変えられる**（「動きが 0 になる所」、既定 1.6）。大きく回すと、正確な範囲と点線の間の帯が、回る向きの側で詰まって見えることがある。幅を広げると詰まりが緩む代わりに、外も少し動く
- パーツのインスペクタの「奥行き（球の上）」で、目・鼻は手前（＋）、耳・後ろ髪は奥（−）にすると、回した時に視差が付く
- 「自動で作る：顔の向き」「自動で作る：下書きをまとめて」も、同じ球の焼き方を使う

### 4c. 線に沿って流す（汗のループなど）

- パーツ（またはワープデフォーマ・骨）を選んで「変形 → 線に沿って流す（汗のループ）」。続けてビューをクリックして線の点を打ち、Enter かダブルクリックで終わります（Backspace で 1 点戻す、Esc でやめる。点を打たずに Enter なら、選んだ物から下へ 4 点の線）。その線を流すループのアニメ（線の名前）ができます
  - パーツは、最初の点から流れ始めます（打った線が離れていれば、そこへ移って流れる）
  - パーツなら、それを運ぶ骨（`<パーツ>Flow`）が、元の骨の子として作られ、パーツはその骨に付きます。パーツがワープデフォーマの中にあれば、骨が格子の中に作られ、パーツは格子から出てその骨に付きます（線は格子と一緒に曲がります。パーツの形は格子で曲がらなくなります）
  - ウェイトで複数の骨に付いたパーツは、聞いてから、ウェイトを外し、一番強く付いていた骨の子の骨で運びます（形は曲がらなくなります。取り消せます）
  - 別のワープデフォーマの中の格子は流せません（下の行に理由が出ます。外側の格子を選んでください）
- 線を選ぶと（変形の欄の「線」）点が出ます。点を引いて動かす、線をダブルクリックで点を足す、Alt＋クリックで点を消す
- 点を押すと、その点のハンドル（曲がり方）が 2 つ出ます。ハンドルを引くと線が曲がり、反対側も一緒に回ります（Alt を押しながらだと片側だけ）。インスペクタの「角にする」でハンドルを無くし、「なめらかにする」で元のなめらかな曲がりに戻します
- インスペクタで、ループの長さ（秒）、輪にする（最後の点から最初の点へ）、線の向きに回す、点ごとの不透明度と速さ（点の間の速さの比。2 なら倍の速さ）を決めます。初めは両端の不透明度が 0 で、流れ始めと終わりが消えます
- インスペクタの「流し方」で、**時間**（線のループのアニメ）か、**パラメータ**（つまみを動かすと線の上を進む）を選べます。「新しいパラメータで」なら線の名前で 0〜1 のパラメータを作ります。パラメータの時は、骨の動きと不透明度を変形に焼きます（初めは両端の不透明度が 0 なので、既定の値 0 では見えません。汗が出る・引くのをパラメータで操る時の形）
- 直すたびに、骨の位置（と向き）とパーツの不透明度のキーを作り直します（1 歩で取り消せます）。線そのものは作業用の JSON（editor 欄）に入り、書き出した .ug9 には焼いたキーだけが入ります
- 「線を消す」は、線と焼いたキーを消します。作った骨とアニメは残ります（他で使っているかもしれないので）

### 5. グルー

- 2 つのパーツのつなぎ目（腕の上下など）を一緒に動かす時は、パーツの欄で相手と距離を選び「重なる頂点をグルーにする」
- グルーを付けたまま、メッシュの編集・作り直し（細かさを変える）をしてかまいません（Live2D のように先に外す必要はありません）。作り直す時は、グルーの頂点を新しいメッシュに残すので、組はそのままです。新しいメッシュの外に出た頂点の組だけが外れ、下の行に数が出ます
- **パーツを複製**（パーツ → パーツを複製、Ctrl+D）：選んだパーツをすぐ手前に写します。メッシュ・絵・骨とウェイト・ワープデフォーマ・重ね方・マスク・色、キーと四隅の形と不透明度、アニメの不透明度、そして**グルー**（同じ相手と同じ組で。Live2D の複製ではグルーが外れます）も一緒です。写した方が選ばれます（1 歩）

### 6. アニメ

**アニメの一覧とフォルダ**：アニメの場では、時間軸の左に「アニメの一覧」が出ます。名前を押すとそのアニメ。「＋ フォルダ」（または アニメ → アニメのフォルダを作る…）でフォルダを作ると、選んでいるアニメが入ります。アニメの名前をフォルダの見出しへドラッグで入れ、一覧の下へドラッグで出します。見出しを押すとたたむ・開く、ダブルクリックで名前を変える、右クリックで消す（中のアニメは残ります）。フォルダは作業ファイルだけの物で、書き出した .ug9 のアニメの名前は変わりません

- 左上の「アニメ」に切り替え、「アニメ → 新しいアニメ」で作ります。長さとループを決めます
- **パラメータ**：時間を決め、スライダーを動かすと、その時間にキーが打たれます（「アニメ → 自動でキーを打つ」。最初から印が付いています。外すと、スライダーは見るだけになり、キーは「キーを打つ」（I）で打ちます。どちらにしたかは覚えます）
- **骨**：アニメの時に骨を回す・動かすと、その時間に骨のキーが入ります
- **色**：アニメの時に色の欄を変えると、色のキーになります
- **待機のアニメ**：「アニメ → 待機のアニメを作る」で、呼吸・まばたき・小さなゆらぎをくり返すアニメが 1 回でできます（モデルにあるパラメータだけを使います。まばたきには先に「自動で作る：まばたき」、ゆらぎには「自動で作る：顔の向き」が要ります）。待機のアニメ（idle）がもうある時は、置き換える・idle2 などとして足す・やめる、を聞きます
- **物理をアニメに焼き付ける**（アニメ → 物理をアニメに焼き付ける…）：物理の揺れ（物理で動くパラメータと、揺れる鎖の骨）を、今のアニメか全部のアニメのキーにします（1 歩）。物理を持たない書き出し先や動画のためです。ループするアニメは 1 周回してから焼くので、揺れがつながります。焼いた後に「物理を切りますか？」と聞きます。残すと、焼いた揺れと物理の揺れが二重に動きます（切るのも 1 歩で取り消せます）
- **音と拍**：時間軸の上の帯の「♪ 音を付ける…」で、どのアニメにも音（曲・声）を付けられます。時間軸の一番上に波形の行が出て、再生で一緒に鳴ります（音はファイルに入れず、名前だけ覚えます。開き直したら選び直します）。「拍を探す」で音から拍の速さ（BPM）と最初の拍を探し、時間軸に拍の線が出ます（小節の頭は濃く）。BPM と最初の拍は打ち替えられ、線の細かさは拍・半拍・4 分の 1 から選べます（作業ファイルの editor に覚えます。1 歩）。「拍に吸い付く」が入っていると、時間の線やキーを拍の線の近くへ動かした時、拍にぴったり合います（Shift を押すと吸い付きません。この PC の設定）
- **時間を挟む・詰める・くり返す**（アニメ メニュー）：「時間の線に空きを挟む…」は、時間の線から後のキーを決めたコマ数（fps も決める）だけ後ろへずらします（1 コマずつずらす、間を空ける）。「時間の線から詰める…」は、その間のキーを消して後ろを前へ詰めます。どちらも「選んだキーのトラックだけ」にでき、アニメの長さも変わります。「選んだキーの範囲をくり返す…」は、選んだキーの最初から最後までを、すぐ後ろに何回か並べます（「往復」で 1 回おきに逆さま＝ピンポン。曲線も逆向きに）。どれも 1 歩
- **中割りのキー**（アニメ メニュー →「中割りのキーを打つ…」）：時間の線の所に、前のキーと次のキーの間の値でキーを打ちます（前と後ろの両方にキーがあるトラックごと。「選んだキーのトラックだけ」も）。つまみ（0＝前のキー、100＝次のキー。0〜100 を越えると行き過ぎ・引き戻し）を動かすと、そのままキャラに出ます。「打つ」で 1 歩、「やめる」・Esc なら残りません。0・25・50・75・100 のボタンも。すでにその時刻にキーがあれば値だけ変わります
- **グラフで見る**（アニメ メニュー →「グラフで見る」、ウィンドウ メニュー →「グラフ」）：時間軸の隣に「グラフ」のタブが出て、トラックの値が時間のグラフになります（選んだキーのトラック。「全部のトラック」で、このアニメの全部）。色のトラックは出しません。キー（ひし形）を掴むと時間と値が動きます（前後のキーは越えません。時間は 60 分の 1 秒に揃います）。曲線のキーは、2 つの取っ手（丸）を掴んで曲がり方を変えます。どちらも動かす間そのままキャラに出て、離した所で 1 歩です。Shift を押していると、横（時間）か縦（値）の片方だけ動きます。何もない所をクリックすると時刻が動きます。「それぞれの高さ」で、値の大きさが違うトラックも、それぞれグラフの高さいっぱいに出ます

- **別のモデルからアニメを持ってくる**（アニメ メニュー →「別のモデルからアニメを持ってくる…」）：ほかのモデル（.ugo9・.json・.ug9）のアニメを、このモデルに写します。窓で、写すアニメと、元のパラメータをこのモデルのどれに写すかの表を決めます。表の候補は自動で出ます（同じ名前 → 標準の名前と前の名前（AngleX と HeadTurnX など）→ Param の付いた名前（ParamAngleX など）→ 似た名前）。見つけ方も出ます。プルダウンで別のパラメータか「（写さない）」を選べます。ほかの行で使っているパラメータには「（〇〇で使用中）」と出ます。2 つが同じパラメータへ行く時は知らせが出て、先の方だけが残ります。値は、元の幅からこのモデルの幅へ合わせて写します（-45〜45 の 45 は -30〜30 の 30）。同じ名前のアニメがある時は、別の名前で足す・置き換える・写さないから選びます。「無いパラメータは足す」で、結び付けていない元のパラメータを足して写せます。決めた表は、この 2 つのモデルの組ごとにこのパソコンに覚え、次に開くと「前に決めた」として出ます。持ってくるのは 1 歩です
- **選んだキーの値をまとめて変える**（アニメ メニュー →「選んだキーの値を変える…」）：時間軸で選んだキーの値を一度に変えます。時間と動き方はそのままです。「足す」（決まった量を足す）・「倍にする」（基準から離す・寄せる。振れ幅を大きく・小さく）・「反転」（基準で折り返す）・「同じ値に」から選びます。基準は 0・既定の値（パラメータの既定値、骨は 0、不透明度は 1）・選んだ値の真ん中です。パラメータはその幅の中、不透明度と色は 0〜1 に収めます（端で止めた数も出ます）。数を変えるとそのままキャラに出ます。「変える」で 1 歩、「やめる」・Esc なら残りません。前の選び方を覚えています
- **口パク（音声から）**：「アニメ → 口パク（音声から）…」で音声ファイル（WAV・MP3・OGG など）を選ぶと、音量から口の開け閉じ（MouthOpen）、母音の大まかな見当から口の形（MouthForm）のキーをアニメに作ります。1 回で 1 歩（取り消せます）
  - **あいうえお**（窓の上で選ぶ）：母音ごとのパラメータ（あ・い・う・え・お。その口の形を値 1 に作った物）に、声から推し量った重みのキーを作ります。声の高さに合わせて見るので、高い声も低い声も同じに使えます。VRM の aa・ih・ou・ee・oh の名前でも見つけます。パラメータが無ければ「無い母音のパラメータを作る」で MouthA〜MouthO（0〜1）を 1 歩で作り、それぞれ値 1 のキーで口の形を作ります
  - **コマ替え**（アニメ風）：口の絵（パーツ）を、閉じと開いた形の分だけ選ぶと、1 度に 1 枚だけ見せる不透明度のキーを段で作ります（名前に mouth_closed・mouth_a などがあれば最初から選ばれています）。無い母音は近い絵を使い、閉じと 1 枚だけなら音量だけで切り替えます。「1 枚を見せる長さ」で、2 コマ・3 コマ以上に（ちらつかない）
  - 音声は**そのパソコンの中だけ**で読みます。どこへも送らず、ファイルにも入れません（入るのは作ったキーと、音声のファイル名だけ）
  - 窓で、キーを書くパラメータ（開け閉じ・口の形。口の形は「使わない」も）、書くアニメ（新しいアニメ lipsync か、今あるアニメ。今あるアニメでは、その 2 本のキーだけ置き換え、長さが足りなければ音声の長さに延ばす）、**強さ**（口の開き方）・**なめらかさ**（細かい動きをならす）・**間引き**（大きいほどキーが少ない）を選べます。下に、できるキーの数が出ます
  - 口の形は母音の見当なので大まかです。合わない時は「開け閉じだけ」にします（口の形のパラメータが無いモデルでは最初からこれ）
  - 作ったアニメを再生すると、その音声が一緒に鳴ります。音声はファイルに入っていないので、開き直した時は下の行で知らせ、アニメの欄の「音声をもう一度選ぶ（ファイル名）」で選び直すと、また一緒に鳴ります
- タイムラインのキー（ひし形）はクリックで選び、横にドラッグで時間を動かし、補間（直線・なめらか・段）を選べます
- タイムラインには、パラメータがみな 1 行ずつ、名前の右に小さなつまみ付きで並びます（キーの無い物は薄く）。つまみを動かすと、今の時間にキーが入ります（自動キーの時。1 回動かすのが 1 歩）。右のパラメータの欄と行き来しなくても、タイムラインだけでアニメが作れます
- Ctrl を押しながら行をクリックすると、そこにキーが入ります（値はその時の値）。Ctrl を押しながらキーをクリックすると消えます（Live2D と同じ）
- **操作を記録してアニメにする**（時間軸の「● 記録」、アニメ → 操作を記録してアニメにする、Shift+Space）：今の時間から再生が始まり、その間に動かしたつまみ（右の欄・時間軸の行・XY の格子・上の帯）の通りにキーができます。止めるのはもう一度押す・Esc・Space・アニメの終わり（ループのアニメは 1 周で止まります）。動かしたパラメータだけ、記録した時間の範囲のキーを置き換えます（範囲の外のキーと、動かさなかったパラメータはそのまま）。手の小さなぶれは少しならし、キーは、直線でつないで値の範囲の 2% 以内になるよう間引きます。1 歩で取り消せます
  - 押すと、まず画面の真ん中に 3・2・1 と出てから（1.5 秒、Esc でやめる）記録が始まります。「3・2・1」の印を外すと、すぐ始まります
  - 記録中は、画面の右上に赤い「● 記録中　残り … 秒」が出ます
  - 「● 記録」の右の速さ（1×・0.5×・0.25×）で、ゆっくり再生しながら記録できます。キーの時間は元の速さに直ります（どちらもこの PC に残ります）
- **オニオンスキン**（時間軸の「オニオン」）：止めている時、今の時間の前の姿を赤みで、後の姿を青みで、薄く重ねます（再生中は出しません）。⚙ で、間隔（前後のキー・0.05〜0.5 秒ごと）、前後の枚数（1〜3）、濃さ、「選んだパーツだけ重ねる」を選べます（この PC に残ります）。文書は変わりません
- **キーをまとめて扱う**（Live2D のドープシートと同じ）：
  - 時間軸の何も無い所をドラッグすると四角が出て、中のキーを選びます（何行にまたがっても。Shift を押すと今の選びに足す）。Shift＋クリックで 1 つずつ足す・外す。Ctrl+A（アニメ → キーをすべて選ぶ）で全部
  - 選んだキーの 1 つをドラッグすると、全部が同じだけ動きます（1 歩）。**Alt＋ドラッグ**で、いちばん早いキーを軸に間隔が広がる・縮みます
  - Delete で選んだキーをまとめて消し、補間の欄を変えると選んだキー全部が変わります
  - **Ctrl+C** で写し、時間を決めて **Ctrl+V** で、いちばん早いキーがその時間に来るよう貼ります。ほかのアニメに切り替えてから貼ることもできます。入りきらない時はアニメの長さを延ばします（下の行に出ます）。同じ時間にキーがあれば置き換えます
- PageUp・PageDown で 1 コマ戻る・進む（タイムラインの fps を選んでいなければ 60 分の 1 秒）、Enter で再生・止める
- タイムラインのルーラーの左（パラメータの名前の列の上）の「自由・24 fps・25 fps・30 fps・60 fps」で、コマの細かさを選べます（作業ファイルに残り、元に戻せます）。選ぶと、ルーラーのクリック・キーのドラッグ・PageUp／PageDown がその fps のコマちょうどに乗り、時間の横に「12 / 48 コマ」と出ます。アニメ・動画に合わせる時は 24、配信・ゲームなら 30 か 60。書き出す .ug9 のキーは秒のままです（Shift を押しながらなら、コマに乗らずに好きな時間）

|---|---|
| ファイル → 保存（.ugo9）（Ctrl+S） | 作業ファイル **.ugo9**：作業用 JSON と、それが使う画像（アトラス・描いたマスク）を 1 つにまとめた物（中身は zip）。model.json として開いた物は、今まで通り JSON と画像を別々に書きます。「名前を付けて保存」で、どちらの形にするかを選べます（.ugo9 が先）。新しい版のエディタで作られたファイルは、開く時に一言知らせます。この版が知らない項目（JSON の知らない欄・.ugo9 の中の知らないファイル）は、直して保存しても消えずに残ります |
| ファイル → 書き出し：Ugo9 データ（.ug9）（Ctrl+Alt+S） | ゲームや Web で使う形（`web/ugo.js` などで再生）。書き出す前に確かめ、注意（使われていないパラメータなど）があれば窓に並べてから書き出します（直し方も出ます。Enter か「書き出す」で書き出し）。何も無ければすぐ書き出します |
| ファイル → 書き出し：glTF・VRM… | glTF（.glb）か VRM に書き出します。書き出す前に、その形で失う物（マスク・重ね方・パーツの色・描画順など）を直し方と一緒に並べ、エラーがあれば書き出せません。窓の上で .ug9・glTF・VRM を選び替えられます。アトラスが 2 ページ以上でも書けます（描いたマスクなど、マスク専用のパーツは書きません） |
| ファイル → 書き出し：画像・動画… | GIF・APNG・WebM・MP4、**透過の連番**（ZIP。After Effects で読むスクリプト import_to_after_effects.jsx 付き）、**MOV**（PNG のコマ・透過・劣化なし。After Effects・Premiere・DaVinci 向け）、**WebM（透過）**。いくつ選んでも絵は 1 回描くだけ。透明が要る時は 透過の連番・MOV・WebM（透過）・APNG。大きさは倍率（× 0.5〜× 2）、長い辺（1920・2560・3840）、枠の中に（1920×1080・3840×2160＝4K、キャラを真ん中に）。下にでき上がりの px が出ます。fps は 24・29.97・59.94 なども打てます。GIF・APNG 以外はコマを描くたびに書くので、長い物・4K でもメモリを食いません。GPU が描けない大きさは、書く前に断ります |
| 書き出しの窓の「パーツのまとまりごとに」 | まとまり（髪・顔・体など）ごとに、ほかのパーツを隠して同じ姿勢で描いた透過の連番（「MOV で」なら MOV）を 1 つの ZIP に。After Effects のスクリプト（import_to_after_effects.jsx）と Premiere・DaVinci の XML で、描く順と合成のとおりに積めます。まとまりの既定は PSD の一番上のフォルダ（フォルダの外のパーツは 1 つずつ）で、「まとまりを選ぶ…」でパーツごとに選び直せます（作業ファイルに覚える、1 歩）。1 つのパーツのまとまりは、そのパーツの合成（乗算など）をレイヤーに付けます。いくつものパーツのまとまりに乗算などがあると、その合成は AE では効かないので、窓で知らせます。別のまとまりのパーツでクリッピングしたパーツも、正しく切り抜かれます |
| 書き出しの窓の「プリセット」「ファイル名」「カメラ」 | **プリセット**：いまの設定（形式・大きさ・fps・背景・アニメと秒・ファイル名・カメラ）に名前を付けて「残す…」とこの PC に残り、一覧で選ぶと戻ります。「.json に書き出す」で人に渡せるファイルに（`ugo_export --preset` でも同じに書き出せます）、「.json を読む」で読みます。読めない値は外して、窓の下に何を外したか出ます。プリセットに固定値（`pinned`）があれば窓に出て、「外す」でいまのスライダーに戻ります。**ファイル名**：`{doc}`（作業ファイル名）・`{anim}`（アニメ名）・`{fps}`・`{w}`・`{h}`（書き出しの px）を並べた形。**カメラ**：「＋ キー」で 秒・倍率・見る点（モデルの px、空なら真ん中）のキーを足すと、キーのあいだをなめらかに寄り・引きします（`ugo_export --camera` と同じ）。2 つ目からのキーの「カット」を入れると、そのキーの時刻で一気に切り替わります（それまでは前のキーのまま）。カメラは描く時だけで、物理（揺れ）は動きません |
| 書き出しの窓の GIF・APNG の大きさ | GIF と APNG は全部のコマをメモリに持ってから書くので、大きさ×長さで要るメモリを先に見積もります（幅×高さ×4×コマ数の 1.5 倍）。約 1 GB を超えると「このまま書きますか？」と聞き、約 2 GB を超えると書かずに、MP4・WebM・PNG の連番（ZIP）か、小さく・短くするよう出します（1080p なら 30 fps で 4 秒ほどで聞き、8 秒ほどで止めます）。MP4・WebM・PNG の連番はコマごとに書くので、長さに関係なく書けます |
| 書き出しが終わったら知らせる | 書き出しの窓の「終わったら知らせる」（始めから印あり・このパソコンに残る）。5 秒より長い書き出しが終わると短い音が鳴り、ほかの窓を見ている時はパソコンの通知（印を付けた時に許すか聞かれます）とタブの名前の ✓ でも知らせます。✓ はエディタに戻ると消えます |
| 書き出しが途中で失敗した時 | 何を書けなかったか・わけ・直し方を 1 行で出します。メモリが足りない（小さく・短く、MP4・WebM・PNG の連番に）、このブラウザで書けない形式（PNG の連番か、新しい Chrome・Edge・デスクトップ版で）、ファイルを書く許しがない（別のフォルダに、同じ名前のファイルを開いているアプリを閉じて）、保存先の空きがない、GPU が途中で止まった（表示 → 表示品質 を「軽い」に）、それ以外（ブラウザの言葉をそのまま添え、表示 → 問題の一覧 へ）。保存の窓で「キャンセル」した時は何も出しません |

- 絵を描き直した時は「ファイル → PSD を読み直す…」。メッシュ・キーの形・ウェイトはそのままで、絵だけが替わります。新しいレイヤーはパーツとして足されます
- 縦横を同じ割合で大きく（小さく）描き直した PSD を読み直すと、「モデル全体を k 倍にして合わせますか？」と聞きます。「OK」なら、メッシュ・キーの形・骨・ワープデフォーマ・アニメ・物理の重力も k 倍になり、作り直さずに新しい大きさで続けられます（1 歩で取り消せます）。「キャンセル」なら大きさはそのままで絵だけ替わります。縦と横の割合が違う時は聞きません

### 揺れ（物理）ごと動画にする

髪や服の揺れ（物理）は、動画の書き出しにそのまま入ります。特別な設定は要りません。

1. アニメの場（Alt+2）で、書き出すアニメを選んで ▶。揺れが見えれば準備はできています（見えない時は 物理 の印と、パラメータに物理が付いているかを見てください）
2. 「ファイル → 書き出し：画像・動画…」で、「アニメ」に同じアニメを選び、形式（MP4・WebM・透過の連番・MOV など）・大きさ・fps を選んで「書き出す」
3. できた動画を開いて、揺れを確かめる

知っておくと良い事：

- 書き出しの窓の「アニメーション」の下に、揺れが入るか（止め絵なら止まった形か）が出ます。焼き付けたキーも持つアニメでは「揺れが二重になります」と出ます
- 物理は書き出す fps のコマごとに動かします。fps が高いほど揺れがなめらかになります（30 か 60 がおすすめ）
- ループするアニメは、書く前に 1 周ぶん物理を回しておくので、動画の終わりと始めの揺れがつながります（ループ再生しても揺れが飛びません）
- 止め絵（アニメを選ばない）では、揺れは止まった形です
- カメラの寄り・引きでは揺れは動きません（カメラは描く時だけ）
- 物理を持たない書き出し先や、キーとして揺れを直したい時は「アニメ → 物理をアニメに焼き付ける…」で揺れをキーにします（焼いた後は物理を切らないと、揺れが二重になります）
- 長い・大きい GIF・APNG はメモリが足りなくなる事があります。その時は MP4・WebM・透過の連番にしてください

## 困った時

| 出る物 | 意味 |
|---|---|
| 状態の行が赤い（コンパイルできません） | 直前の変更に問題があります。表示は最後に通った形のまま。押すと問題の物を選びます。取り消し（Ctrl+Z）で戻せます |
| 「注意 n 件」・左の「問題」 | 動くけれど、おかしいかもしれない所（使われていないパラメータ、ワープデフォーマからはみ出したパーツなど）。左の「問題」のタブに一覧が出ます（下の「注意 n 件」を押しても開きます）。項目を押すとその物を選びます。直すと一覧から消えます。薄い項目は「お知らせ」で、多くは直さなくて大丈夫です |
| 目・口が見つからない、左右が逆 | 目や口のパーツは、レイヤーの名前で探します。左右は、レイヤーの名前、無ければ入っているフォルダの名前（「左目」など）で分けます。知らせの横の「PSD の描き方を見る」で、[PSD の描き方](PSDの描き方.md) のその節が開きます |
| 「キーの間です」 | キーの上でだけ形を作れます。「ここにキーを作る」を押すか、スライダーをキーの点に合わせます |

## 保存していない作業の控え

保存していない変更があると、決めた間隔（はじめは 15 秒。「ファイル → 控えを取る間隔…」で 10 秒〜5 分、この PC に覚えます）ごと（と、窓を隠した時）に、作業の控えをこのコンピューターの中に残します。下の行の右に「控え 12:34:56」と、最後に取った時刻が出ます。**控えはどこにも送りません。**

- 落ちた・閉じてしまった後に開くと、下の行に枠付きで「保存していない作業の控えがあります」と出ます。「戻す」で控えの状態に戻ります（まだ保存していない扱いなので、「保存」で残してください）。「捨てる」で控えを消します
- 「ファイル → 控えから戻す…」で、いつでも控えを出せます（「捨てる」を押してしまった後でも、その後の変更の控えがあれば）
- 「保存」すると、控えは消えます
- デスクトップ版は、保存していない変更がある時に窓を閉じようとすると、閉じてよいか聞きます（ブラウザ版はブラウザが聞きます）

控えのある場所と消し方：

| 版 | 場所 | 消し方 |
|---|---|---|
| デスクトップ版（Windows） | `%LOCALAPPDATA%\app.ugo9.editor\EBWebView\` の中（アプリの表示用のデータと一緒） | アプリで「捨てる」を押す。アプリを消した後に残っていれば、このフォルダごと消す |
| ブラウザ版 | ブラウザの、エディタを開いたサイト（例 `localhost:8099`）のデータ（IndexedDB） | アプリで「捨てる」を押す。またはブラウザの設定で、そのサイトのデータを消す |

控えは 1 つだけです。新しい作業の控えは、前の控えを上書きします。

## 人に頼む・頼まれた時に渡す物

モデルを人に作ってもらう時・作って渡す時は、後で直せるように次をそろえます（「編集用のデータが渡されない」ことがよくあります。頼む時に、これも渡してもらうと決めておきます）。

| ファイル | 何か | 後で直せるか |
|---|---|---|
| **作業ファイル（.ugo9）** | エディタで開いて直すための 1 つのファイル。メッシュ・骨・ウェイト・パラメータ・キー・アニメ・物理と、絵（アトラス）が全部入っています | **直せる**。これがあれば、続きから作れます |
| **元の絵（PSD など）** | 描いたアプリのレイヤーのままの絵 | 絵を描き直す時に要ります（「ファイル → PSD を読み直す」で、メッシュやキーはそのまま絵だけ入れ替わります） |
| 書き出した .ug9 | ゲーム・Web・アプリで動かすための、小さくまとめた物 | 直すためには作られていません。「開く」で作業ファイルに戻せますが、名前や一部の設定は戻りません（下の行に出ます） |
| 書き出した PNG・動画（MP4・WebM・GIF） | 動きを絵や動画にした物 | 直せません（見るため・使うための物です） |

- 頼む時：「作業ファイル（.ugo9）と元の PSD も渡してください」と最初に決めておきます。書き出した物（.ug9・動画）だけでは、後で表情を足す・絵を直すことができません
- 頼まれた時：渡す時は「ファイル → 保存」で .ugo9 を作り、元の PSD と一緒に渡します。.ugo9 は 1 つのファイルなので、そのまま送れます
- フォントや素材の使ってよい範囲（権利）は、ファイルとは別に、頼む人と頼まれた人で決めてください
