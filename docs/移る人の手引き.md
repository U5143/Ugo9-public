# ほかのアプリから移る人の手引き（2026-11-10、利用者の声 #10・#5・#14）

After Effects・Live2D Cubism・Spine・Procreate／CLIP STUDIO PAINT を使ってきた人が、Ugo9 のどこで同じことをするかの表と、よくある作業の手順の書き換え。考え方の違い（つまみの上で形を作る、など）は「ヘルプ → 動きの仕組み」（F1、[動きの仕組み.md](動きの仕組み.md)）に、名前の分からない道具は **F3**（機能を名前で探す）で。

- Ugo9 の側はエディタの今のメニューの名前（日本語の画面。英語の画面では同じ所に英語の名前）とキー
- 向こうの側は、各アプリの公開の説明にある言葉だけ（画面の写しは使っていない）。向こうのキー操作は書かない
- 「—」は、Ugo9 に同じ物が無い物。近い物があれば書く
- どの道具も、エディタで **F3** を押して元のアプリの言葉（「パペットピン」「回転デフォーマ」「スロット」など）を打つと出る
- ほかのアプリが書き出したモデルのファイル（Live2D の .moc3 など）は読まない。絵（PSD など）から作り直す

## Procreate・CLIP STUDIO PAINT から（絵を描く人）

| 描くアプリの言葉 | Ugo9 でどうなるか |
|---|---|
| レイヤー | 1 枚が 1 つのパーツ。動かす所ごとに分ける（[PSDの描き方.md](PSDの描き方.md)） |

## よくある作業の書き換え

### 1. PSD から、まばたきと顔の向きのある顔（Live2D の流れ）

1. ファイル → 開く…（Ctrl+O）で PSD を開く（名前の決まりは [PSDの描き方.md](PSDの描き方.md)）
2. パラメータ → 自動で作る：下書きをまとめて（顔の向き・まばたき・口の開け閉じ・揺れ物の候補）
3. パラメータの一覧でつまみを動かして確かめ、直したい形はつまみをキーの上に置いて形を動かす
4. 角の形が変な時：パラメータ → 四隅の形を作り直す（Ctrl+4）
5. ファイル → 保存（.ugo9）（Ctrl+S）、ランタイム用は ファイル → 書き出し：Ugo9 データ（.ug9）（Ctrl+Alt+S）

### 2. 骨とウェイトで体を動かす（Spine の流れ）

1. 変形 → 骨を作る（B）で、体 → 上腕 → 前腕 の順にドラッグ（選んだ骨の子になる）
2. パーツを選んで 変形 → ウェイトを自動で付ける、直す所は ウェイトを塗る（W、Alt で逆向き）
3. ウィンドウ → アニメ（Alt+2）、アニメ → 新しいアニメ
4. 時間を動かし、骨をドラッグで回す。アニメ → キーを打つ（I）か、自動でキーを打つ
5. キーの動き方は、キーを選んでプロパティの「キーの曲線」で曲げる

### 3. 揺れ物を付ける（AE の wiggle・Live2D の物理・Spine の物理制約の代わり）

1. 髪の骨を選ぶ（骨が無ければ ファイル → PSD を開く時：グループを骨に で開き直すか、骨を作る）
2. 変形 → 物理のチェーンを作る（選んだ骨から）。たくさんある時は まとめて作る
3. 表示 → 物理を動かす で、つまみや骨を動かして揺れ方を見る
4. パラメータで揺らしたい時（Live2D の物理と同じ形）：変形 → 物理（パラメータの揺れ）…
5. 繰り返すアニメに揺れを入れたい時：アニメ → 物理をアニメに焼き付ける…

### 4. 動画にして編集アプリへ（AE のレンダーキューの代わり）

1. ファイル → 書き出し：画像・動画（GIF・APNG・WebM・MP4）…
2. 形式を選ぶ：After Effects には 透過の連番（ZIP、読むスクリプト付き）か MOV。Premiere・DaVinci には MOV
3. 大きさ・fps・背景・カメラのキーを決め、よく使う設定はプリセットに保存する
4. まとまりごとに色や光を付けたい時は「パーツのまとまりごとに」
5. コマンドで同じ物を作る時は `ugo_export --preset 保存したプリセット.json`（[動画の書き出し.md](動画の書き出し.md)）

### 5. 描き直した絵を差し替える（Live2D の PSD の差し替え）

1. 描くアプリで PSD を直して保存する（レイヤーの名前は変えない。変えた時は下の 4）
2. ファイル → PSD を読み直す…（いつも見張るなら ファイル → PSD の更新を見張る）
3. メッシュ・キーの形・ウェイトはそのまま、絵だけが替わる。絵が大きく動いたパーツはお知らせが出る
4. レイヤーの名前を変えた・消した・足した時は、読み直す前に `node tools/psd_links.mjs model.json 新.psd` で一覧を見る（名前の変更を見つけて、パーツが消えないようにできる）
5. Ugo9 で描き足した所を PSD に戻す：パーツ → 絵を描き足す の後、ファイル → 描き足しを PSD に書き戻す…

## 言葉の違いで迷いやすい所

- Ugo9 の「キー」は、Live2D のキーフォーム（パラメータのつまみの上の点：形）と、時間軸のキーフレーム（時間）の両方を指す。つまみの上の点は形、時間軸の上の点は時間
- 「ワープデフォーマ」は Live2D と同じ働き。「デフォーマ」だけの時は、キーの形（差）を入れる入れ物のこともある
- 骨は、Live2D の回転デフォーマ、Spine のボーン、AE のパペットピン（とヌル）のどれにも当たる
