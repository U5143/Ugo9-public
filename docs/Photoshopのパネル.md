# Photoshop のパネル「Ugo9 の確かめ」（`plugins/photoshop/`、2026-11-10、機能の比べ #21・利用者の声 #8）

Photoshop で絵を分けている間に、Ugo9 の自動の道具（目の開け閉じ・口の開け閉じ・顔の向き）が名前でパーツを見つけられるかを、開いている文書のレイヤーから確かめるパネル。PSD を書き出して Ugo9 で開く前に直せる。

## 中身

- 開いている文書のレイヤーを見て、直す所を一覧にする（文書が変わると自動で見直す。「確かめ直す」でも）
  - 名前が既定のまま（`レイヤー 1`・`Layer 1` など）
  - 調整レイヤー・塗りつぶしレイヤー（Ugo9 は読まないので、下に結合する）
  - 目のレイヤーに左右が無い（名前にも、入っているフォルダ（`左目` など）にも）、上まぶた・まつ毛が無い
  - 口が 1 枚（上唇・下唇・口の中に分ける）、口の中が無い
  - 顔の絵が名前で見つからない、同じフォルダに同じ名前
  - 隠れる所（前髪の下のおでこ）を描いたか
- 一覧の行をクリックすると、そのレイヤーを選ぶ
- 「下塗りを足す」：選んだレイヤーのすぐ下に、空のレイヤー「（名前） 下塗り」を足す（隠れる所を描くため。Photoshop の取り消しで 1 回で戻る）
- 名前の決まりは Ugo9 の自動の道具（`tools/eye_mouth.mjs`）と同じ文字列（試験で同じかを見る）と、[PSDの描き方.md](PSDの描き方.md)
- 文書を変えるのは「下塗りを足す」だけ。外の部品は使わない。Photoshop の API は Adobe の公開の説明だけから
- 画素を見て分かること（1 枚のレイヤーに離れた絵がある、など）は、PSD を保存してから `node tools/psd_check.mjs 絵.psd` で（[PSDの描き方.md](PSDの描き方.md) の「読み込む前に確かめる」）

## 読み込み方（開発者モード）

今は、Adobe の **UXP Developer Tool** で読み込む（.ccx にして配るのは後で決める）。

1. Creative Cloud のアプリから「UXP Developer Tool」を入れる
2. Photoshop（2022 / 23.3 以降）を開き、「環境設定 → プラグイン」で「開発者モードを有効にする」に印を付けて、Photoshop を開き直す
3. UXP Developer Tool で「Add Plugin」を押し、このリポジトリの `plugins/photoshop/manifest.json` を選ぶ
4. 足した行の「•••」→「Load」を押す。Photoshop の「プラグイン」メニューに「Ugo9 check（Ugo9 の確かめ）」が出るので、パネルを開く
5. ファイルを直した時は「Reload」

## 確かめたこと

- `tests/photoshop_panel_test.mjs`（Photoshop 無し）：名前の決まりが自動の道具と同じ文字列。手引きどおりの顔は直す所なし、雑な物（既定の名前・左右の無い目・1 枚の口・調整レイヤー・顔なし）はそれぞれ出る。フォルダの名前から左右。`main.js` を Photoshop の API の代わりの物の上で動かし、一覧・行のクリックで `batchPlay` の select（レイヤーの id）・「下塗りを足す」が 1 回の modal で作って選んだレイヤーの下へ動かす
- Photoshop そのものでは、まだ（PC確認.md）
