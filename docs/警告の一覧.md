# 読み込みと下書きの関数の警告（`notes` の code）

`importPsd`・`reimportPsd`・`readPsd`・`importKra`・`importOra`・`importPngSet`（と各 `Async`）・`makeFaceAngles`・`makeEyeBlink`・`makeMouthOpen`・`makeIdle`・`makeStarterRig`・`importUg9` は、英語の文の `warnings` に並べて `notes` を返す。`notes[i]` は `{ code, vars, level, text }` の形で、`warnings[i]` と同じ順・同じ数になる。`text` は `warnings[i]` と同じ文、`level` は `'warn'` か `'info'`。エディタは `code` と `vars` から日本語や英語の文を作る（`tools/notes.mjs`）。`suggestChains` の候補は、`warning`（文）に加えて同じ形の `note` を持つ。

`vars` の中身は、id（パーツ・骨・レイヤーの名前）、数、配列だけ。

下の表で「PSD」と書いた code のうち、レイヤーの扱いの物（`layerAdjustment`・`layerEmpty`・`layerBlend`・`layerHidden`・`groupBlend`・`psdScaledDown`・`psdLargeCanvas`・`meshCoarser`・`atlasPages`）は、Krita・OpenRaster・PNG の組（`tools/import_layers.mjs`）でも同じ形で出る（文の「in the PSD」はそのまま）。

揺れ物の `kind` は `hair`・`ribbon`・`skirt`・`tail`・`ear`・`cloth`・`accessory` のどれか。候補の `reason`（英語の文）にも、同じ形の `reasonNote` を並べて付ける。

読めない PSD は、`code` と `vars` の付いた Error で止まる（`importPsd`・`readPsd`・`importPsdAsync`）。`e.code` が次のどれか：`psdNotPsd`（PSD でない）、`psdVersion` {`version`}、`psdDepth` {`depth`}（32 ビットなど）、`psdMode` {`mode`：`bitmap`・`Lab`・`multichannel`}、`psdTruncated`（ヘッダーで切れている）。

PSD にレイヤーを足す（`addLayerToPsd`、`tools/psd_add_layer.mjs`）が断る時も、`code` と `vars` の付いた Error で止まる：`psdAddNotPsd`（PSD でない）、`psdAddDepth` {`depth`}（8 ビットでない）、`psdAddMode` {`mode`}（RGB でない）、`psdAddNoLayerInfo`（16・32 ビットのレイヤーの置き場。まだ書けない）、`psdAddNoLayers`（レイヤーの無い 1 枚の絵）、`psdAddBadLayer` {`width`, `height`}（画素の数が大きさに合わない）。

PSD のレイヤーの画素を置き換える（`replaceLayerPixels`、`tools/psd_add_layer.mjs`）が断る時も、`code` と `vars` の付いた Error で止まる：`psdEditNotPsd`、`psdEditDepth` {`depth`}、`psdEditMode` {`mode`}、`psdEditNoLayerInfo`、`psdEditNoLayer` {`layer` か `index`}、`psdEditAmbiguous` {`layer`, `count`}、`psdEditKind` {`layer`, `kind`：`text`・`smartObject`・`fill`・`adjustment`}、`psdEditBadPixels` {`width`, `height`}、`psdEditNeedsInflate`。止めずに知らせる物は `opts.notes` に：`psdEditMaskHides` {`layer`}（マスクが外を隠すので、マスクの外へ描いた画素は見えない）。

Krita・OpenRaster・PNG の組（`importKra`・`importOra`・`importPngSet`、`tools/import_layers.mjs`）が読めない時も同じ形の Error：`layersNotZip`（ZIP でない）、`layersNoStack`（.ora に stack.xml が無い）、`layersNoMaindoc`（.kra に maindoc.xml が無い）、`layersKraOld` {`version`}（Krita 1 のファイル。今の Krita で保存し直す）、`layersZip64`（4 GB を超える ZIP）、`layersZipMethod` {`entry`, `method`}（stored・deflate 以外の圧縮）、`layersNone` {`reasons`}（読めるレイヤーが 1 つも無い。`reasons` は飛ばした理由の code）、`pngBad` {`file`}（PNG でない・切れている）、`pngUnsupported` {`file`, `type`, `depth`}。Procreate：`procreateNoArchive`（Document.archive が無い）、`procreateBadArchive`（読めない plist・キャンバスの大きさが無い）。止めずに知らせる物：`procreateRowsFlipped`（info。タイルの行が下からだったので、縮小画像に合わせて上下を返した）。Aseprite：`aseNotAseprite`（ヘッダに 0xA5E0 が無い）、`aseDepth` {`depth`}（32・16・8 でない）、`aseNoPalette`（パレット付きなのにパレットが無い）、`aseBroken` {`what`}（コマ・塊・レイヤー・セル・パレット・タグ・文字列・セルの絵のどれかが壊れている）。止めずに知らせる物：`aseFrames` {`frames`}（2 コマ目からは読まない。`frames: 'animate'` で読む）、`aseAnimated` {`animations`, `frames`, `parts`}（info。コマをアニメとして読んだ）、`aseFramesTooMany` {`parts`, `max`}（違う絵が多すぎるので最初のコマだけ）、`aseTagRange` {`tag`, `from`, `to`}（ファイルに無いコマのタグは飛ばす）、`aseTags` {`tags`, `frames`}（タグの名前と、コマの範囲〔0 から〕）、`aseTilemap` {`layer`}、`aseReference` {`layer`}（info）、`aseLinkedLater` {`layer`}、`aseZIndex` {`layer`, `z`}、`asePixelRatio` {`width`, `height`}、`aseNearest`（info。ピクセルアートなので近い色で描くのを勧める）。SVG（`importSvgAsync`、`tools/import_svg.mjs`）：`svgNotSvg`（`<svg>` が無い）、`svgNoSize`（幅と高さも viewBox も無い）、`svgEmpty`（描く物が無い）、`svgNoRasterizer`（ブラウザのページの外で `opts.rasterize` が無い）、`svgDrawFailed` {`layer`}。止めずに知らせる物：`svgExternal`（ファイルの外の絵は描かれない）、`svgText`（info。文字はこのコンピュータのフォントで描く）、`svgForeignObject` {`element`}（`<foreignObject>` は画素に描けない）。

`layer` は、PSD の中のフォルダを `/` でつないだ名前（例：`顔/目/白目`）。

## .ug9 から作業ファイルへ（`importUg9`、`tools/import_ug9.mjs`）

読めない時は Error の `code`：`ug9NotUg9`（先頭が UGO9 でない）、`ug9Version` {`version`, `newer`, `reads`}（読まない版：0.7 と 1.x のほか。`newer` が true なら新しい版の Ugo9 で作られた（Ugo9 を新しく）、false なら古い版（作業ファイルからコンパイルし直す））、`ug9Newer` {`kind`, `version`}（新しい版の Ugo9 で作られた後の 1.x で、読めないと正しく動かない表がある。`version` はファイルの版）。`ugo_export` も同じ事を言葉で出す（新しい版：ファイルの版とこの ugo_export が読む版、古い版：コンパイルし直す、途中で切れたファイル、.ug9 でないファイル。終わりに芯のエラー番号）、`ug9Broken` {`what`}（大きさ・表・番号・数が合わない。`what` はどの表か）。読めた時に戻らない物を知らせる note：

| code | vars | どの関数 | 意味 |
|---|---|---|---|
| `ug9NamesRenamed` | — | .ug9（warn） | 空の名前や同じ名前があったので、新しい id を付けた |
| `ug9ConstraintIds` | `count` | .ug9（info） | 制約には .ug9 に名前が無いので constraint0.. と呼ぶ。複数の骨の transform 制約は骨ごとに 1 つになる |
| `ug9ColorIds` | `count` | .ug9（info） | 色には .ug9 に名前が無いので color0.. と呼ぶ |
| `ug9DeformerIds` | `count` | .ug9（info） | デフォーマには .ug9 に名前が無いので、差分のある物を morph0.. と呼ぶ。同じ範囲を使っていたデフォーマは 1 つにまとまることがある |
| `ug9WarpNotRegular` | `warp`, `off`（px） | .ug9（warn） | 格子の基準の点が等間隔でない。角の四角（rect）で戻した |
| `ug9SmoothBaked` | `tracks` | .ug9（info） | 曲線を短い直線に分けて焼いたらしいトラックがある。その直線のまま戻した |
| `ug9ColorJoined` | `tracks` | .ug9（warn） | 色のトラックで、チャンネルごとにキーの時刻となめらかさが違った。まとめたので、なめらかさが少し変わることがある |

| `ug9SkippedTable` | `kinds`, `changesPicture` | .ug9（info か warn） | 後の 1.x の、知らない種類の表を飛ばした（`changesPicture` に入る物があれば warn） |

| `ug9Lost` | — | .ug9（info） | .ug9 に無いので戻らない物：取り込み元（PSD・Spine）とのつながり、のり（重みと差分に焼かれている）、曲線の形と補間の名前、エディタだけの情報（ガイド・選択セット・フォルダ・スクリプト） |

## 書き出す前の確かめ（`checkExport`、`tools/check_export.mjs`）

各 note には `fix`（直し方の一言、英語）も付く。

| code | level | vars | 行き先 | 意味 | 直し方 |
|---|---|---|---|---|---|
| `exportCompileError` | error | `path`, `code`, `message` | 全部 | モデルがコンパイルできない（書き出せない） | 問題の一覧のエラーを直す |
| `exportMasks` | warn | `parts`, `count` | glTF・VRM | マスクは書けない。マスクの掛かったパーツは切り抜かれずに描かれる | PSD で切り抜いた絵にする、またはその書き出しから外す |
| `exportBlend` | warn | `parts`, `count` | glTF・VRM | 合成モード（乗算・スクリーン・加算）は書けない。通常で描かれる | 描画アプリで効果を絵に描き込む |
| `exportColors` | warn | `parts`, `count` | glTF・VRM | パーツの色（乗算色・スクリーン色・tint）は書けない | 色を絵に焼き込む、または色の変化を外す |
| `exportDrawOrder` | warn | `parts`, `count` | glTF・VRM | 描画順が変わる。基準の姿の順のまま | 入れ替わるパーツを手前用と奥用の 2 つに分け、不透明度で切り替える |
| `exportFlatSkeleton` | info | `bones`, `count` | glTF | IK・transform の制約・せん断・受け継ぎ方・格子の中の骨があるので、骨は平らに書き、毎フレームを焼く | 何もしなくてよい |
| `exportGridMorphs` | info | `parts`, `count` | glTF | 格子の中のパーツの曲がりを、モーフターゲットで書く（2 本のパラメータで曲がる所は近い値） | 何もしなくてよい |
| `exportManyWeights` | info | `parts`, `count`（頂点の数） | glTF | 5 本以上の骨の重みを、JOINTS_n を増やして書く（three.js は 4 本だけ読む） | Blender・Godot・Unity では何もしなくてよい |
| `exportWeightsCut` | warn | `parts`, `count`（頂点の数） | VRM | 5 本以上の骨の重みは、強い 4 本だけにする | 頂点ごとに骨 4 本までにする |
| `exportPhysicsBaked` | info | `names`, `count` | glTF | 物理と揺れの鎖はアニメに焼き込む（書き出し先では動きに反応しない） | 生きた揺れは .ug9 か VRM のスプリングボーンで |
| `vrmNoHumanoid` | error | `head`, `body`（見つかったか） | VRM | 人型に当てる骨（head と body / spine）が無い（書き出せない） | 頭の骨を head、体の骨を body（か spine）にする |
| `vrmSkeleton` | warn | `bones`, `count` | VRM | IK・transform の制約・せん断・受け継ぎ方は、VRM の骨では再現しない | VRM で動く骨は、通常の受け継ぎ・せん断なし・制約なしにする |
| `vrmChainInertia` | info | `names`, `count` | VRM | inertia か mix が 1 未満の鎖。VRM のスプリングボーンは 1 で動く | 何もしなくてよい（少し自由に揺れる） |
| `vrmExpressionsMissing` | info | `expressions`, `count` | VRM | VRM の表情（blink・aa・lookLeft など）に当てるパラメータが無い（その表情は書かない） | EyeOpenL / EyeOpenR・MouthOpen・EyeBallX / EyeBallY・BrowY を足す |
| `vrmAnimations` | warn | `names`, `count` | VRM | アニメは書かない。VRM にアニメは無い（アプリが動かす）（利用者の声 #400 の 5） | VRM では何もしない。アニメは .ug9（Web・Unity・Godot）・glTF・動画で |

| `exportTextureMemory` | warn | `bytes`, `mipmapBytes`, `largest` | .ug9 | テクスチャのメモリが 256 MB を超える、または 4096 px を超えるページがある（スマホや一部のエンジンで読み込みが遅い）。`checkExport` に `opts.textureSizes` を渡した時だけ見る | 半分の版も書く（`ugo9.mjs export --light`、エディタの「解像度ごとのアトラス」）か、PSD を開く時にアトラスを小さくする |

行き先 `ugo` では、コンパイラ自身の警告（上の表の compile の code）をそのまま返す。glTF・VRM でも、コンパイラの警告（info を除く）を後ろに付ける。
