# 機能の比べ：Live2D Cubism Editor・Spine Editor と Ugo9

2026-11-10 に作った。ユーザーの方針（11/10）は「Ugo9 エディタは機能を詰め込めるだけ詰め込んでからテストする」。この文書はそのための材料で、社内向けの比べに使う。

## 作り方

- Live2D Cubism Editor（5.3.04、Viewer と AE プラグインを含む）と Spine Editor（4.3.26）について、公開されている機能の名前を集めた。元にしたのは公式のマニュアル・ユーザーガイド・機能紹介・リリースの頁だけ
- 一行の説明は自分の言葉で書いた。コード・ファイル・画面の写しは使っていない。Live2D 本体のファイルと SDK には触れていない
- 集めた機能は、Live2D が約 145、Spine が約 160
- 突き合わせた物：利用者の声 の行番号（表では「声 #n」）。Ugo9 の今は、main（6c653e5）の docs と、エディタのメニューの項目名（`editor/i18n.js` の日本語、127 項目）で確かめた
- 2026-11-10（夜）：ugo9/v11 で済んだ物の「Ugo9 の今」を書き直した（済・一部済と PR 番号。まだ入っていない物は「PR #n」）。表から外さず残した
- 下の表には、Ugo9 に**無い物**と**弱い物**だけを載せた。並んでいる物は最後にまとめた

### 手数の見込み

| 印 | 意味 |
|---|---|
| 小 | エディタだけで済む。1 つの PR の中ほど |
| 中 | エディタの PR が数本、またはランタイムの API も要る |
| 大 | いくつもの担当にまたがる。設計から始める |
| **形式** | .ugo か作業用 JSON の形が変わる（ユーザーの了承が要る） |

## Ugo9 にもう並んでいる物（主な物）

上の表に入れなかった物。どれも main の docs かメニューで確かめた。

- **作業の土台**：組み立て・アニメの 2 つのモード、パネルの場所・名前付きのレイアウト、UI の大きさ、日英、グリッド・ガイド・定規、下絵、選択セット（その中だけ表示。Live2D の Solo・Spine の選択グループに当たる）、ロック、投げ縄、F3、問題の一覧、作業の控え、取り消し
- **PSD と絵**：PSD を開く・読み直す・見張る、k 倍で大きさを合わせる、描き足しとマスクを描いて PSD に書き戻す、Krita・Aseprite・PNG の読み込み、アトラスの自動配置（MaxRects と回転）
- **メッシュと描き方**：自動（選んだパーツにまとめて）・手で直す・作り直す・外周の帯・ミラー、マスク（反転・専用）、重ね方 4 つ、乗算色・スクリーン色・暗い色、穴を探す
- **変形**：骨・IK・ウェイト（自動・塗る・写す。左右反転して写すも）、ワープデフォーマ（まとめて作る・細かくする）、ワープの中の骨（回転デフォーマに当たる）、球・円柱（3D 回転表現に当たる）、グルー、変形ブラシ、線に沿って流す
- **パラメータ**：キー（2 点・3 点・ここに作る）、結合と四隅の作り直し、ブレンドシェイプ、マルチキー編集、まとめて動かす組（パラメータコントローラに当たる）、形のコピー・貼り付け・初期に戻す、動きの反転、今の形を基準に、ランダムポーズ、値のコピー、パラメータのグループと一覧
- **自動の下書き**：顔の向き・まばたき・口の開け閉じ・まとめて、物理のチェーン（名前から候補）、待機のアニメ、口パク（音量・あいうえお・絵の切り替え）
- **物理**：骨の鎖、パラメータの揺れ（Live2D の物理の設定と同じ並び）、アニメへの焼き付け
- **アニメ**：自動キー、キーをまとめて扱う、操作を記録、オニオンスキン、アニメのフォルダ、補間（直線・なめらか・段）
- **書き出し**：.ug9（再生用）、.ugo9（作業ファイル 1 つ）、.ug9 から作業ファイルへ戻す、glTF・VRM、GIF・APNG・WebM（透過）・MP4・PNG の連番・mov（PNG）・ProRes 4444 の mov（透過、`ugo_export`、v11 #377）、4K・好きな fps、プリセット、カメラ、AE で読むスクリプト、Spine の JSON・バイナリの読み込み
- **再生**：Web（ES Modules）、Godot、Unity、three.js。芯は C で 1 つ、形式は公開、MIT
