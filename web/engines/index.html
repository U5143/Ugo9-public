Ugo9 を Web のエンジンで

見本のキャラ（samples/basic）を、それぞれのエンジンの中に出します。右の欄で、アニメを選ぶ・パラメータを動かす・マイクで口を動かす（雑音の門つき）・自分でまばたき。キャラをクリックすると、そこにあるパーツの名前が出ます。

  • three.js（3D の場面の中の板。右ドラッグでカメラを回す）
  • PixiJS（v8）
  • Phaser（4）

エンジンは CDN（jsDelivr）から読みます。このフォルダを開くには、リポジトリの頭で node tools/serve.mjs 8080 などの小さなサーバーを立て、http://localhost:8080/web/engines/ を開きます。使い方は docs/エンジンの使い方.md。
