Ugo9 の Web の例

どれも短い 1 ページ。共通の準備は common.js。リポジトリのフォルダで node tools/serve.mjs（か npx serve など、どの静的なサーバーでも）を動かして http://localhost:…/web/examples/ を開く（ファイルを直に開くと、ブラウザが WASM とモデルを読ませない）。Next.js・Nuxt などで import しても、読み込むだけでは window・document を触らない。

  1. 読み込んで再生する
  2. 表情
  3. 視線（指の方を向く）
  4. まばたき
  5. 口（音の大きさで）
  6. 当たり判定
  7. 決まったフレームで描く（動画の道具）
